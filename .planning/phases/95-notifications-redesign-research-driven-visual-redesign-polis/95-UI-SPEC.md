# Phase 95 — UI Design Contract

> Visual and interaction contract for the notifications popover redesign. Generated by gsd-ui-researcher, verified by gsd-ui-checker.
> Sources: 95-RESEARCH.md (inventory, D1-D10 recommended defaults), user memory preferences, `components.json`, `src/index.css`. ## Spacing Scale

Declared values (multiples of 4):

| Token | Value | Usage |
|-------|-------|-------|
| xs | 4px | Icon-to-text gap, dot-to-glyph gap, row vertical padding (compact) |
| sm | 8px | Row horizontal padding, gaps between row cells, header control gaps |
| md | 16px | Popover header horizontal padding, banner padding |
| lg | 24px | Empty-state vertical padding |
| xl | 32px | (unused in popover) |
| 2xl | 48px | (unused) |
| 3xl | 64px | (unused) |

Row heights (one line at every density; density changes padding and font size only, never line count):

| Density | Event row | Group header | Time-bucket header |
|---------|-----------|--------------|--------------------|
| compact | 28px (py 4) | 28px | 24px |
| default | 32px (py 8 equivalent via h-8) | 32px | 28px |
| comfortable | 36px | 36px | 28px |

Virtualizer `estimateSize`: 32 (events/groups), 28 (headers); `measureElement` stays on wrapper; stable `getItemKey` per entry id (`header:{bucket}`, `group:{entityKey}`, `event:{id}`).

Fixed leading cells use explicit px sizing (avoid 0-width collapse in virtualized rows): unread-dot cell 8px wide, type-glyph cell 16px, avatar 20px (never dropped at any width), time cell `w-12` (48px) right-aligned tabular-nums.

Exceptions: icon-only hover-tray buttons are 24px square (visual) inside the row; the row overlay button supplies the full-row hit target. Header icon buttons 28px square (match sibling controls). Tray overlays the time cell (absolute, no layout shift) and also shows on `group-focus-within`.

## Typography

Three sizes, two weights (matches existing app scale; replaces the current 8/10/11/12.5px scatter).

| Role | Size | Weight | Line Height |
|------|------|--------|-------------|
| Body (event text, group title, filter labels, banners) | 12px | 400 (500 when unread) | 1.5 (single line, truncate) |
| Label (issue key mono, time, bucket headers, counts, state pill) | 11px | 400 (500 for bucket header) | 1.5 |
| Heading (popover title "Notifications", empty-state heading) | 14px | 500 | 1.2 |
| Display | not used in this phase | -- | -- |

Weights: 400 regular + 500 medium only (no semibold, no bold). Unread = weight 500 + `text-foreground`; read = weight 400 + `text-muted-foreground`. Issue keys use `font-mono` at 11px. Bucket headers are uppercase-free sentence case. If any italic text is used with `truncate`, add `pr-0.5`.

## Color

Neutral base-nova tokens from `src/index.css`; no new tokens.

| Role | Value | Usage |
|------|-------|-------|
| Dominant (60%) | `--background` (popover bg; oklch(1 0 0) light / oklch(0.145 0 0) dark) | Popover surface, rows at rest |
| Secondary (30%) | `--muted` / `--accent` (oklch(0.97 0 0) / 0.269) | Hover row (`hover:bg-accent`), count chips, group-header hover, banner bg |
| Accent (10%) | `--primary` (neutral, oklch(0.205 0 0) / 0.922) | See reserved list |
| Destructive | `--destructive` (oklch(0.577 0.245 27.325)) | Pipeline-failure glyph only |

Accent reserved for: (1) the unread dot (`bg-primary`), (2) the active segment of the Unread|All control and the active source tab underline/indicator, (3) focus ring on keyboard-focused row (`ring-ring`). Nothing else uses accent.

Semantic status colour (the only colour in the feed, "colour = status only", D3):
- pipeline-failure: type glyph `text-destructive`
- mr-approval: type glyph green (existing success/status green token from `lib/statusStyles.ts`, reuse; do not invent)
- due-date-reminder: type glyph amber (existing warning token)
- Entity state (Open / Merged / Closed) shown as a small `statusPillClass` pill **only on group headers**, wrapped in a flex parent (pill needs flex parent).

Everything else is neutral: the 9 per-type rainbow badges, orange/purple source left borders, blue unread tint and avatar unread ring are all removed. Source (Jira vs GitLab) = small neutral muted glyph in the type-glyph slot's tooltip and the source tab only; no coloured border. Tab count chips: `bg-muted text-muted-foreground`, never coloured. Peeked row/group: `PEEKED_ROW_CLASS` last in `cn()` (focus-within bg beats tint). Unread rows have no background tint, so peek highlight never competes.

## Layout and Interaction Contract

### Popover structure (top to bottom)
1. **Header** (px 16, h 40): title "Notifications" (Heading), right side: `Mark all read` (ghost sm button, scoped to active tab/filter, disabled when 0 unread) and an overflow icon button (lucide `MoreHorizontal`, 28px) containing `Clear read` and `Notification settings`. Sibling controls share one button style (match local row).
2. **Filter bar** (h 36, px 16, border-b): segmented `Unread | All` on the left (AIO-cycles pattern, not Switch), source tabs `All sources | Jira | GitLab` on the right with neutral count chips (unread count per source; hidden when 0).
3. **Banners** (conditional, above list): permission-denied and send-error use `Alert`; fetch error with cached items uses `StaleDataBanner` ("Couldn't refresh - showing cached data", Retry, dismiss). Error with zero items uses `ErrorState`.
4. **List** (scroller `relative overflow-y-auto`, `role="listbox"`-free: plain list with roving focus on overlay buttons).

### Time buckets (D5)
`Today / Yesterday / This week / Older` (replaces "Earlier"). Bucket header is a non-interactive 11px/500 muted label, not promised sticky (virtual branch cannot stick). Bucket "now" comes from a ticking `useNow(60_000)` state passed into pure helpers.

### Entity grouping (D5, NOTIF-02)
- Events on same entity (`getEntityKey`: Jira key, GitLab `project/iid`) are grouped inside a bucket, group ordered by newest event.
- Single-event entity renders as a plain event row (no header).
- Multi-event group: one-line header `[chevron 16][avatar 20 of newest author][KEY mono 11][title truncate flex-1 min-w-0][+N chip][state pill, GitLab/Jira entity state][time]`, then child event rows indented 24px. Groups containing unread are expanded by default; others collapsed. Chevron rotates; no height animation (virtualizer safety).
- Group tooltip (TooltipBody, max 4 rows): full title, parent story summary (if any), event count, newest absolute time.

### Event row (one line, NOTIF-01/03)
`[unread dot 8][type glyph 16][avatar 20][KEY mono 11 (Jira/MR ref, flex-none)][text flex-1 min-w-0 truncate][time 48, right]`
- `text` = short action + snippet in one string (e.g. "commented: ..."), single-line truncate. Full body, parent summary and absolute timestamp only in hover `TooltipBody` (<=4 rows, ~600ms delay). Nothing stacks; narrower widths truncate `text` first, then hide the key, never the avatar or dot.
- Whole row click = overlay button (`absolute inset-0`) that marks read and opens the item via the existing handlers (D9: preserve current effective behaviour, full-page navigation via `onIssueClick`/`onMRClick`; peek wiring is a planner/UAT confirmation, not assumed). Key is a sibling `relative z-10` button (opens issue), tray buttons `relative z-10`; text/glyph cells `pointer-events-none relative`. No `div[role=button]` with nested button.
- Same stateful row component for read and unread; only classes vary (no remount on mark-read).
- Hover/focus tray (absolute over the time cell, `opacity-0 group-hover:opacity-100 group-focus-within:opacity-100`): Mark read/unread (`Circle`/`CircleDot`... use `Mail`/`MailOpen`), Open in browser (`ExternalLink`, wrapped in `LinkContextMenu`), Done (`Check`). Tooltips: "Mark as read", "Mark as unread", "Open in browser", "Done".

### Type glyphs (neutral `text-muted-foreground`, 16px lucide)
comment-mention/jira-comment `MessageSquare`; gitlab-mention/mr-note `MessageSquare` (distinguished by source tooltip); issue-update `RefreshCw`; issue-assignment `UserPlus`; mr-approval `CheckCircle2` (green); pipeline-failure `XCircle` (destructive); due-date-reminder `CalendarClock` (amber). Executor may swap icon names to the closest lucide equivalent but must keep neutral-except-three.

### Keyboard (popover-scoped, D7, NOTIF-05)
Up/Down and j/k move focus between entries (call `virtualizer.scrollToIndex` for off-screen), Enter/Space activates, Right/Left expand/collapse a focused group, `u` toggles read, `e` or Delete dismisses (Done) then focuses the next entry, Esc closes (Base UI). Ignored when target is input/textarea. Focus ring visible (`focus-visible:ring-2 ring-ring`, inset). Hover tray also revealed on focus. Bell badge unchanged (unread count, 99+ cap, pulse only on increase, none while open).

### Density
`density-compact:` and `density-comfortable:` change only row height/padding and font size (12/11 compact, 12/11 default, 12/11 comfortable with taller rows per table above). Never add or remove lines.

## Copywriting Contract

| Element | Copy |
|---------|------|
| Primary CTA | Mark all read |
| Secondary actions | Clear read; Notification settings |
| Row action tooltips | Mark as read / Mark as unread / Open in browser / Done |
| Segmented filter | Unread / All |
| Source tabs | All sources / Jira / GitLab |
| Empty (no notifications ever) | Heading: "No notifications yet". Body: "Activity on your Jira issues and GitLab merge requests will show up here." Action: "Notification settings" |
| Empty (Unread filter, all read) | Heading: "All caught up". Body: "You have no unread notifications." |
| Empty (source tab filtered) | Heading: "Nothing from {Jira/GitLab}". Body: "No notifications from this source." |
| Error, no cache | Heading: "Couldn't load notifications". Body: "Check your Jira and GitLab connection, then try again." Action: "Retry" |
| Error, cached items | StaleDataBanner: "Couldn't refresh - showing cached data" + Retry |
| Permission denied | Alert: "System notifications are blocked. Enable them in System Settings to get alerts outside the app." |
| Destructive confirmation | Done (dismiss one): no confirmation, immediate, row removed. Clear read: no modal; immediate action in overflow menu labelled "Clear read" with tooltip "Remove all read notifications"; Mark all read: no confirmation (reversible per row). No undo/toast (none exists). |
| Group count chip | "+{N}" (hover: "{N} more updates") |

Sentence case throughout, no jargon, no emojis.
