## Interaction States

### AIO toggle off (default)
- Picker block hidden
- Continue always enabled

### AIO toggle on + loading
- `<Loader2 className="h-4 w-4 animate-spin" />` + "Loading projects…" inline
- Continue disabled (D-02)

### AIO toggle on + error
- `<XCircle className="h-4 w-4" />` + "Couldn't load AIO projects." + underlined "Retry" button inline
- Continue disabled (D-03)
- `role="alert"` on error container

### AIO toggle on + loaded, empty list
- Disabled `<Select>` trigger showing "No AIO projects available" muted text
- Continue disabled (D-04)

### AIO toggle on + loaded, project selected
- Select showing project name
- Continue enabled

### AIO toggle on + stale persisted key
- Picker renders normally (project selected from list if available)
- Stale warning below picker: `<p className="text-xs text-destructive">Previously selected project "{key}" is no longer available. Pick another or clear the selection.</p>`
- Continue disabled until a valid project is selected

### Tempo toggle
- Standalone toggle; no conditional sub-elements
- No effect on Continue gating
