## Spacing Scale

Declared values (multiples of 4):

| Token | Value | Usage |
|-------|-------|-------|
| xs | 4px | Icon-to-label gaps, chip internal padding, inline spacing |
| sm | 8px | Row internal padding, badge horizontal padding, button gaps |
| md | 16px | Form field vertical rhythm, section padding, modal body padding |
| lg | 24px | Between logical groups within a section, modal header/footer padding |
| xl | 32px | Between major sections in the Settings template editor |
| 2xl | 48px | — |
| 3xl | 64px | — |

Exceptions:
- Touch targets on icon-only row controls (drag handle, delete, expand): minimum 32px hit area via `p-1` or `size-8` class.
- Progress bar in bulk modal: full width, no horizontal margin (matches `BulkProgressIndicator` pattern — `w-full`).

Source: inherited from project-wide 8-point scale; `WorkflowSection.tsx` uses `gap-4`, `gap-8`; `BulkProgressIndicator.tsx` uses `gap-2`; `CreateEditIssueModal.tsx` uses `px-6 py-4`.

## Component Inventory

### 1. Settings — Subtask Templates Section (`SubtaskTemplatesSection.tsx`)

**Entry point:** New section in `Settings.tsx` SECTIONS array — id `'subtask-templates'`, label `"Subtask Templates"`, icon `<LayoutTemplate className="h-4 w-4" />`.

**Layout:** Mirrors `WorkflowSection.tsx` outer shell:
```
<div className="flex flex-col gap-8">
  <h2 className="text-lg font-semibold">Subtask Templates</h2>
  {/* template list area */}
</div>
```

**Template list:**
- Each template: a card-like row `flex items-center gap-2 rounded-lg border bg-background px-3 py-2`
- Drag handle (left): `GripVertical` icon, `text-muted-foreground`, cursor-grab
- Template name: editable inline via `<input>` with `border-none bg-transparent text-sm font-medium focus:outline-none focus:ring-1 focus:ring-ring rounded px-1`
- Right side controls: `"Edit"` text button (opens template row editor below) + `Trash2` icon button in `text-destructive hover:text-destructive` — both `variant="ghost" size="icon-sm"`
- Reorder via dnd-kit (matches project dnd pattern from P78/P79); uses `@dnd-kit/core` + `@dnd-kit/sortable`

**Template row editor (inline expand below template):**
- `flex flex-col gap-4 rounded-lg border bg-muted/30 px-4 py-4 mt-1`
- Subsection header: `text-xs font-semibold text-muted-foreground uppercase tracking-wide` — "ROWS"
- Each row: see Row Component spec below
- Footer: `"+ Add row"` button, `variant="ghost"` with `Plus` icon, left-aligned

**Empty state — no templates yet (Claude's Discretion — resolved here):**
- Heading: `"No templates yet"`
- Body: `"Create a template to bulk-add subtasks from any issue."`
- CTA: `"New Template"` button, `variant="outline"`, `Plus` icon left
- Layout: `flex flex-col items-center gap-3 py-12 text-center`

**Add new template:** `"New Template"` button above the list, `variant="outline"`, `size="sm"`, right-aligned. Creates a blank template row in edit mode with placeholder name `"Untitled Template"`.

### 2. Shared Row Component (`SubtaskTemplateRow.tsx`)

Used in both the Settings template editor and the bulk modal preview table. Satisfies D-07 (curated core inline + Advanced expand).

**Inline core fields (always visible, left-to-right):**
1. **Title** (required) — `<Input placeholder="Subtask title" className="flex-1 min-w-0" />` — fills available width
2. **Assignee** — compact selector; shows placeholder chip if `@inherit` / `@current` / `@unassigned`; otherwise shows resolved display name. `w-32` minimum.
3. **Priority** — icon+label select. `w-28`.
4. **Labels** — tag-style multi-select badge. `w-32`.
5. **Due Date** — date input. `w-32`.
6. **Estimate** — text input `"e.g. 2h"`. `w-20`.
7. **Story Points** — number input. `w-16`.
8. **Advanced toggle** — `ChevronRight` / `ChevronDown` icon button, `variant="ghost" size="icon-sm"`, `aria-expanded`, right of inline fields.
9. **Remove row** — `X` icon button, `variant="ghost" size="icon-sm"`, `text-muted-foreground hover:text-destructive`, far right.

**Row layout:** `flex items-center gap-2 min-h-[44px] px-2 py-1 rounded-md hover:bg-muted/50`

**Advanced expand (below row, collapsed by default):**
- `flex flex-col gap-3 pl-4 pt-2 pb-3 rounded-b-md bg-muted/30 border-l-2 border-border`
- Contains: Components multi-select + all custom fields from createmeta, rendered using `CustomFieldsSection` pattern
- Subsection label: `"Advanced fields"` in `text-xs font-semibold text-muted-foreground uppercase tracking-wide`

**In bulk modal only — additional per-row state indicators:**
- Pending: no indicator (normal row)
- Creating: `Loader2` spin icon, `text-muted-foreground`, far right replaces remove button; row opacity `opacity-70`
- Created: `CheckCircle2` icon, `text-green-600 dark:text-green-400`, far right
- Failed: `AlertCircle` icon, `text-destructive`, far right + row background `bg-destructive/5`

### 3. Bulk Create Subtasks Modal (`BulkCreateSubtasksModal.tsx`)

**Trigger:** "Bulk Create Subtasks" button in `IssueDetailContent.tsx` subtask section, alongside the existing "Add subtask" button. Uses `variant="outline" size="sm"` with `LayoutList` icon.

**Modal shell:** `@base-ui/react/dialog` — direct usage of `Dialog.Root` / `Dialog.Portal` / `Dialog.Backdrop` / `Dialog.Popup` (matches `CreateEditIssueModal.tsx` pattern — NOT `dialog.tsx` wrapper components).

**Popup dimensions:**
```
className="fixed left-1/2 top-1/2 z-50 -translate-x-1/2 -translate-y-1/2
           w-[860px] max-h-[88vh] overflow-y-auto
           bg-background border rounded-lg shadow-xl flex flex-col"
```
Wider than CreateEditIssueModal (860px vs 680px) to accommodate the multi-field row table.

**Header:**
```
<div className="flex items-center justify-between border-b px-6 py-4">
  <div className="flex flex-col gap-0.5">
    <h2 className="text-lg font-semibold">Bulk Create Subtasks</h2>
    <p className="text-xs text-muted-foreground">Parent: {parentKey}</p>
  </div>
  <!-- close button -->
</div>
```

**Toolbar (below header, above row list):**
```
<div className="flex items-center gap-3 px-6 py-3 border-b bg-muted/30">
  <!-- Template selector (left) -->
  <!-- Subtask type selector (center-left) -->
  <!-- Spacer -->
  <!-- "N fields skipped" badge (right, shown only when applicable) -->
</div>
```
- Template selector: `<Select>` — `"No template (ad-hoc)"` as first option, then template names. `w-48`.
- Subtask type selector: `<Select>` — lists `subtaskIssueTypes()` for current project. `w-40`.

**Row list area:**
```
<div className="flex flex-col gap-1 px-6 py-4 flex-1 min-h-0">
  {rows.map(row => <SubtaskTemplateRow ... />)}
  <!-- Add row button -->
</div>
```

**Ad-hoc empty state (Claude's Discretion — resolved here):**
When no template is selected and no rows exist yet:
- Shown inline in the row list area, above the "Add row" button
- Copy: `"Add rows below, or choose a template above to pre-fill."` — `text-sm text-muted-foreground text-center py-6`
- No illustration; no heading.

**Footer:**
```
<div className="-mx-0 flex items-center justify-between gap-2 border-t bg-muted/50 px-6 py-4 rounded-b-lg">
  <!-- Progress indicator (left, hidden until creating) -->
  <!-- Cancel + Create Subtasks buttons (right) -->
</div>
```
- Progress indicator: reuses `BulkProgressIndicator` component (`total`, `completed`, `succeeded`, `failed`, `failures`, `isComplete`, `onDismiss` props). Positioned `flex-1` left of the button group.
- "Create Subtasks" button: `variant="default"` (primary), disabled when `rows.length === 0` or `creating`.
- During creation: button becomes `disabled`, label stays `"Create Subtasks"` (progress bar conveys state).
- After partial failure: `"Retry Failed"` button replaces "Create Subtasks" — `variant="outline"`.
- After all success: footer auto-dismisses after 3s (inherited from `BulkProgressIndicator` behavior); modal can also be closed manually.

## Interaction Contracts

### Settings Template Editor

| Interaction | Behavior |
|-------------|----------|
| Click "New Template" | Appends a new template entry with name `"Untitled Template"`, immediately focused for rename |
| Click template name | Puts name field into edit mode (`border border-input` ring appears) |
| Blur template name (non-empty) | Saves name to store |
| Blur template name (empty) | Restores previous name |
| Click "Edit" on template | Expands the inline row editor below that template entry; collapses any other open editor |
| Drag template row | dnd-kit sortable; live reorder; persist to store on drop |
| Click Trash2 on template | Immediately removes template from store; no confirmation dialog |
| Click "+ Add row" | Appends a blank row with assignee defaulted to `@inherit` chip (D-10) |
| Click Advanced toggle on row | Expands advanced fields panel below that row; `ChevronDown` icon |
| Click X on row | Removes that row from template |
| Edit title field | Required — empty titles show `border-destructive` ring; Save Template disabled |

### Bulk Create Modal

| Interaction | Behavior |
|-------------|----------|
| Open modal | Loads createmeta for current project's first subtask type; if a template was previously used, no auto-apply — user must select |
| Select template from dropdown | Replaces current rows with template rows resolved against active project createmeta; shows "N fields skipped" badge if any fields were dropped |
| Switch subtask type | Re-resolves visible fields for all rows; may trigger new "fields skipped" count |
| Edit row inline field | Updates that row's data model; does not affect the source template |
| Click placeholder chip | Opens a dropdown/popover to override with a concrete value; original placeholder is replaced in that row's data only |
| Reorder rows | dnd-kit sortable (same as Settings editor) |
| Click "+ Add row" | Appends blank row; assignee defaults to `@inherit` |
| Click "Create Subtasks" | Begins sequential `createIssue()` loop; progress bar appears; CTA disables; per-row status icons update |
| Row succeeds | Row shows `CheckCircle2` green icon; `completed++`, `succeeded++` |
| Row fails | Row shows `AlertCircle` red icon + red background tint; `completed++`, `failed++`; failure added to list |
| All rows done, 0 failures | Progress bar shows 100%; status text green; auto-dismiss after 3s; modal can be closed |
| All rows done, some failures | "Retry Failed" button appears; details expandable via "View Details"; footer stays open |
| Click "Retry Failed" | Re-runs only failed rows (rows with `status !== 'created'`); resets failed rows to pending |
| Close modal during creation | Disabled — close button hidden/disabled while `creating === true` |
| Escape key | Closes modal when not creating |

## Accessibility

| Requirement | Implementation |
|-------------|---------------|
| Row drag handles | `aria-label="Drag to reorder"` + `role="button"` |
| Progress updates | `aria-live="polite"` on status text (matches `BulkProgressIndicator.tsx` L63) |
| Per-row status icons | `aria-label="Created"` / `aria-label="Failed"` with `role="img"` |
| Advanced toggle | `aria-expanded={open}` + `aria-controls="{row-id}-advanced"` |
| Placeholder chips | `aria-label="@inherit placeholder, resolved to {value}"` |
| "N fields skipped" badge | `role="status"` |
| Modal focus trap | `@base-ui/react/dialog` handles focus management automatically |
| Delete template | `aria-label="Delete template {name}"` on Trash2 button |
| Keyboard shortcut | Enter on title field submits template name; Tab moves to next field |
