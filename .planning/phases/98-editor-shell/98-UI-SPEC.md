# Phase 98 — UI Design Contract

> Visual and interaction contract for the shared `<WikiEditor>` and its dev-tools "Editor" tab. Generated by gsd-ui-researcher, verified by gsd-ui-checker.
> Sources: CONTEXT.md D-01..D-10 and Claude's Discretion defaults (locked unless stated), existing code (`index.css`, `components.json`, `WikiRenderer.tsx`, `DescriptionEditor.tsx`). No user questions were needed.

| Property | Value |

## Spacing Scale

| Token | Value | Usage |
|-------|-------|-------|
| xs | 4px | Gap between toolbar buttons, icon-to-label gap |
| sm | 8px | Toolbar horizontal padding, group separators margin, chip padding |
| md | 16px | Content area padding (default density), split-pane gutter |
| lg | 24px | Dev-tools tab section gaps |
| xl | 32px | Skeleton/min-height steps |
| 2xl | 48px | Not used in this phase |
| 3xl | 64px | Not used in this phase |

Component sizing:
- Toolbar height 40px; icon buttons 28px square (ghost, `size="icon-sm"` equivalent), 4px gap, 1px vertical `border` separators between groups.
- Content min-height: `full` 160px, `compact` 96px. Max-height before internal scroll: `full` 480px, `compact` 280px (the frame scrolls under the sticky toolbar). Dev-tools tab may override to 640px.
- Source split: textarea and preview each min 240px; below 560px frame width, preview auto-hides (stacks is NOT used; hidden with the toggle still reachable).
- Table grid picker cells 20px with 4px gap (up to 6x6). Panel corner control 28px.
- Frame radius `rounded-lg` (token `--radius`), 1px `border-input`; focus-within shows `ring-1 ring-ring`.

Exceptions: 1px hairlines/borders; 20px grid-picker cells and 28px/40px control sizes are multiples of 4. Container query breakpoints are in the Layout section, not spacing.

## Typography

Rich view shares WikiRenderer prose classes (`prose prose-sm dark:prose-invert`, same density-tier margins) so the editor looks identical to rendered output (EDIT-01). Do not fork prose styles; extract and import them.

| Role | Size | Weight | Line Height |
|------|------|--------|-------------|
| Body (prose, textarea, preview) | 14px | 400 | 1.5 (prose-sm renders ~1.7 for paragraphs; keep the WikiRenderer value for parity) |
| Label (toolbar labels, notices, panel titles, tooltips, chips, dev-tools captions) | 12px | 400 (600 for panel title and active segmented item) | 1.5 |
| Heading (H3-H6 and dev-tools section heads) | 16px | 600 | 1.2 |
| Display (H1/H2 as rendered by prose-sm) | 20px | 600 | 1.2 |

Two weights only: 400 and 600. Source textarea: `font-mono text-sm` (14px). Code blocks: `font-mono` 12px per `prose-code` in WikiRenderer. Heading sizes inside the document follow prose-sm scale; the table above is the contract for chrome and dev tools.

## Color

Neutral base-nova tokens only; the app has no brand accent hue in this surface.

| Role | Value | Usage |
|------|-------|-------|
| Dominant (60%) | `--background` (oklch 0.985/white light; 0.145 dark) | Editor content area, source textarea |
| Secondary (30%) | `--muted` / `bg-muted/30-40` | Toolbar background, panel headers, raw-atom frame fill, chips, preview pane header |
| Accent (10%) | `--primary` / `--ring` (neutral) | See list below |
| Destructive | `--destructive` | Save-failed inline error text, "Remove panel", "Delete table" only |

Accent reserved for: focus ring on the frame and toolbar buttons; active/pressed state of mark buttons and the selected "Rich | Source" segment; selected swatch ring in the colour popover; table selected-cell outline; node-selection outline on raw atoms and panels. Never for hover backgrounds (use `accent`/`muted`).

Semantic colours that are content, not chrome:
- Panel family keeps WikiRenderer panel colours (panel/info/note/warning/tip), no new colours.
- `{color}` palette: Jira standard text palette (swatch popover, 3 rows of ~8 + "Remove colour"). Swatches are content colours; each swatch needs a 1px `border` and an `aria-label` of its name. Off-palette existing colours render as-is and appear in the popover as a single "Custom (kept)" swatch that is selected and not editable. All values pass the Phase 97 CSS-injection guard before being applied.
- SAFE-05 notice and demoted notice: `text-muted-foreground`, never amber/red.
- Raw-atom frame: `border border-dashed border-border`, `bg-muted/30` (matches existing dashed chip in DescriptionEditor).

## Component & Interaction Contract

### Frame and layout (D-01, D-02, EDIT-09)
- Single bordered frame; order top to bottom: sticky toolbar, optional one-line notice, content area. Same frame in rich and source modes; toolbar and mode toggle stay put, only content switches.
- Sticky scroller must be `relative` (sr-only escape gotcha); all overlays (colour, link, insert, text-style, table toolbar, language select) portal to `body` (isolate `<main>`).
- Lazy chunk with `Skeleton` frame of identical dimensions (toolbar 40px + min-height content), no layout jump when the editor mounts.
- Container-query collapse (frame is the `@container`; styles go on an inner wrapper, never the container itself):
  - `full`: below `@[640px]` move to overflow, in this order: sub/superscript, strikethrough, monospace, quote, rule, colour, link.
  - `compact`: below `@[420px]` move to overflow: strikethrough, monospace, then lists.
  - Always visible: text-style (full only), bold, italic, "+ Insert", "⋯", Rich|Source toggle. Preview toggle visible only in source mode and collapses into the textarea header at narrow widths.
  - One row at every width; never wrap.

### Toolbar contents (D-03, EDIT-04/05/06)
- `full`: Normal text ▾ | Bold, Italic, Underline, Strikethrough, Monospace, Sub/Superscript, Colour ▾ | Bullet list, Numbered list, Quote | Link | + Insert ▾ | ⋯ | (right) Rich|Source.
- `compact`: Bold, Italic, Underline, Strikethrough, Monospace | Bullet, Numbered | Link | + Insert ▾ | ⋯ | (right) Rich|Source. No text-style dropdown, no colour, no sub/sup (kept in overflow if Claude chooses).
- Text-style dropdown items: Paragraph, Heading 1..6, Quote. Trigger shows the current style (label 12px).
- "+ Insert" items (data-driven list exported for Phase 99 slash menu): Table (opens 6x6 grid picker, header row on), Code block, Noformat, Panel, Info, Note, Warning, Tip, Horizontal rule. Each item: lucide icon + label.
- Icon buttons: lucide icons 16px, ghost variant, `aria-label` and `aria-pressed` for marks; tooltips "Label ⌘K" with keycaps via `tooltip-body` (open delay matches existing app tooltips).
- Disabled buttons (e.g. no selection for link, source mode marks) use `disabled` + 50% opacity; in source mode, rich-only controls are hidden except Insert (inserts canonical wiki text at the cursor via the existing `insertAtCursor` forms), marks (wrap selection), and link.

### Mode toggle (D-06, D-07, D-09)
- Right-aligned segmented control "Rich | Source" (compact preset may use a single icon toggle if the row cannot fit). Shortcut ⌘⇧M, registered in `src/lib/shortcuts.ts`.
- Selection persists globally in settings store (default rich). A forced-source text does not change the saved preference.
- Forced source (round-trip failed): "Rich" segment disabled with tooltip "This text uses formatting the rich editor can't keep safely." Notice line sits under the toolbar: 12px muted, single line, truncates with full text in `title`. No dismiss, no "try rich anyway".
- Switching source to rich is one undo step; rich history is preserved (EDIT-08). Source mode keeps native textarea undo.

### Source mode (D-05, EDIT-02/03)
- Left: textarea `font-mono text-sm`, no resize handle (frame autosizes within min/max). Right: live WikiRenderer preview in the same prose styles, with a 12px muted pane label "Preview". Divider 1px `border`.
- Hide/show preview via a toolbar icon button (PanelRight icon) with tooltip "Hide preview"/"Show preview"; state is remembered in component state only.
- Empty preview: "Nothing to preview" (12px muted) matching current DescriptionEditor copy.

### Rich blocks (BLOCK-01..04)
- Table: floating toolbar (portaled, anchored above the table) shown while the caret is in a table. Buttons: Add row above/below, Add column left/right, Delete row, Delete column, Toggle header row, Toggle header column, Delete table (destructive text, last, separated). Tab/Shift+Tab move cells; Tab in last cell adds a row. Header-less tables remain header-less (Phase 97 attribute). No hover handles.
- Panel: renders like WikiRenderer panel; header line holds editable title (12px, 600, placeholder "Title (optional)") and a 28px corner control opening a menu: Panel, Info, Note, Warning, Tip (radio, check leading), separator, "Remove panel" (destructive). Body is editable.
- Code block: header strip (muted, 28px high) with language SearchableSelect (Jira languages + "None") at left; `{noformat}` shows the label "Noformat" with no select. Mono 12px, no wrapping, horizontal scroll.
- Colour: swatch popover (see Color). Applying to a selection only; the colour button shows the current colour as a 12px underline bar.
- Link: popover (not inline) with URL input + "Apply"; opens on Cmd+K or the toolbar button; pasting a URL over a selection links it directly (EDIT-06). Existing link: popover shows URL, "Open", "Remove link".
- Raw atoms (block): WikiRenderer output, read-only, dashed frame, hover-reveal "Edit in source" 12px ghost button top-right (switches to source mode and keeps scroll/block position). Inline raw atoms: quiet chip (`rounded bg-muted/40 px-1 text-xs`). Both selectable and deletable as a unit (Backspace/Delete on node selection). Demoted loads: frames only, no banner.
- Placeholder (empty doc): "Write a description…" in `full`, "Add a comment…" in `compact`; 14px muted.
- Input rules: `*bold*`, `_italic_`, `-`/`*` list, `#` list, `h1.`..`h6.`, `{code}`, markdown equivalents; none fire during IME composition.

### Keyboard (EDIT-04, FLOW-04)
Registered in `src/lib/shortcuts.ts` for the ⌘/ panel: Bold ⌘B, Italic ⌘I, Underline ⌘U, Strikethrough ⌘⇧X, Monospace ⌘E, Link ⌘K, Bullet list ⌘⇧8, Numbered list ⌘⇧7, Quote ⌘⇧B, Toggle source ⌘⇧M, Undo ⌘Z, Redo ⌘⇧Z. Global hotkeys and raw `keydown` listeners (`main.tsx`, `useImageViewer.ts`, `usePreviewEscape.ts`, `AioTestRunDetailPage.tsx`, `AttachmentPreviewModal.tsx`) ignore events whose target is contenteditable.

### Save-failed state (D-08)
- Rich doc is kept; nothing is written. Inline error under the toolbar (replaces notice slot, same height-neutral line): `text-destructive` 12px, "Couldn't save safely: {engine reason}." plus a ghost xs button "Fix in source" that switches mode. Source mode text is decided during planning (last safe emit, or original plus a note); never drops the user's edit.

### Dev-tools "Editor" tab (D-10)
- New tab in `DevToolsPage.tsx` (gated by `devToolsEnabled`), same tab styling as Logs/Operations/Waterfall/Notifications.
- Layout: left column controls, right column editor frame, below it the verdict panel. Control row: fixture picker (SearchableSelect: Blank doc + Phase 96/97 corpus, placeholder-only), preset switcher (Full | Compact, segmented), width switcher (Narrow 360px | Wide 100%, segmented), "Paste wiki" textarea with "Load" button (local only; caption "Local only. Never saved.").
- Verdict panel: `loadWiki` kind as a small pill (rich / rich-demoted / failed) with demoted block indexes shown as numbered chips; `saveWiki` kind pill (unchanged / saved / failed) and a mono read-only output block (12px, max-height 240px, scroll). Pill colours: neutral muted for rich/unchanged, `--primary` outline for saved/rich-demoted, destructive for failed. Show rendered previews where possible (WikiRenderer of the emitted output beside the raw text) rather than raw JSON.
- No card panels; plain headings (16px, 600) with 1px dividers.

## Copywriting Contract

| Element | Copy |
|---------|------|
| Primary CTA | "Insert" (toolbar menu label "+ Insert"); dev tab: "Load" |
| Empty state (editor placeholder) | "Write a description…" / "Add a comment…" |
| Empty state (preview pane) | "Nothing to preview" |
| Empty state (dev tab, no fixture chosen) | Heading "No document loaded", body "Pick a fixture or paste wiki text to start." (compact `EmptyState`) |
| Forced-source notice | "This text uses formatting the rich editor can't keep safely, so it opens in source." |
| Rich segment disabled tooltip | "This text can't be edited in rich view without risking its formatting." |
| Save failed error | "Couldn't save safely: {reason}." + action "Fix in source" |
| Raw-block affordance | "Edit in source" |
| Lazy load failure | "The editor couldn't load. Reload the page to try again." |
| Destructive actions | Delete table, Remove panel, delete raw atom: no confirm dialog (single undo step restores via ⌘Z); tooltips "Delete table", "Remove panel". Nothing in this phase is irreversible. |

Tooltips: "Bold ⌘B", "Italic ⌘I", "Underline ⌘U", "Strikethrough ⌘⇧X", "Monospace ⌘E", "Link ⌘K", "Bullet list", "Numbered list", "Quote", "Text colour", "Insert", "More", "Switch to source ⌘⇧M" / "Switch to rich ⌘⇧M", "Hide preview"/"Show preview".
