**Decision for user review (RESEARCH A1, D-08):** after `saveWiki` returns `failed`, switching to source shows a best-effort unchecked `emitWiki(doc)` of the user's edit, with the engine reason in the error line, and that text becomes the value (in source mode the textarea is the value). </objective>
