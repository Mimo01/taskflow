New contracts:

`lib/release-timeline.ts`:
- `timelineWeeks(widthPx: number): number`: `clamp(floor(w / 115), 3, 8)`
- `addDaysKey(key, n): string`, using UTC arithmetic
- `timelineWindow({ today, weeks, earliestOverdue, offset }): { start: string; end: string }`
  - `base = weeks <= 5 ? addDaysKey(min(earliestOverdue ?? today, today), -3) : addDaysKey(today, -21)`
  - `start = addDaysKey(base, offset * 7 * Math.max(1, weeks - 2))`
  - `end = addDaysKey(start, weeks * 7 + 2)`
- `timelinePercent(key, win): number`: `daysBetweenKeys(start, key) / daysBetweenKeys(start, end) * 100`
- `timelineReleases(versions): JiraFixVersion[]`: dated unreleased versions plus the single most recent released version, sorted by date ascending
- `laterCount(versions, win): number`: dated releases with date > end
- `placeTickRows(items: { id: string; x: number; label: string }[]): Map<string, 0 | 1 | null>`
  - label width = `label.length * 6.2`
  - row 0 if `x - w/2 > lastEnd0`, else row 1 if `x - w/2 > lastEnd1`, else null (hidden)
  - `lastEnd = x + w/2 + 4`
  - process items in x order
- `placeChipLanes(items: { id: string; x: number }[], nextId: string | null): Map<string, 0 | 1 | 2>`
  - chip width 104 for next, 98 for others, padding 2px each side
  - interval lanes `[[], [], []]`
  - the next item is placed first, the rest in x order
  - first lane with no overlap wins; fallback is lane 0
- `CHIP_LANE_TOP = [4, 86, 45] as const` (px), taken from the sketch `drawTrack`
- `chipStatus(b: StatusBreakdown | undefined, released: boolean): string | null`
  - released → '✓ done'
  - no b → null (loading)
  - total 0 → 'No issues'
  - started (done + indeterminate > 0) → `${done}/${total} done`
  - otherwise → `${total} to do`
- `chipShortName(name)`: text after the first ' - ' (trimmed), else the full name
- `formatRange(win, later)`: `'08 Oct – 05 Dec'` plus `' · +N later'` when later > 0. Dates use en-GB `{ day: '2-digit', month: 'short', timeZone: 'UTC' }`, with Sept replaced by Sep.
- `tickLabel(key)`: `'Tue 03 Nov'` (UTC formatting)

`releases-list/ReleaseTimeline.tsx`:

- `versions` is the full fix-version list. The component derives its own set via `timelineReleases`.
