- **Task 2:** Rewrote the single PROJECT.md Key Decisions row that recorded "EpicsPage uses fetchEpicsBasic — enrichment too slow for list view" as current. It now records "EpicsPage renders fetchEpicsBasic first, then merges fetchEpicEnrichmentMap progressively," with the rationale noting Phase 91.2 (roadmap D-04) accepted one batched JQL for all epics (not N per-epic queries) on the condition it never blocks first paint, and the outcome column marking it as superseding the earlier decision (Phase 91.2). One-row diff (1 insertion / 1 deletion), no other table changes.
- **Task 3 (human-verify checkpoint):** A human ran `npm run tauri dev` and verified the real Tauri/WebKit webview at all three densities (compact, default, comfortable). **Result: approved.** No zero-width columns at any density (EPIC-02, ROADMAP criterion 8); every epic stayed on exactly one line (D-07); row click still opened `EpicDetailSheet` and no search UI exists anywhere on the page (EPIC-07, D-18); the D-09 tinted-badge colour treatment was confirmed to read as modern and keep epic identity legible next to the segmented progress bar, compared side by side with Backlog.
  UAT surfaced three issues, all fixed on the main tree during the checkpoint before final approval:
  - Priority sat after the status pill instead of directly after the key cell (Backlog's convention) — reordered in both `EpicRow` and `EpicsSkeleton` to match Backlog's column order and its `flex-none px-0` 18×18 cell shape (`8989a777`).
  - Key and priority icon read as visually touching — priority cell now carries its own `pl-2` instead of relying solely on the key cell's `pr-2`, applied to both the row and the skeleton so nothing shifts when data lands (`96aa9271`).
  - Progress bars took a long time to appear — `fetchEpicEnrichmentMap` was paging through every child story serially at 200/page. Added `fetchAllSearchPagesConcurrent` (page 1 fetched alone to read `total`, remaining offsets fetched in parallel bounded to 6 in flight, fails closed on any page error per D-15), turning N sequential round-trips into `ceil(N/6)` (`cb1eca7d`).
  Final state after all three fixes: `tsc --noEmit` clean, biome clean, full suite 2606 passed / 0 failed.
