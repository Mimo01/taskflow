## Decisions Made

- SVG pipeline worked directly without a PNG intermediate — `tauri icon` CLI supports SVG natively as of Tauri v2. No `sharp` installation needed.
- Explicit `<rect width="1024" height="1024" fill="#0d1117"/>` ensures no transparent background artifact in macOS Dock (transparent areas render black without this).
- Draw order: edges first, then glow ring, then satellite nodes, then center hub — ensures correct z-ordering purely via SVG paint order.
