    - `resolveStatus(id, maps)`: hit → `{ id, name: maps.statuses[id].status.name, statusCategory: { key: <mapped> } }` where mapped uses `maps.statuses[id].status.statusCategory.key` if it equals `'new' | 'indeterminate' | 'done'`, else falls back to `'indeterminate'`; miss → `{ id, name: 'Unknown', statusCategory: { key: 'indeterminate' } }` AND `warnOnce('status', id)`

    - `warnOnce(kind, id)` uses a module-level `Set<string>` keyed by `${kind}:${id}`; second call with the same key is a no-op
    - Test-only export `__resetWarnOnce()` clears the Set (lets tests assert the once-per-session behavior in isolation)
