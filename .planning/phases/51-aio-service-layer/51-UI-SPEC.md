## Component Specification: IntegrationsSection

This is the only new UI component in Phase 51.

### File
`taskflow/src/routes/settings/IntegrationsSection.tsx`

### Structure (mirrors WorkflowSection.tsx exactly)

```
<div data-testid="section-integrations" className="flex flex-col gap-8">
  <h2 className="text-lg font-semibold">Integrations</h2>

  <div className="flex flex-col gap-4">
    <h3 className="text-sm font-semibold text-muted-foreground uppercase tracking-wide">
      AIO Test Management
    </h3>
    <label className="flex items-center justify-between gap-4 cursor-pointer">
      <div>
        <p className="text-sm font-medium">Enable AIO Test Management</p>
        <p className="text-xs text-muted-foreground">
          Show test execution data from AIO TCMS. Requires AIO plugin on your Jira instance.
        </p>
      </div>
      <input
        type="checkbox"
        aria-label="Enable AIO Test Management"
        checked={aioEnabled}
        onChange={(e) => setAioEnabled(e.target.checked)}
        className="h-4 w-4 accent-primary"
      />
    </label>
  </div>
</div>
```

- Add entry to `SECTIONS` array after `'workflow'` (before `'updates'`):
  ```ts
  { id: 'integrations', label: 'Integrations', icon: <Plug className="h-4 w-4" /> }
  ```
- Import `Plug` from `lucide-react` (alongside existing imports).
- Add `{activeSection === 'integrations' && <IntegrationsSection />}` to content area.

## Copywriting Contract

| Element | Copy |
|---------|------|
| Settings nav label | Integrations |
| Section heading | Integrations |
| Subsection label | AIO Test Management |
| Toggle label (primary) | Enable AIO Test Management |
| Toggle description | Show test execution data from AIO TCMS. Requires AIO plugin on your Jira instance. |
| Empty state heading | n/a — no empty state in Phase 51 |
| Empty state body | n/a — no empty state in Phase 51 |
| Error state | n/a — no error state in Phase 51 (toggle is a local store write only) |
| Destructive confirmation | n/a — no destructive actions in Phase 51 |

Copywriting notes:
- "Enable" not "Activate" or "Turn on" — consistent with Tauri app conventions observed in existing Settings sections.
- "Requires AIO plugin on your Jira instance." — sets user expectation that this is not a standalone Taskflow feature, reduces confusion for users without AIO installed.
- No confirmation dialog. Toggling off is not destructive (no data is deleted).

## Interaction States

The checkbox is the only interactive element. Required states:

| State | Visual |
|-------|--------|
| Unchecked (default) | Empty checkbox, `accent-primary` color scheme |
| Checked | Checked checkbox, `accent-primary` fill |
| Focus | Browser default focus ring (respects `outline-ring/50` from `@layer base`) |
| Hover | Parent `<label>` has `cursor-pointer`; no additional hover treatment needed |
| Disabled | Not applicable — toggle is always enabled (store is always writable) |

No loading state, no async side effects. The toggle writes to `useSettingsStore` synchronously.

## Accessibility

| Requirement | Implementation |
|-------------|----------------|
| Label association | Wrapping `<label>` element covers the entire row — clicking anywhere toggles |
| `aria-label` | `aria-label="Enable AIO Test Management"` on the `<input>` (redundant but required by existing pattern) |
| Keyboard | Native checkbox — Space bar toggles, Tab navigates |
| Screen reader | "Enable AIO Test Management, checkbox, checked/unchecked" announced automatically |
