| Zustand persist → Tauri Store | aioEnabled value is serialized as a boolean by the existing persist middleware; no new serialization path |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-51S-01 | Tampering | settings.store.ts version migration | mitigate | Both `version: 15` on persist options AND `if (version < 15)` guard in migrate are required; acceptance criteria explicitly verify both; RESEARCH.md Pitfall 3 documents the exact failure mode |
| T-51S-02 | Information Disclosure | aioEnabled stored in Tauri Store (settings.json) | accept | aioEnabled is a feature flag (boolean); no PII, no secrets; Tauri Store is app-sandboxed and not world-readable |
| T-51S-03 | Tampering | Missing migration guard — existing users get aioEnabled: undefined | mitigate | Acceptance criteria require `if (s.aioEnabled === undefined) s.aioEnabled = false` guard; unit test verifies default value after setState reset (proxy for rehydration) |
| T-51S-04 | Spoofing | aioFetch called with non-PAT credentials | accept | Phase 51 settings plane only; aioFetch is in Plan 03; no new auth path here |
</threat_model>
