## Spacing Scale

Declared values (must be multiples of 4):

| Token | Value | Usage |
|-------|-------|-------|
| xs | 4px | Icon gaps, badge internal padding, chevron-to-label gap in folder tree |
| sm | 8px | Compact element spacing, gap between progress bar segments |
| md | 16px | Default horizontal padding inside table cells, column gaps |
| lg | 24px | Page header horizontal padding (`px-6`), section separators |
| xl | 32px | Left panel / right panel divider region |
| 2xl | 48px | Not used in this phase |
| 3xl | 64px | Not used in this phase |

Exceptions: Folder tree rows use `py-2.5` (10px) vertical padding to match existing accordion row height. Table cell rows use `py-3` (12px) vertical padding. Both are established in the Phase 56 codebase — preserved for visual continuity.

## Layout Contract

### Page shell

The `AioProjectOverviewPage` transitions from `flex flex-col h-full` to `flex flex-row h-full`. The two panels are separated by a 1px `border-r border-border`.

```
┌────────────────────────────────────────────────────────────────┐
│ PAGE HEADER  "Cycles — {projectKey}"          [Show closed ○] │  h-auto px-6 py-4 border-b
├──────────────┬─────────────────────────────────────────────────┤
│              │                                                 │
│  FOLDER TREE │  CYCLE LIST (right panel)                       │
│  (left panel)│  ┌───────────────────────────────────────────┐  │
│  w-64        │  │ thead: Key | Name | Owner | Total | Bar   │  │
│  shrink-0    │  ├───────────────────────────────────────────┤  │
│  overflow-y  │  │ cycle row …                               │  │
│  -auto       │  │ cycle row …                               │  │
│              │  │ cycle row …                               │  │
│              │  └───────────────────────────────────────────┘  │
│              │  (empty state if no cycles in selected folder)  │
└──────────────┴─────────────────────────────────────────────────┘
```

Source: CONTEXT.md D-01, Claude's Discretion (left panel width `w-64`).

### Left panel — Folder tree

- Width: `w-64 shrink-0` (fixed, not resizable — D deferred)
- Background: `bg-muted/10`
- Each folder node is a `<button>` with `w-full text-left px-3 py-2` layout
- Indentation per depth level: `pl-{3 + depth * 4}` (12px base + 16px per level)
- Chevron icon: `ChevronRight size-4 text-muted-foreground`, rotated `rotate-90` when expanded
- Cycle count badge: `<Badge>` with variant `secondary`, displayed inline after folder name — e.g. `"Campaign A (3)"`; use the count map data (D-02)
- Selected folder: `bg-primary text-primary-foreground` on the row button
- Ungrouped entry: shown at bottom of tree with label `"Ungrouped"` when count map key `-1` is non-zero (D-02)
- All folders start collapsed; first root folder auto-expands on load (Claude's Discretion)

### Right panel — Cycle list table

Column layout (from D-06):

| Column | Width | Align | Notes |
|--------|-------|-------|-------|
| Key | `w-28` | left | `font-mono text-xs text-muted-foreground` |
| Name | flex-1 | left | `<NavLink>` with `hover:underline`; `+ <Badge>Closed</Badge>` when `isClosed` and "Show closed" is on |
| Owner | `w-32` | left | display name from Jira user lookup; skeleton while loading; raw ID on 404 |
| Total tests | `w-20` | right | `text-xs text-muted-foreground`; from `summary.totalTests` |
| Progress | `w-44` | left | `h-1.5 rounded-full overflow-hidden flex` bar + `text-xs text-muted-foreground` counts below |

Table header: `bg-muted/10 text-xs font-medium text-muted-foreground`.

### "Show closed" toggle

- Positioned in the right panel header area, right-aligned
- Use a shadcn `<Switch>` with label `"Show closed"` at `text-sm`
- Default: `false` (closed cycles hidden)
- State: `useState<boolean>(false)` in-component (session only — planner picks; simplest is local state)

## Interaction Contract

### Folder tree

| Interaction | Behavior |
|-------------|----------|
| Click folder with children | Toggle expanded/collapsed; show/hide child folders |
| Click leaf folder (no children) | Select folder — loads cycle list in right panel |
| Click folder with children | Also selects that folder — loads its cycles in right panel |
| Auto-select on load | First root folder auto-expands; first leaf or root folder auto-selected |
| Collapse parent of selected | Clears selected folder (right panel shows "Select a folder" empty state) |
| Keyboard: Enter / Space on folder button | Same as click |
| Keyboard: Tab | Moves through all folder buttons in DOM order |

### Cycle list

| Interaction | Behavior |
|-------------|----------|
| Click cycle Name NavLink | Navigate to `/aio-cycle/:projectKey/:cycleKey` |
| "Show closed" toggle on | Closed cycles appear with "Closed" badge |
| "Show closed" toggle off | Cycles where `detail.isClosed === true` are hidden |
| Empty folder selected | Right panel shows `<EmptyState>` — "No cycles in this folder" |
| No folder selected (collapsed parent) | Right panel shows `<EmptyState>` — "Select a folder to view cycles" |

### Loading states

| Surface | Skeleton |
|---------|---------|
| Folder tree loading | 6 skeleton rows of `h-4 w-40` at increasing indentation, using `useDelayedLoading(200ms)` |
| Cycle list loading | 5 rows of Key/Name/Owner/Total/Progress skeletons using `useDelayedLoading(200ms)` |
| Owner cell loading | Inline `<Skeleton className="h-4 w-24">` while user query resolves |
| Progress bar loading | `<Skeleton className="h-1.5 w-full rounded-full">` while summary query resolves |
| Owner 404 | Raw `ownedByID` string shown as plain text (D-08) |
