| lg | 24px | Section padding, gap between attachments section and activity timeline |
| xl | 32px | Layout gaps, spacing above/below collapsible section headers |

## Interaction Contracts

### Time Tracking

1. **Log Work flow:** User clicks "Log Work" button in sidebar --> Popover opens with DurationInput (focused), date picker (defaults to today), optional comment field, and "Save" button.
2. **Duration parsing:** Input accepts natural language ("2h 30m", "1d", "45m"). On blur or submit, parse to seconds. If parse fails, show inline error below input in destructive color.
3. **Clock icon fallback:** Small clock icon inside input opens a secondary popover with hours (0-99) and minutes (0-59) number inputs.
4. **Time summary display:** Horizontal progress bar in sidebar MetaRow. Bar segments: spent (primary fill) / remaining (muted fill). Text below: "Spent: 4h / Estimated: 8h / Remaining: 4h". If no estimate, show only "Spent: 4h" with "No estimate" in muted text and no bar.
5. **Worklog timeline entries:** Two-line entries in ActivityTimeline. Line 1: avatar (20px circle) + author name (semibold) + duration badge + relative timestamp (muted). Line 2: optional comment in regular weight. 3-dot menu on hover: "Edit" and "Delete" (own entries only).
6. **Edit worklog inline:** Clicking "Edit" in 3-dot menu replaces the duration badge and comment with inline DurationInput and comment input. "Save" / "Cancel" buttons below.
7. **Delete worklog:** Clicking "Delete" shows a confirmation popover (not a full dialog). "Delete" button in destructive variant.

### Attachments

1. **Section placement:** Below description, above activity timeline. Collapsible with chevron toggle. Default state: expanded if attachments exist, collapsed if empty.
2. **Image thumbnails:** 80x80px rounded-md grid with 8px gap. Uses AuthImage for authenticated fetching. Skeleton placeholder while loading. 4 columns max, wraps to next row.
3. **Non-image files:** Compact list below thumbnail grid. Each row: file type icon (from lucide: FileText, FileSpreadsheet, File) + filename (truncated at 40ch) + file size (formatted: "2.4 MB") + download icon button.
4. **Lightbox:** Click thumbnail opens Dialog overlay. Full-size image centered. Close button (X) top-right. Prev/Next arrow buttons on sides (only if multiple images). Filename + size caption below image. Click outside or Escape closes.
5. **Upload:** "Attach file" button opens native file picker. Drag-drop: entire AttachmentsSection becomes a drop zone with dashed border highlight on dragover. Single file at a time (per D-10). Progress bar below section header during upload.
6. **Delete attachment:** 3-dot menu on file rows and thumbnails (on hover). Confirmation popover before deletion.

### Mentions

1. **Trigger:** Typing "@" in CommentComposer textarea opens MentionPopover anchored to the "@" character position.
2. **Filtering:** Characters typed after "@" filter the user list. Minimum 0 characters (show all on "@"). Debounce: 200ms after typing stops before filtering API call.
3. **Navigation:** Arrow Up/Down to navigate list items. Enter to select. Escape to dismiss. Clicking an item selects it.
4. **Selection:** Inserts `[~username]` at the "@" position in textarea. Popover closes. Cursor moves to after the inserted markup.
5. **Rendering:** WikiRenderer parses `[~username]` and renders as `<span>` with `font-semibold bg-accent/20 text-accent-foreground rounded px-1` styling. Non-clickable.
6. **User list:** Fetched from Jira assignable users API, cached with TanStack Query (staleTime: 5 minutes). Shows avatar (20px) + display name per row. Max 8 visible rows, scrollable.

## Accessibility Contract

| Requirement | Implementation |
|-------------|---------------|
| Time tracking progress bar | `role="progressbar"` with `aria-valuenow`, `aria-valuemin="0"`, `aria-valuemax` set to estimate seconds |
| Log Work popover | Focus trapped inside popover. DurationInput auto-focused on open. Escape closes. |
| Attachment thumbnails | `role="button"` with `aria-label="{filename} - click to view full size"` |
| Lightbox navigation | Arrow keys for prev/next. Escape to close. Focus trapped. `aria-label` on navigation buttons. |
| Mention popover | `role="listbox"` on container, `role="option"` + `aria-selected` on items. `aria-activedescendant` on textarea. |
| Timeline filter chips | Extend existing `role="radiogroup"` pattern with Worklogs chip. `role="radio"` + `aria-checked`. |
| Drag-drop zone | `aria-label="Drag and drop files to attach"` on drop zone. Visual feedback only (keyboard users use button). |
| Delete confirmations | Focus moves to "Cancel" button on open (safe default). Destructive button requires explicit click. |
