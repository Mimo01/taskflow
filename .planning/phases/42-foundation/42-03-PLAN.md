```typescript
import { visualizer } from "rollup-plugin-visualizer";
```

Add conditional visualizer to the plugins array (after the existing plugins, per D-09):
```typescript
plugins: [
  tailwindcss(),
  react(),
  babel({ presets: [reactCompilerPreset()] }),
  ...(process.env.ANALYZE === 'true'
    ? [visualizer({ open: true, gzipSize: true, brotliSize: true })]
    : []),
],
```

CRITICAL: The visualizer MUST be behind the `process.env.ANALYZE === 'true'` guard per D-09. Never include unconditionally — it adds overhead and auto-opens browser tabs.
