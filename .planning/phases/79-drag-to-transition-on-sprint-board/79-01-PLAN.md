<objective>
Land the D-08 prerequisite: add `hasScreen?: boolean` and `hasValidators?: boolean` to the
`JiraTransition` type (in BOTH declaration sites per the dual-file rule) and propagate both
fields through `__adaptToJiraTransition` so drop-target gating (D-07, Plan 03) can read them.

HARD prerequisite for all downstream drag-gating work and is sequenced standalone in Wave 1.

Output: Extended `JiraTransition` type (two files), an adapter that copies the two fields in
both return branches, and adapter unit tests asserting both fields round-trip.
</objective>
