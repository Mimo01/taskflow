## Interaction Contracts

### Cycles page (AioProjectOverviewPage) — redesigned

| Element | State | Visual |
|---------|-------|--------|
| Cycle table row | Default | `border-b border-border` |
| Cycle table row | Hover | `hover:bg-muted/30 transition-colors` |
| Cycle name cell | Default | `<NavLink className="hover:underline">` |
| Per-row mini progress bar | Loading (stats query pending) | `<Skeleton className="h-1.5 w-full rounded-full" />` |
| Per-row mini progress bar | Loaded | `h-1.5 rounded-full overflow-hidden flex` with green-500/red-500/orange-400/bg-muted segments |
| Per-row counts | Loading | `<Skeleton className="h-3 w-24" />` below bar |
| Per-row counts | Loaded | `text-xs text-muted-foreground` below bar, format: `{pass}P {fail}F {blocked}B {notRun}N` |

Column layout (left to right): Key (mono, `w-28`) | Name (NavLink) | Status badge | Progress bar + counts

### Cycle detail page (AioCycleDetailPage) — tabbed

| Element | State | Visual |
|---------|-------|--------|
| Tab bar | — | `<TabsList>` immediately below progress section, inside the `border-b` container |
| Executions tab trigger | Active | `data-active:bg-background data-active:text-foreground` (shadcn Tabs default) |
| Executions tab trigger | Inactive | `text-foreground/60` |
| Defects tab trigger | Active | same as Executions |
| Run table row | Default | `border-b border-border` |
| Run table row | Hover | `hover:bg-muted/30 transition-colors cursor-pointer` |
| Run table row | Keyboard focus | standard `focus-visible:ring` from Tailwind base |
| Defect table row | Hover | `hover:bg-muted/30 transition-colors` |
| Defect key | Default | `font-mono text-sm <NavLink to="/issue/:key" className="hover:underline">` |

Default active tab: Executions (`defaultValue="executions"`).

Progress section (progress bar + counts row) stays above the tab bar and is always visible regardless of active tab.

Filter chips toolbar moves inside the Executions `<TabsContent>` — it does not appear on the Defects tab.

### Run row click (Executions tab)

Clicking a run row navigates to `/aio-cycle/:projectKey/:cycleKey/run/:runId`. Before navigating, push current cycle entry to `useBreadcrumbStore`. Use `onClick` + `useNavigate()` on the `<tr>` element with `role="button"` and `tabIndex={0}` for keyboard accessibility. Do not use `<NavLink>` on `<tr>` (invalid HTML).

### Defects tab — enriched rows

Column layout: Key (mono NavLink) | Title (body text) | Jira Status chip | Triggered By (test case key(s), plain text or comma-separated)

Each defect key fires one `useQuery` for Jira issue data. While loading: `<Skeleton className="h-4 w-32" />` in Title cell. Jira status chip uses the existing status badge pattern from issue detail pages (`text-xs font-medium px-2 py-0.5 rounded-full`).
