Contract (from Plan 02 `editor/types.ts` and `editor/schema.ts`; do not redefine): `WikiParse = { doc: WikiDocJSON; slices: string[] }`, `WikiLoad` union with kinds 'rich' | 'rich-demoted' | 'failed', `wikiSchema`. Spelling attrs: doc `eol`/`tail`; global block `gap`; heading `sep`; horizontalRule `src`; codeBlock `open`/`close`/`bodyLead`/`bodyTail`/`language`; hardBreak `src`; rawBlock/rawInline `raw`.

Layout rules (fix them here; later plans reuse them):
- Text is LF-normalised first (`\r\n` and lone `\r` to `\n`); `eol` = 'crlf' when the count of `\r\n` is greater than the count of bare `\n`, else 'lf'.
- `gap` = number of blank lines (empty or whitespace-only) before a block. Emit: `'\n'.repeat(first.gap) + block0`, then for each next block `'\n' + '\n'.repeat(gap) + block`, then `'\n'.repeat(doc.tail)` where `tail` = number of `\n` after the last block's last character. All-blank or empty input = one empty paragraph with gap 0 plus `tail`.
- `slices[i]` = (i > 0 ? '\n' : '') + '\n'.repeat(gap_i) + block source, and the last slice also carries the tail, so `slices.join('')` equals the LF-normalised input.
- User-created blocks have no recorded spelling and get gap 1 and canonical forms (D-08).

Module rules (React Compiler, Pitfall 7): constants at module scope only, frozen tables, no mutable module state, no module-scope `/g` regex used with `.test`/`.exec` (create sticky regexes per call or use `matchAll`/`replace`). Linear scans only (ReDoS): no nested quantifiers.
