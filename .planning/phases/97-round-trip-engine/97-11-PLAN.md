<objective>
Close the two renderer gaps the phase's own D-12 rewrite introduced (VERIFICATION.md SC1 gaps, REVIEW CR-01 and CR-02).

1. CR-01: the D-12 panel rewrite wraps every non-table panel in a blank-line block div, which splits list items and paragraphs when the panel opens mid-line. Restrict the block form to panels that sit on their own lines.
2. CR-02: panel titles and color values (and every other user-derived value interpolated into an HTML attribute in preprocess.ts) are pasted unescaped, so a `"` adds attributes, including the `data-wiki-headerless` marker that deletes a real header row. Attribute-escape every such value and restrict the marker match to the injected position.

Purpose: WikiRenderer is the equivalence oracle for the whole round-trip engine (Success Criterion 1). It must match Jira and must not regress existing renders.
Output: fixed preprocess.ts / pipeline.ts, a new placeholder corpus fixture, renderer and pipeline regression tests that fail before the fix.
