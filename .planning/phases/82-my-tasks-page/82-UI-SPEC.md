## Spacing Scale

Standard 8-point scale — matches existing app conventions (`py-2`, `px-4`, `gap-2` throughout `BacklogRow.tsx` and `TaskCard.tsx`).

| Token | Value | Usage |
|-------|-------|-------|
| xs | 4px | Icon gaps (`gap-1`), inline badge padding (`px-1 py-0.5`) |
| sm | 8px | Row cell padding (`py-2`, `px-2`), strip item gap |
| md | 16px | Section horizontal padding (`px-4`), filter strip padding |
| lg | 24px | Group header vertical margin, section breaks |
| xl | 32px | Page-level top padding |
| 2xl | 48px | Empty-state vertical centering (`py-8` = 32px minimum; use `py-12` = 48px for full-page empty) |
| 3xl | 64px | Not used in this phase |

Exceptions:
- Issue-type icon and priority icon cells use explicit `width: 18, height: 18` px (not Tailwind class) to prevent WebKit 0-width column collapse in table rows — carry the `BacklogRow.tsx` pattern exactly (see `project_virtualized_table_zero_width_col` memory).
- Subtask indent: `pl-8` (32px) applied to nested subtask rows to signal hierarchy visually.
- Touch target for scope toggle buttons: minimum 36px height (`h-9`).

Source: `taskflow/src/routes/dashboard/BacklogRow.tsx` (explicit-px pattern carried forward)

## Typography

| Role | Size | Weight | Line Height |
|------|------|--------|-------------|
| Body / row summary | 14px (`text-sm`) | 400 (regular) | 1.5 |
| Label / metadata | 12px (`text-xs`) | 400 (regular) | 1.4 |
| Section heading / group header | 14px (`text-sm`) | 600 (semibold) | 1.2 |
| Page title | 20px (`text-xl`) | 600 (semibold) | 1.2 |

Constraints:
- Maximum 4 sizes declared (12, 14, 20 — display/page title only needs one jump above body).
- Maximum 2 weights: 400 (regular) and 600 (semibold). No 500/700 in this phase.
- Issue key: monospace `font-mono text-xs text-muted-foreground` — inherited from `BacklogRow.tsx` pattern.
- Done-issue summary: `line-through text-muted-foreground` via `doneSummaryClass()` — carry existing helper.
- Overdue due date: `text-destructive` (`oklch(0.577 0.245 27.325)` in light, `oklch(0.704 0.191 22.216)` in dark) — no new color needed, reuse token.

Source: `taskflow/src/routes/dashboard/BacklogRow.tsx`, `taskflow/src/routes/dashboard/TaskCard.tsx` (existing patterns)

## Color

All values are shadcn OKLCH design tokens from `taskflow/src/index.css`. Do not use raw hex — use CSS custom properties and Tailwind semantic classes.

| Role | Token | Light Value | Dark Value | Usage |
|------|-------|-------------|------------|-------|
| Dominant (60%) | `--background` | `oklch(1 0 0)` | `oklch(0.145 0 0)` | Page background, row base |
| Secondary (30%) | `--card` / `--muted` | `oklch(1 0 0)` / `oklch(0.97 0 0)` | `oklch(0.205 0 0)` / `oklch(0.269 0 0)` | Filter strip surface, group headers (`bg-muted`), hover state (`hover:bg-muted/30`) |
| Accent (10%) | `--sidebar-primary` (dark) / `--primary` (light) | `oklch(0.205 0 0)` | `oklch(0.488 0.243 264.376)` (blue) | Active scope toggle button, active filter strip count highlight |
| Destructive | `--destructive` | `oklch(0.577 0.245 27.325)` | `oklch(0.704 0.191 22.216)` | Overdue due date text, ErrorState alert border |

Accent reserved for ONLY:
1. Active scope toggle pill (Current Sprint / All Assigned — the selected state)
2. Active summary-strip filter count highlight (the single active filter button)

Never apply accent to: row hover, group headers, pagination loading indicator, subtask indent lines, or status pills (status pills use `statusPillClass()` from `lib/statusStyles.ts`).

Special semantic colors (carry existing patterns, not new tokens):
- Flagged row background: `bg-yellow-100 dark:bg-yellow-900/30` — same as `BacklogRow.tsx`
- Flagged icon: `text-yellow-700 dark:text-yellow-300`
- MR health badge: reuse existing `Badge` variant patterns from `TaskCard.tsx`

## Interaction Contract

### Row Anatomy (MYTASK-05)
Each `MyTaskRow` renders left-to-right:
1. **Type icon** — `IssueTypeIcon`, 18×18px explicit style (WebKit column fix)
2. **Issue key** — `font-mono text-xs text-muted-foreground`, inner `<button>` with `stopPropagation` → full-page detail
3. **Priority icon** — `PriorityIcon`, 18×18px explicit style
4. **Summary** — `text-sm truncate`, flag icon (`Flag size-3.5`) prepended when flagged, `OverdueBadge` appended when overdue
5. **Status pill** — `statusPillClass()` from `lib/statusStyles.ts`, wrapped in `flex div` (not bare `span` — see `project_statuspill_needs_flex_parent` memory), click → `StatusPopover`
6. **Due date** — `text-xs`, `text-destructive` when overdue (past today and not done)
7. **Story points badge** — `inline-flex w-7` border chip, `?` when null
8. **MR health badge** — `Badge` variant, shown when MR exists
9. **Time logged/remaining bar** — `Progress` component, shown when time data available

Row outer element: `div[role=button]` with `onClick` → `PeekPanel` (body click, D-08). Issue key is a sibling `<button>` with `stopPropagation` — NOT a nested button inside the outer role=button (overlay-button pattern from `project_overlay_button_nested_interactive` memory).

Subtask rows: `pl-8` indent, same anatomy, no group header.

### Summary / Filter Strip (MYTASK-02, D-01, D-02)
- Horizontal strip of count pills: To Do | In Progress | In Review | Done this sprint | Overdue | MRs awaiting me
- Each pill: `text-xs font-semibold`, count number prominent, label below or inline
- Active pill: accent background (scope toggle active style) + `font-semibold`
- Inactive pill: `bg-muted text-muted-foreground hover:bg-muted/80`
- Single-select only — clicking active pill deactivates filter (toggle behavior)
- Strip sits below page title, above grouping tabs

### Grouping Tabs (MYTASK-03)
- Three tabs: "My Day" | "By Status" | "By Sprint & Parent"
- Use `Tabs` from `components/ui/tabs.tsx` (shadcn Tabs primitive)
- Active tab: underline + `text-foreground font-semibold`
- Inactive tab: `text-muted-foreground`

### Scope Toggle (MYTASK-07)
- Two-state toggle: "Current Sprint" / "All Assigned"
- Render as a pair of `<button>` elements styled as a segmented control
- Active: `bg-primary text-primary-foreground` (uses accent for dark mode sidebar primary)
- Inactive: `bg-muted text-muted-foreground hover:bg-muted/80`
- Minimum height `h-9` (36px)
- Positioned top-right of the page header area, same horizontal row as grouping tabs

### Progressive Loading Indicator (D-06, Claude's Discretion)
When All-Assigned scope is loading additional pages via `fetchAllSearchPages`:
- Show a `Skeleton` row pair at the bottom of the current list
- Label: "Loading more tasks…" in `text-xs text-muted-foreground` below the skeletons
- No spinner — skeletons communicate the list is growing
- Placement: below the last rendered row, before the list container's scroll end

### Group Headers (MYTASK-03)
- `text-sm font-semibold text-foreground` with `bg-muted` background strip
- `px-4 py-2` padding
- My Day: band labels (Flagged / Blocked, Overdue, In Review, In Progress, To Do, Done)
- By Status: status category names
- By Sprint & Parent: sprint name + date range; parent issue key + summary

## Accessibility Notes

- Row outer `div[role=button]` must have `tabIndex={0}` and `onKeyDown` handler for Enter/Space → PeekPanel (keyboard parity with mouse click).
- Issue key inner button must be focusable and keyboard-reachable independent of the row (Tab stop).
- Group headers: `role="rowgroup"` or section headings (`<h3>`) depending on whether the list renders as a `<table>` or flex/div layout.
- Status pill click target: minimum 28px height so it is reachable by keyboard and touch.
- Filter strip active state: use `aria-pressed="true"` on the active count button.
- Scope toggle: use `role="group"` + `aria-label="Scope"` wrapping the two toggle buttons; active button `aria-pressed="true"`.
- Overdue dates: `aria-label="Due {date}, overdue"` on the overdue date element.
