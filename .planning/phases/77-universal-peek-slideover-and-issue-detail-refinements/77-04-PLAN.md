<objective>
Apply the uniform key-vs-body click split (D-10) across ALL list surfaces: card/row body click → `onOpenIssue` (open peek), issue-key click → `stopPropagation()` → navigate full-page. The `onOpenIssue` handler is already in outlet context (visual surfaces) and on CommandPalette/NotificationPopover props (from Plan 03). This completes universal peek triggering (PEEK-01) for all issue types (PEEK-02) and the key→full-page rule (PEEK-05) on every surface; clicking another card while the peek is open swaps it (PEEK-04).

Plan 03 wired the BODY-click path of CommandPalette and NotificationPopover to the peek (onOpenIssue) but did NOT add the inner key→full-page clickable on those two surfaces. This plan delivers that key split so PEEK-05 / D-10 ("uniform rule applied across … CommandPalette … and Notifications") is satisfied on every surface, not just the visual cards.

Purpose: Surfaces own their DOM; this plan wires each to the two handlers established upstream. The visual card/row surfaces consume `onOpenIssue` from outlet context; CommandPalette/NotificationRow consume the props Plan 03 added.
Output: modified TaskCard, BacklogRow, DashboardInProgressCard, StandupNotesPage, CommandPalette, NotificationPopover, NotificationRow; TaskCard.test.tsx PEEK-05 activated.
</objective>
