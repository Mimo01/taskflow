## Typography

| Role | Size | Weight | Line Height |
|------|------|--------|-------------|
| Body | 14px (text-sm) | 400 (regular) | 1.5 |
| Label | 12px (text-xs) | 400 (regular) | 1.4 |
| Heading | 20px (text-xl) | 600 (semibold) | 1.2 |
| Display | 28px (text-3xl) | 600 (semibold) | 1.1 |

**Role mapping for this phase:**
- Display (28px / semibold): hero greeting — "Welcome back, [displayName]"
- Heading (20px / semibold): not used in cards; reserved for page-level headings (consistent with `text-xl font-semibold` in BacklogPage, AioProjectOverviewPage)
- Label (12px / regular): card header label (e.g., "SPRINT HEALTH", "MY IN PROGRESS", "NEXT RELEASE") — uppercase tracking-wide, `text-muted-foreground`; visual distinction from Body is achieved via `uppercase tracking-wide text-muted-foreground` alone, not via font-weight
- Body (14px / regular): card body text — sprint name, subtask summary, release name, countdown copy, empty states

Source: detected from `IssueDetailContent.tsx` (text-xl/font-semibold headings), `SprintHealthPanel.tsx` (text-sm body, text-sm font-semibold uppercase for section labels), `BacklogPage.tsx` (text-lg font-semibold page headings).

## Color

| Role | Value | Usage |
|------|-------|-------|
| Dominant (60%) | `var(--background)` — oklch(1 0 0) light / oklch(0.145 0 0) dark | Page background, hero gradient base surface |
| Secondary (30%) | `var(--card)` — oklch(1 0 0) light / oklch(0.205 0 0) dark | Card surfaces (`bg-card`), sidebar |
| Accent (10%) | `var(--primary)` — oklch(0.205 0 0) light / oklch(0.922 0 0) dark | Hero gradient tint at low opacity (primary/10); subtask click-through hover ring |
| Destructive | `var(--destructive)` — oklch(0.577 0.245 27.325) | Not used in this phase — no destructive actions |

**Per-card icon accent colors (distinct, semantic):**
- Sprint Health card: `text-amber-500` icon (Zap or Activity from lucide) — amber/orange warmth
- My In Progress card: `text-green-500` icon (CheckCircle2 or ListTodo from lucide) — active/in-progress green
- Next Release card: `text-blue-500` icon (Calendar or Rocket from lucide) — planning blue

**Timing / status badge colors for Next Release card (matching ReleasesTab conventions):**
- Future release: `text-muted-foreground` — "X days away"
- Due today: `Badge tone="blue"` — "Today"
- Overdue: `text-amber-600 dark:text-amber-400` text or `Badge tone="red"` — "X days overdue"

**Hero gradient:**
- Light: `bg-gradient-to-br from-primary/5 to-background` (very subtle warm tint)
- Dark: `bg-gradient-to-br from-primary/10 to-background`
- No illustrations on the hero itself (per D-02)

Accent reserved for: hero gradient tint only; subtask row hover focus ring; icon accents on card headers. NOT used on card borders, text links, or general interactive elements.

Source: `index.css` CSS custom properties; D-02, D-04 from CONTEXT.md; ReleasesTab badge tone patterns.

## Interaction Contract

### Subtask Click-Through (My In Progress card)

- Each subtask row is a full-width clickable element (`role="button"` or `<button>`)
- Click navigates to `/issue/:key` via `useNavigate` (react-router-dom)
- Hover state: `hover:bg-muted/50` (matching existing row hover patterns in ReleasesTab)
- Focus state: `focus-visible:ring-2 focus-visible:ring-ring`
- Keyboard: Enter key triggers navigation

### Loading States

- All three cards use `useDelayedLoading` (200ms threshold) before showing skeleton
- Skeleton: 3 stacked `h-4 rounded bg-muted animate-pulse` blocks per card
- No skeleton flash on cache hits (existing cache warm from SprintBoardTab / ReleasesTab visits)

### No Interactive Elements on Hero

- Hero section is purely display — no buttons, no refresh controls
- Cards contain no refresh buttons (unlike the tab views); data is read-only summary
