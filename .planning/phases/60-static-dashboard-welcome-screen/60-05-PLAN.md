Fix the breadcrumb regression on the Dashboard In-Progress card.

Purpose: Users clicking a subtask row on the dashboard can navigate back to the dashboard via the breadcrumb back-arrow.
Output: DashboardInProgressCard.tsx (prop-based navigation), dashboard/index.tsx (useOutletContext wiring), DashboardInProgressCard.test.tsx (updated test 3).
</objective>
