## Spacing Scale

Declared values (must be multiples of 4):

| Token | Value | Usage |
|-------|-------|-------|
| xs | 4px | Icon gaps, inline padding, grid gap between widget controls |
| sm | 8px | Compact element spacing, sidebar item toggle gaps |
| md | 16px | Default element spacing, widget card padding, settings section gaps |
| lg | 24px | Section padding in Settings > Appearance, widget picker grid gap |
| xl | 32px | Dashboard page padding (p-4 = 16px existing; grid gap-4 = 16px existing) |
| 2xl | 48px | Major section breaks in settings page |
| 3xl | 64px | Not used this phase |

Exceptions: Dashboard page uses existing `p-4` (16px) and `gap-4` (16px) pattern from current dashboard. Widget grid gutter is 16px to match.

## Interaction Contracts

### Sidebar Customization (Settings > Appearance)

| Interaction | Behavior |
|-------------|----------|
| Toggle sidebar item visibility | Switch component toggles item `visible` boolean in store. Sidebar re-renders immediately. Settings link cannot be toggled (always pinned). |
| Drag-reorder sidebar items | @dnd-kit/core drag-and-drop within the settings list. Vertical reorder only. Drop indicator: 2px `var(--primary)` horizontal line at insertion point. Sidebar updates on drop. |
| Apply Dev preset | Click "Apply Dev Preset" button. Confirmation dialog: "This will reset your sidebar and dashboard to developer defaults. Continue?" Restores Dev sidebar items + Dev dashboard layout. |
| Apply PM preset | Same flow as Dev preset but with PM defaults. |

### Dashboard Widget System

| Interaction | Behavior |
|-------------|----------|
| Add widget | Click "Add Widget" button in dashboard header. Opens Dialog with widget catalog grid. Click widget card to add at next available position. Dialog stays open for multiple adds. |
| Remove widget | Hover widget card to reveal X button in top-right corner of title bar. Single click removes. No confirmation (undo-friendly: user can re-add). |
| Drag widget | Grab drag handle (grip icon) in widget title bar. Ghost follows cursor. Other widgets reflow with smooth 200ms transition. Auto-compact on drop (vertical). |
| Resize widget | Grab resize handle (bottom-right corner, diagonal grip icon). Respects per-widget min/max constraints. Other widgets reflow. |
| Widget loading | Each widget shows its own skeleton state (existing pattern from panels). No global loading state. |
| Widget error | Each widget shows inline error with retry button. Does not affect other widgets. |
| Empty dashboard | When all widgets removed: EmptyState with LayoutDashboard icon, heading "Your dashboard is empty", body "Add widgets to build your workspace", action button "Add Widget". |

## Drag-and-Drop Visual Feedback

| State | Visual |
|-------|--------|
| Idle drag handle | `GripVertical` icon (lucide), `text-muted-foreground`, `cursor-grab` |
| Dragging (sidebar items) | Dragged item has `ring-2 ring-ring` outline, 50% opacity at origin, 2px `var(--primary)` insertion line at drop target |
| Dragging (dashboard widget) | Widget gets `shadow-lg`, `ring-2 ring-ring`, slight scale (1.02). Placeholder shows dashed border `border-dashed border-2 border-muted-foreground/30` at drop zone |
| Resize handle | Bottom-right corner, `GripHorizontal` icon rotated 45deg or diagonal resize icon, `text-muted-foreground`, `cursor-se-resize` |
| Resizing | Widget border becomes `ring-2 ring-ring`, real-time size preview |

## Accessibility

| Requirement | Implementation |
|-------------|---------------|
| Sidebar item reorder | Keyboard accessible: arrow keys to move focus, Enter/Space to pick up, arrow keys to reorder, Enter/Space to drop. aria-roledescription="sortable" on each item. |
| Widget drag | react-grid-layout handles keyboard support natively. Each widget card is a landmark with `role="region"` and `aria-label="{widget title}"`. |
| Toggle switches | shadcn Switch has built-in aria. Label association via htmlFor. |
| Remove widget | `aria-label="Remove {widget title} widget"` on X button. |
| Preset confirmation dialog | Focus trapped in dialog. Escape to close. Confirm button is not autofocused (cancel is default focus to prevent accidental resets). |
| Widget picker dialog | Focus trapped. Grid of widget cards navigable with arrow keys. Each card has `role="button"` with `aria-label="Add {widget title} widget"`. |
