<objective>
Build the pure, DOM-only paste conversion layer: an allowlist HTML normaliser (web, Word, Google Docs, Jira) that rewrites clipboard HTML into the exact parse tags the editor schema already accepts, plus the "clearly wiki" plain-text heuristic. No editor plugin wiring here (plan 10 does that).

Purpose: INPUT-04 / D-12..D-14. Research verified that the stock parser drops `<img>`, flattens `div.panel` and parses `span[data-color]` with an empty value (Pitfalls 1-2), and that HTML tables can make the emitter throw (Pitfall 3). The normaliser closes all of these without touching extensions.ts.
Output: four pure modules, five placeholder-only fixtures, two test files.
</objective>
