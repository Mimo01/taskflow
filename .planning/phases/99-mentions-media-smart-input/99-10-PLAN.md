## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-99-34 | Tampering / EoP | HTML paste | mitigate | Only normalisePastedHtml output reaches the ProseMirror parser; no innerHTML sinks (grep gate); schema drops unknown nodes |
| T-99-35 | Information disclosure | remote image fetch | mitigate | single fetch, 5s timeout, image content-type only, only for images the user pasted; failure falls back to a link (no retry) |
| T-99-36 | Tampering | fallback links | mitigate | fallback link only when isSafeLinkUrl(src) |
| T-99-37 | Denial of service | huge wiki paste | mitigate | looksLikeWiki 200k cap (plan 02); loadWiki failure falls back to plain paste |
| T-99-38 | Elevation | data: images | mitigate | decoded to a File and uploaded via host only; never set as an img src in the doc |
