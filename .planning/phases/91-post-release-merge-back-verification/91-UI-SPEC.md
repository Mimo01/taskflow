# Phase 91 — UI Design Contract

> Visual and interaction contract for frontend phases. Generated by gsd-ui-researcher, verified by gsd-ui-checker.

**Scope note:** This phase adds exactly one new UI element — a "Merged back" `MetaRow` in the release detail sidebar's Details block — plus a wording edit to the existing "Release Branch" row. No new pages, dialogs, or components. This contract is intentionally thin: it constrains the one row being added and defers everything else to the existing `ReleaseDetailSidebar.tsx` conventions it must match byte-for-byte.

## Interaction Contract (phase-specific, in place of a generic component inventory)

- **No click, no button, no keyboard interaction.** The row is display-only; the tooltip is the browser's native `title` hover/focus behavior, identical to how `branch-status-released` and `branch-status-check-failed` already work in this file — do not upgrade to a JS-driven tooltip/popover for this row alone while its siblings use native `title`.
- **Placement:** immediately below the existing "Release Branch" `MetaRow`, before "MR Labels", inside the same Details block (per D-07). Same `MetaRow label="Merged back"` wrapper, same visual rhythm as every other row — no distinct card, border, or background treatment.
- **No banner, no page-level treatment, no toast.** MERGE-03's manual-override affordance is descoped (D-12); nothing about this feature may read as blocking or require dismissal (D-07 explicitly rules out a banner).
- **Loading state:** while the two new queries (tracking-MR lookup, `repository/compare`) are in flight, follow the existing pattern used by `branchState.kind === 'loading'` in the same file — `<span className="text-muted-foreground text-xs">Loading...</span>` — for visual consistency, not a spinner or skeleton.
- **Icon sizing:** `size-3` (12px) for every verdict icon, matching every other row icon in this sidebar. Do not use a larger icon to "highlight" the warning state — the color change (orange) carries that weight, per the existing file's convention (see label-coverage `AlertTriangle`).
