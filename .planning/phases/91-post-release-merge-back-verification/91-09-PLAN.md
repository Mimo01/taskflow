row asserts "No matching tag found — tags are an incomplete record, so this is
not evidence the release did not ship." whenever `branchState.tagName` is falsy,
which is true in three structurally different situations — the tag query in
flight, the tag query failed, and the tag query resolved with genuinely no
match. That makes a settled-sounding negative claim on every ordinary page load
for the duration of the tag fetch, and permanently on a genuine tag-fetch
failure (a real, reachable outcome since 91-07 made `searchProjectTags` throw
instead of swallowing errors into `[]`).

row, applied to the second consumer of the same tag channel: `resolveBranchState`
never received `tagLookupPending`/`tagCheckFailed`, even though both are computed
a few lines above its call site in the same hook function.

Purpose: D-08 requires this row to report only what it knows. An unverified
negative asserted as settled fact is precisely the defect class D-08 exists to
eliminate.
Output: a `TagChannelHealth` discriminant carried end-to-end from the live tag
query into the released-row tooltip, with unit and render coverage.
