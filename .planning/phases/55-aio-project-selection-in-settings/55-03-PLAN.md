<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| URL path construction (`/aio-project/${selectedAioProjectKey}`) | The value originates from a server-controlled enum (AIO `projectKey` from `fetchAioProjects` response — see Plan 02 threat model T-55-04) and flows into a React Router `to` prop. |
| Sidebar visibility predicate | Read-only consumer of two store fields (`aioEnabled`, `selectedAioProjectKey`); no writes. |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-55-08 | Tampering | NavLink `to` template literal | mitigate | `selectedAioProjectKey` is sourced from the picker's `<SelectItem value={p.projectKey}>` callback (Plan 02), which is rendered from the authenticated `fetchAioProjects` response — not from user free-text input. React Router URL-encodes path segments natively. Tauri's same-origin context prevents external redirection from a NavLink. The filter guarantees `selectedAioProjectKey !== null` when the item is rendered, so the template never produces `/aio-project/null` at runtime. |
| T-55-09 | Information Disclosure | Sidebar render exposes project key in URL bar | accept | Project keys are non-secret (e.g., `PROJ`). Tauri desktop app has no URL bar exposed to other origins. Standard browser URL semantics apply. |
| T-55-10 | Denial of Service | Re-render on every selection change | accept | Zustand's shallow-equal subscription only fires when the destructured field actually changes; selection change is a low-frequency user action. No DoS surface. |
</threat_model>
