Modify notifications.store.ts to cache derived unread count instead of creating new Set(readIds) on every selector call.

**Step 1: Add _unreadCount, _jiraUnreadCount, _gitlabUnreadCount fields to the state interface:**
Add these 3 fields to the existing NotificationsState interface:
```typescript
_unreadCount: number;
_jiraUnreadCount: number;
_gitlabUnreadCount: number;
```

Initialize all three to `0` in the create() initial state.

**Step 2: Create a helper function (inside the store file, not exported):**
```typescript
function computeUnreadCounts(items: NotificationItem[], readIds: string[]) {
  const readSet = new Set(readIds);
  let total = 0;
  let jira = 0;
  let gitlab = 0;
  for (const item of items) {
    if (!readSet.has(item.id)) {
      total++;
      if (item.source === 'jira') jira++;
      else gitlab++;
    }
  }
  return { _unreadCount: total, _jiraUnreadCount: jira, _gitlabUnreadCount: gitlab };
}
```

**Step 3: Update every action that changes items or readIds to recalculate:**
In `setItems`: after setting items, spread `...computeUnreadCounts(items, get().readIds)` into the set call.
In `prependItems`: after computing new items array, spread computed counts.
In `markAsRead`: after updating readIds, spread computed counts.
In `toggleRead`: after updating readIds, spread computed counts.
In `markAllRead`: set all three counts to 0 directly (all items read).
In `deleteNotification`: after filtering items and readIds, spread computed counts.
In `clearAll`: set all three counts to 0.

**Step 4: Simplify the exported selectors:**

