**A11Y-02: Custom dropdown ARIA roles:**

6. **Epic link picker** (likely in EpicSection.tsx or equivalent):
   - Find the filter input for epics. Add: `role="combobox"`, `aria-expanded={epicDropdownOpen}`, `aria-controls="epic-listbox"`, `aria-label="Filter epics"`.
   - Find the dropdown list container. Add: `role="listbox"`, `id="epic-listbox"`.
   - Find each epic option button/item. Add: `role="option"`, `aria-selected={selectedEpicKey === epic.key}`.

7. **Assignee autocomplete** (likely in AssigneeSection.tsx or equivalent):
   - Find the assignee search/filter input. Add: `role="combobox"`, `aria-expanded={assigneeDropdownOpen}`, `aria-controls="assignee-listbox"`, `aria-label="Assignee"`.

   - Find each assignee option. Add: `role="option"`, `aria-selected={selectedAssignee === user.accountId}`.

**Important:** Only modify hand-built dropdowns. If any dropdown uses @base-ui/react Select primitives, it already has correct ARIA — skip it. Check imports to determine which are hand-built vs library-provided.
