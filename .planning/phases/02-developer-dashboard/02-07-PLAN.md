<objective>
Fix the silent failure pattern in TokenSection that hides the GitLab group and Jira project selectors when list fetches fail. Currently, both selectors are rendered inside `{groups.length > 0 && ...}` guards. When the fetch silently fails (network error, CORS, bad token), the state stays empty and the selector never appears — the user sees nothing and has no way to select a project or group.

Purpose: UAT tests 6, 7, 8, and 9 all fail because the GitLab group selector is missing. The user cannot configure an active git project. This fix makes the selector unconditionally present (when the base URL is configured) with clear feedback on failure.
Output: Selectors render with loading spinners, error messages on failure, and the dropdown on success — no more silent hiding.
</objective>

    const [jiraProjectsLoading, setJiraProjectsLoading] = useState(false)
    const [jiraProjectsError, setJiraProjectsError] = useState<string | null>(null)
    const [gitlabGroupsLoading, setGitlabGroupsLoading] = useState(false)

    **Part 2: Replace silent-failure useEffect with one that tracks loading/error state**

    For Jira (replace existing jiraBaseUrl useEffect):
    ```typescript
    useEffect(() => {
      if (!jiraBaseUrl) return
      setJiraProjectsLoading(true)
      setJiraProjectsError(null)
      ;(async () => {
        try {
          const pat = await readSecret('jira-pat').catch(() => null)
          if (!pat) {
            setJiraProjectsError('Could not read Jira token')
            return
          }
          const list = await listJiraProjects(jiraBaseUrl, pat)
          setJiraProjects(list)
        } catch (err) {
          setJiraProjectsError((err as Error)?.message ?? 'Failed to load projects')
          setJiraProjects([])
        } finally {
          setJiraProjectsLoading(false)
        }
      })()
    }, [jiraBaseUrl])
    ```

    For GitLab (replace existing gitlabBaseUrl useEffect):
    ```typescript
    useEffect(() => {
      if (!gitlabBaseUrl) return
      setGitlabGroupsLoading(true)
      setGitlabGroupsError(null)
      ;(async () => {
        try {
          const pat = await readSecret('gitlab-pat').catch(() => null)
          if (!pat) {
            setGitlabGroupsError('Could not read GitLab token')
            return
          }
          const list = await listGitLabGroups(gitlabBaseUrl, pat)
          setGitlabGroups(list)
        } catch (err) {
          setGitlabGroupsError((err as Error)?.message ?? 'Failed to load groups')
          setGitlabGroups([])
        } finally {
          setGitlabGroupsLoading(false)
        }
      })()
    }, [gitlabBaseUrl])
    ```
