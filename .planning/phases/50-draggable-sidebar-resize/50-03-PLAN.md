const { width, isDragging, handleMouseDown } = useResizable({
  initialWidth: issueDetailPanelWidth ?? 400,
  // 400px is a safe fallback — style falls back to '42%' string when issueDetailPanelWidth is null
  min: 240,
  max: () => (containerRef.current?.offsetWidth ?? 800) * 0.5,
  // Compute max at drag time (Pitfall 6 in RESEARCH.md: do not compute at mount time)
  onCommit: setIssueDetailPanelWidth,
});

**Change 5 — Add ref to the two-column flex container** (find the outer flex container div at approximately line 353, which has `className="flex flex-1 overflow-hidden"`, and add `ref={containerRef}` to it):

**Change 6 — Replace the right panel div** (find the right panel at approximately line 420 and replace the entire opening tag):

BEFORE:
```tsx
<div className="w-[42%] border-l overflow-auto p-4 shrink-0">
```

AFTER:
```tsx
<div
  className={`relative border-l overflow-auto p-4 shrink-0${isDragging ? '' : ' transition-all duration-200'}`}
  style={{ width: issueDetailPanelWidth !== null ? width : '42%' }}
>
  <div
    aria-hidden="true"
    onMouseDown={handleMouseDown}
    className="absolute left-0 top-0 h-full w-2 cursor-ew-resize z-20 border-l border-border transition-colors duration-100"
    onMouseEnter={(e) => {
      (e.currentTarget as HTMLElement).style.borderColor = 'var(--ring)';
    }}
    onMouseLeave={(e) => {
      if (!isDragging) (e.currentTarget as HTMLElement).style.borderColor = '';
    }}
    style={{ borderColor: isDragging ? 'var(--ring)' : undefined }}
  />
```

Key points:
- `style={{ width: issueDetailPanelWidth !== null ? width : '42%' }}`: when store value is null (before first drag), panel renders at 42% just as before. After first drag, numeric px width from hook drives the style.
- `relative` class added to the panel div (needed for the absolutely positioned drag handle child).
- `w-[42%]` Tailwind class is removed entirely.
- `shrink-0` remains.
- Drag handle is on the LEFT border (`left-0`, `border-l`) — detail pages have the right panel on the right side, so the drag handle is on its left edge.
- `transition` suppressed while `isDragging` (same pattern as Sidebar.tsx).
- The existing right panel content (IssueDetailSidebar component and all children) remains unchanged after the drag handle div.
