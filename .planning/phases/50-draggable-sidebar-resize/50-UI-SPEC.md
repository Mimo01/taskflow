## Interaction Contract

This section is specific to Phase 50 because the entire phase is an interaction feature with no new page elements.

### Drag Handle — Main Navigation Sidebar

| State | Visual |
|-------|--------|
| Default (sidebar expanded) | No permanent visible element. Right border uses `border-r border-border` — existing class. |
| Hover (cursor enters 8px zone along right border) | `cursor: ew-resize`. Border color transitions to `var(--ring)`. Transition: `border-color 100ms ease`. |
| Active drag | `cursor: ew-resize` maintained on `<html>` element (prevents cursor flicker during fast mouse moves). Border stays highlighted. |
| Collapsed sidebar | No drag affordance. Handle is not rendered. Cursor reverts to default. |
| Sidebar restoring after uncollapse | Width animates from 64px to last persisted `sidebarWidth` using the existing `transition-all duration-200` class. |

Drag bounds:
- Minimum: 160px
- Maximum: 320px
- Default (no stored value): 224px (`md:w-56` = 14rem = 224px — matches current Tailwind class)

Source: D-01, D-02, D-04 (Claude's Discretion) from 50-CONTEXT.md

### Drag Handle — Detail Page Right Panels (Issue, MR, Release)

| State | Visual |
|-------|--------|
| Default | No permanent visible element. Left border of the right panel uses `border-l border-border`. |
| Hover (cursor enters 8px zone along left border of right panel) | `cursor: ew-resize`. Border color transitions to `var(--ring)`. Transition: `border-color 100ms ease`. |
| Active drag | `cursor: ew-resize` maintained on `<html>`. Border stays highlighted. |

Drag bounds:
- Minimum: 240px
- Maximum: 50% of the parent flex container's width (computed at drag time)
- Default (no stored value): Issue detail: `42%` of container; MR detail: 288px (`w-72`); Release detail: 288px (mirrors MR)

Source: D-03, D-05 (Claude's Discretion) from 50-CONTEXT.md

### Width Application Pattern

Dynamic user-controlled widths MUST be applied via `style={{ width: `${px}px` }}` inline style. Do NOT use Tailwind width classes for resizable elements. The `shrink-0` class MUST be preserved on the sidebar `<aside>`.

Source: "Established Patterns" from 50-CONTEXT.md code_context section.

### Persistence

| Key | Store field | Default |
|-----|-------------|---------|
| Main nav sidebar width | `sidebarWidth: number` (add to `useSettingsStore`) | `224` |
| Issue detail right panel width | `issueDetailPanelWidth: number` (add to `useSettingsStore`) | `null` (use `42%` of container) |
| MR detail right panel width | `mrDetailPanelWidth: number` (add to `useSettingsStore`) | `288` |
| Release detail right panel width | `releaseDetailPanelWidth: number` (add to `useSettingsStore`) | `288` |

Store version: increment from current `13` to `14`. Migration guard: add each field with `if (s.fieldName === undefined) s.fieldName = defaultValue` under `version < 14`.

Source: D-03, 50-CONTEXT.md code_context, `settings.store.ts` version 13.

## Copywriting Contract

This phase introduces no new user-facing text, dialogs, or labels. The drag interaction is silent (cursor + border only). No CTAs, empty states, errors, or destructive confirmations exist.

| Element | Copy |
|---------|------|
| Primary CTA | Not applicable — no CTA in this phase |
| Empty state heading | Not applicable |
| Empty state body | Not applicable |
| Error state | Not applicable — resize failures silently clamp to bounds |
| Destructive confirmation | Not applicable — no destructive actions |

Tooltip / aria-label note: The existing collapse chevron button already has `aria-label={sidebarCollapsed ? 'Expand sidebar' : 'Collapse sidebar'}`. The drag handle div should carry `aria-hidden="true"` (it is a mouse-only interaction with no keyboard equivalent in this phase).
