**Change 4 — Replace the `<aside>` element** (find the existing `<aside>` at line ~195 and replace it exactly):

BEFORE (remove this entire `<aside>` opening tag):
```tsx
<aside
  className={`relative flex flex-col h-full ${sidebarCollapsed ? 'w-16' : 'w-16 md:w-56'} border-r border-border bg-background shrink-0 transition-all duration-200`}
  onMouseEnter={() => setHovered(true)}
```

AFTER (replace with):
```tsx
<aside
  className={`relative flex flex-col h-full border-r border-border bg-background shrink-0${isDragging ? '' : ' transition-all duration-200'}`}
  style={{ width: sidebarCollapsed ? 64 : width }}
  onMouseEnter={() => setHovered(true)}
  onMouseLeave={() => setHovered(false)}
>
```

Key points:
- `w-16` and `w-16 md:w-56` Tailwind width classes are removed entirely — width is now driven by `style={{ width }}`.
- `shrink-0` remains as a Tailwind class (prevents double-shrink during drag, Pitfall 4).
- `transition-all duration-200` is conditionally included only when `!isDragging` (resolves Assumption A3 from RESEARCH.md — prevents laggy drag feedback from CSS transition fighting the inline style).
- `sidebarCollapsed ? 64 : width` — collapsed state always 64px; expanded state uses hook width (resolves Pitfall 5: collapse toggle regression).

**Change 5 — Add drag handle div** (insert immediately after the `<aside>` opening tag, BEFORE the existing hover-chevron `<button>`, conditionally rendered only when `!sidebarCollapsed` per D-02):
```tsx
{!sidebarCollapsed && (
  <div
    aria-hidden="true"
    onMouseDown={handleMouseDown}
    className="absolute right-0 top-0 h-full w-2 cursor-ew-resize z-20 border-r border-border transition-colors duration-100"
    onMouseEnter={(e) => {
      (e.currentTarget as HTMLElement).style.borderColor = 'var(--ring)';
    }}
    onMouseLeave={(e) => {
      if (!isDragging) (e.currentTarget as HTMLElement).style.borderColor = '';
    }}
    style={{ borderColor: isDragging ? 'var(--ring)' : undefined }}
  />
)}
```

Notes on the drag handle:
- `aria-hidden="true"` — mouse-only interaction, no keyboard equivalent (per UI-SPEC.md).
- `z-20` — sits above the collapse chevron button which is at `z-10`.
- `right-0` with `w-2` (8px) — does not overlap the chevron at `-right-3` (12px outside).
- Border highlight: resting state inherits `border-border`; hover and active state use `var(--ring)` (per UI-SPEC.md color contract).
