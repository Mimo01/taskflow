  <how-to-verify>
Start the app: `cd /Users/mimo/Documents/Projects/taskflow/taskflow && npm run tauri dev`

Then verify each item:

**SC-1 + SC-3 — Main nav sidebar drag:**
1. Hover over the right edge of the main navigation sidebar (the border between the sidebar and main content). The cursor should change to `ew-resize` and the border should highlight (subtle color change to ring/accent color).
2. Click and drag the edge to the right — sidebar should widen (max 320px).
3. Click and drag the edge to the left — sidebar should narrow (min 160px).
4. During drag: cursor stays as `ew-resize` even when moving fast, no text is selected, resize is smooth without jitter.

**SC-1 + D-01 — Collapse/expand coexistence:**
5. Drag the sidebar to a non-default width (e.g., ~280px).
6. Click the collapse chevron (or Cmd+B) — sidebar collapses to icon-only (~64px). The drag handle should disappear.
7. Click the collapse chevron again to expand — sidebar should restore to ~280px (your last drag position), NOT 224px default.

**D-02 — No drag handle in collapsed state:**
8. Collapse the sidebar. Hover over its right edge — cursor should remain default (not ew-resize). No drag should be possible.

**SC-2 + SC-3 — Issue detail right panel drag:**
9. Open any issue (navigate to a project issue).
10. Hover over the LEFT border of the right panel (between main content and the property/sidebar panel). Cursor changes to `ew-resize`, border highlights.
11. Drag left to widen the right panel (max: 50% of page width).
12. Drag right to narrow the right panel (min: 240px).

**SC-2 — MR detail right panel drag:**
13. Open a merge request detail page.
14. Repeat the hover + drag test on the left border of the right panel.

**SC-2 — Release detail right panel drag:**
15. Open a release detail page.

**SC-4 — Persistence:**
17. Drag the main nav sidebar to a non-default width (~280px) and drag one detail panel to a non-default width.
18. Close the app completely.
19. Reopen the app — sidebar and the detail panel should restore to the widths you set, not the defaults.

**SC-5 — Smoothness:**
20. During any drag, verify: no jank/stutter, no cursor flicker, no text gets selected, the layout doesn't jump.
