## Interaction Contract

### Progressive Section Loading

Each section (active sprint, future sprints, backlog-only) renders independently as its query resolves:

- **Loading state**: Show `BacklogSkeleton` per section while the section's query is pending (gated by `useDelayedLoading` — no skeleton shown if data arrives within 200ms)
- **Populated state**: Render the div-based virtualized table for the section
- **Empty state**: Show inline empty message (existing `<p>` pattern, not full EmptyState component) — "No issues match the current filters" or "This sprint has no issues"
- **Error state**: Show `ErrorState` component with retry affordance (existing pattern)

### Per-Row Epic Badge Loading (LOAD-04 completion)

- **While `allEpics` query is pending**: Each row's epic cell shows `<Skeleton className="h-4 w-14 rounded-full" />`
- **When `allEpics` resolves**: Skeleton swaps to colored epic badge (`inline-flex items-center rounded-full border px-1.5 py-0 text-[11px] font-medium`)
- **No layout shift**: Skeleton height (16px / h-4) matches badge height to prevent row height changes on swap
- **If issue has no epic**: Cell renders empty (no Skeleton, no badge) — same as current behavior

### Virtualization (Div-Based Rows)

- Each row is a `<div>` with CSS grid layout matching the current six-column table structure
- Column widths mirror current `<td>` widths: checkbox (32px), key (96px), epic (auto), summary (1fr), points (56px), assignee (40px)
- `useVirtualizer` from `@tanstack/react-virtual` applied to each section's issue list
- `overscanCount`: 5 rows above and below viewport
- `estimateSize`: 36px (py-2 top + py-2 bottom + ~20px content = ~36px at default density)
- Focused row visual: `border-l-2 border-primary bg-muted` (unchanged from current `isFocused` behavior)
- Row hover: `hover:bg-muted/30 transition-colors` (unchanged)

### Density Variants

Row padding responds to density data-attribute (inherited from existing system):
- `data-density="compact"`: `py-1` → ~28px estimated row height
- default: `py-2` → ~36px estimated row height
- `data-density="comfortable"`: `py-3` → ~44px estimated row height

The virtualizer `estimateSize` callback should read the current density setting and return the appropriate value.
