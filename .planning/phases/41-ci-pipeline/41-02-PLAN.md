The user must complete these steps before the pipeline can be tested. Claude cannot do these -- they require GitHub account access, secret creation, and key generation.

**Step 1: Create the public releases repo**
- Go to https://github.com/new
- Repository name: `taskflow-releases`
- Owner: `Mimo01`
- Visibility: Public
- Initialize with a README (optional)
- Create repository

**Step 2: Add version-policy.json to taskflow-releases**
- In the `taskflow-releases` repo, create a file `version-policy.json` at the repo root with this content:
  ```json
  {
    "softMinimum": "0.0.0",
    "hardMinimum": "0.0.0"
  }
  ```
- Commit to main branch. These safe defaults mean no version enforcement until intentionally bumped.

**Step 3: Generate Ed25519 signing key pair**
- In terminal, from the `taskflow` directory:
  ```bash
  cd /Users/mimo/Desktop/Tasker/taskflow
  npx tauri signer generate -w ~/.tauri/taskflow.key
  ```
- This outputs a public key string and saves the private key to `~/.tauri/taskflow.key`
- Copy the public key string (starts with `dW50cnVzdGVkI...`)
- Back up the private key file to a second location (it is irreversible)

**Step 4: Add pubkey to tauri.conf.json**
- Edit `taskflow/src-tauri/tauri.conf.json`
- In the `plugins.updater` section, add the `pubkey` field:
  ```json
  "plugins": {
    "updater": {
      "pubkey": "<paste the public key string here>",
      "endpoints": [
        "https://github.com/Mimo01/taskflow-releases/releases/latest/download/latest.json"
      ]
    }
  }
  ```
- Commit this change

**Step 5: Create fine-grained PAT for cross-repo publishing**
- Go to https://github.com/settings/personal-access-tokens/new
- Token name: `taskflow-releases-publish`
- Expiration: 90 days (or custom)
- Repository access: "Only select repositories" -> select `Mimo01/taskflow-releases`
- Permissions: Repository permissions -> Contents = Read and write
- Generate token, copy the value

**Step 6: Add GitHub secrets to the private repo**
- Go to https://github.com/Mimo01/taskflow/settings/secrets/actions
- Add these repository secrets:
  1. `RELEASES_REPO_TOKEN` = the fine-grained PAT from Step 5
  2. `TAURI_SIGNING_PRIVATE_KEY` = content of `~/.tauri/taskflow.key` (cat the file, paste entire content)
  3. `TAURI_SIGNING_PRIVATE_KEY_PASSWORD` = the password you set during key generation (or empty string if none)
  </action>
