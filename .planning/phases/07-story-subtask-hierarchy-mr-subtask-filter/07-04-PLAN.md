In `TaskCard.tsx`, fix the subtask count + chevron row (the block rendered when `subtaskCount != null && subtaskCount > 0`).

Current code:
```tsx
<div className="flex items-center gap-1">
  <Badge variant="secondary" className="text-xs py-0">
    {subtaskCount} subtask{subtaskCount !== 1 ? 's' : ''}
  </Badge>
  <button
    type="button"
    onClick={(e) => { e.stopPropagation(); onToggle?.() }}
    className="inline-flex items-center text-muted-foreground hover:text-foreground transition-colors"
    aria-label={isExpanded ? 'Collapse subtasks' : 'Expand subtasks'}
  >
    {isExpanded ? (
      <ChevronDown className="size-3" />
    ) : (
      <ChevronRight className="size-3" />
    )}
  </button>
</div>
```

Replace with a **single `<button>` wrapping both the Badge and the chevron icon**. This makes the entire row the hit target (~32-44px tall) instead of just the 12px icon:

```tsx
<button
  type="button"
  onClick={(e) => { e.stopPropagation(); onToggle?.() }}
  className="flex items-center gap-1 p-1 -mx-1 rounded text-muted-foreground hover:text-foreground transition-colors"
  aria-label={isExpanded ? 'Collapse subtasks' : 'Expand subtasks'}
>
  <Badge variant="secondary" className="text-xs py-0 pointer-events-none">
    {subtaskCount} subtask{subtaskCount !== 1 ? 's' : ''}
  </Badge>
  {isExpanded ? (
    <ChevronDown className="size-4" />
  ) : (
    <ChevronRight className="size-4" />
  )}
</button>
```

Key changes:
- Outer `<div>` removed; single `<button>` wraps both Badge and chevron
- `p-1 -mx-1` on the button: gives padding without displacing layout
- `pointer-events-none` on Badge: prevents nested click confusion (badge is decorative within the button)
- Icon size bumped from `size-3` (12px) to `size-4` (16px) for better visual affordance
- The `-mx-1` negative margin compensates for the left padding so the badge aligns with card content

No other changes to TaskCard.
