## Spacing Scale

Declared values (must be multiples of 4):

| Token | Value | Usage |
|-------|-------|-------|
| xs | 4px | Icon gaps, inline chip padding, checkbox-to-label gap |
| sm | 8px | Quick filter chip row gap, gap between bulk action buttons in floating bar |
| md | 16px | Sprint goal banner padding, filter chip row horizontal padding, floating bar internal padding |
| lg | 24px | Gap between sprint goal banner and filter chip row, saved filter list item padding |
| xl | 32px | Layout gaps, floating bulk action bar bottom offset from viewport |
| 2xl | 48px | Major section breaks |
| 3xl | 64px | Page-level spacing |

Exceptions: Floating bulk action bar uses `bottom: 32px` viewport offset. Sprint card checkbox uses a 20px rendered checkbox size (component dimension, not a layout spacing token) within a 44px minimum touch area (the card hover zone).

## Color

| Role | Value | Usage |
|------|-------|-------|
| Dominant (60%) | `var(--background)` oklch(1 0 0) / oklch(0.145 0 0) dark | Page background, floating bar background |
| Secondary (30%) | `var(--muted)` oklch(0.97 0 0) / oklch(0.269 0 0) dark | Sprint goal banner background, inactive quick filter chip background, saved filter list hover state |
| Accent (10%) | `var(--primary)` oklch(0.205 0 0) / oklch(0.922 0 0) dark | Active quick filter chip fill, "Apply" button in bulk actions, progress bar fill, save filter submit button |
| Destructive | `var(--destructive)` oklch(0.577 0.245 27.325) / oklch(0.704 0.191 22.216) dark | Delete filter confirmation, bulk operation failure count text |

Accent reserved for:
- Active quick filter chip (Badge variant="default" when toggled on)
- "Apply" primary action button in floating bulk action bar
- Bulk operation progress bar fill
- "Save Filter" submit button in save dialog
- Saved filter sidebar item active state

Sprint goal banner uses a distinct visual treatment: `bg-muted` background with `border-l-4 border-primary` left accent stripe, giving it visual prominence without consuming the accent color budget on a passive display element.

## Interaction Contracts

### Sprint Goal Banner (BOARD-01)

1. **Placement:** Rendered between the sprint name/header row and the filter area. Full width of the board content area.
2. **Styling:** `bg-muted` background, `border-l-4 border-primary` left accent stripe, `rounded-md`, `px-4 py-3`. Body text at 14px/400.
3. **Visibility:** Only rendered when `JiraActiveSprint.goal` is a non-empty string (D-02). No animation on mount.
4. **Overflow:** Full goal text always shown, banner grows vertically (D-03). No truncation, no expand/collapse.

### Quick Filter Chips (BOARD-02, BOARD-03)

1. **Placement:** Horizontal row between sprint goal banner and the existing UnifiedFilterBar (D-05). Same horizontal padding as UnifiedFilterBar.
2. **Chip rendering:** Each Jira quick filter from board config renders as a Badge. Labels also render as Badges in the same row (D-07). Jira QFs first, then label chips, separated by a subtle `border-r border-border` divider.
3. **Toggle behavior:** Click toggles on/off. Active chips use Badge `variant="default"` (primary fill). Inactive chips use Badge `variant="outline"`. Chips act independently (multi-select, not radio).
4. **Filter logic:** Active quick filters AND with existing UnifiedFilterBar selections (D-08). Quick filter JQL conditions are applied client-side by evaluating against issue fields where possible, or as an additional API parameter.
5. **Overflow:** If chips exceed container width, row scrolls horizontally with `overflow-x-auto no-scrollbar`. No wrapping.
6. **Keyboard:** Tab into chip row, arrow left/right between chips, Space/Enter to toggle.

### Bulk Operations (BOARD-04, BOARD-05, BOARD-06, BOARD-07)

1. **Card selection:** Checkbox appears as an overlay on the top-left corner of DraggableCard/TaskCard. Checkbox is visible on hover. Once any card is selected, all checkboxes become permanently visible until selection is cleared (D-09).
2. **Checkbox style:** Native `<input type="checkbox">` matching BacklogRow pattern. 16px checkbox with `2px` accent ring on focus. Position: absolute, top-left of card with `8px` offset from edges.
3. **Shift+click range:** Shift+clicking a card selects all cards between the last-clicked card and the current card (within the same swimlane column). Range is calculated by DOM order.
4. **Select all:** No global "select all" -- users build selections incrementally per D-09.
5. **DnD coordination:** When any checkbox is selected, drag-and-drop is disabled on selected cards to avoid accidental moves. Unselected cards remain draggable.
6. **Floating bar:** Fixed position at `bottom: 32px`, horizontally centered, `max-width: 640px`. Background: `bg-card` with `shadow-lg border border-border rounded-xl`. Internal layout: `flex items-center gap-4 px-4 py-3`.
7. **Bar contents (left to right):** Badge with "{N} selected" (variant="secondary") | Select dropdown "Status" | Select dropdown "Assignee" | Select dropdown "Priority" | "Apply Changes" Button (primary) | "Deselect All" Button (ghost).
8. **Dropdown options:** Status dropdown shows all project statuses grouped by category. Assignee dropdown shows project members. Priority dropdown shows Jira priority levels. All use the existing shadcn Select component.
9. **Apply flow:** Clicking "Apply Changes" disables the bar, replaces contents with BulkProgressIndicator. Parallel API calls (D-11). Progress bar fills as each call completes.
10. **Completion:** On all-success: Alert with success message, auto-dismiss after 3 seconds, bar returns to normal. On partial/full failure: Alert persists with failure count + "View Details" link that expands to show per-issue errors. Cards update optimistically with rollback on individual failures (D-12).
11. **Keyboard:** Escape clears selection and hides floating bar. Tab navigates between bar controls.

### Saved Filters (FILT-01, FILT-02, FILT-03, FILT-04)

1. **Save trigger:** "Save Filter" text button with BookmarkPlus icon appears in UnifiedFilterBar when at least one filter is active (D-15). Clicking opens SaveFilterDialog.
2. **Save dialog:** Modal Dialog with name Input (required, auto-focused), description Textarea (optional), and "Save to Jira" / "Discard" buttons. On submit, POST to `/rest/api/2/filter` with current filter state translated to JQL.
3. **Sidebar section:** "Saved Filters" section appears below existing nav links in Sidebar (D-14). Section header with Bookmark icon. Collapsible with chevron. Lists user's favourite Jira filters.
4. **Filter list items:** Each item: Bookmark icon + filter name (truncated at 24ch). Click applies the filter's JQL to the current board view. Active filter shown with checkmark icon and `font-semibold`. Context menu (right-click) with "Edit" and "Delete Filter" options.
5. **Edit flow:** Opens EditFilterDialog with current name, description, and JQL pre-filled. User can modify any field. "Update Filter" submits PUT to Jira. "Discard Changes" dismisses the dialog without saving.
6. **Delete flow:** Context menu "Delete Filter" opens a confirmation popover (not dialog). Destructive copy per copywriting contract. Deletes from Jira via DELETE API.
7. **Command palette:** Saved filters registered as searchable actions in command palette (D-16). Action icon: Bookmark. Executing applies the filter to the current view.
8. **Loading state:** Sidebar shows Skeleton placeholders (3 items, 16px height each) while fetching favourite filters.

## Accessibility Contract

| Requirement | Implementation |
|-------------|---------------|
| Sprint goal banner | `role="banner"` with `aria-label="Sprint goal"`. Rendered as Alert component (inherits `role="alert"`). |
| Quick filter chips | Container: `role="toolbar"` with `aria-label="Quick filters"`. Each chip: `role="switch"` with `aria-checked` reflecting toggle state. |
| Card checkboxes | `<input type="checkbox">` with `aria-label="{issueKey} - select for bulk action"`. Visible label not needed (card context provides it). |
| Shift+click range | Range selection announced via `aria-live="polite"` region: "{N} issues selected". |
| Floating bulk action bar | `role="toolbar"` with `aria-label="Bulk actions for {N} selected issues"`. Focus trapped when visible. |
| Bulk progress | `role="progressbar"` with `aria-valuenow` (completed count), `aria-valuemin="0"`, `aria-valuemax` (total count). `aria-live="polite"` for status updates. |
| Save filter dialog | Focus trapped. Name input auto-focused. Escape closes. Standard Dialog accessibility from shadcn. |
| Saved filter list | `role="listbox"` on container, `role="option"` + `aria-selected` on items for the currently applied filter. |
| Edit/Delete filter | Delete confirmation uses focus trap. Focus moves to "Discard" button (safe default) on open of save dialog; focus moves to "Discard Changes" button on open of edit dialog. |
