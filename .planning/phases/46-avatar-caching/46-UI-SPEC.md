> Visual and interaction contract for frontend phases. Generated by gsd-ui-researcher, verified by gsd-ui-checker.

## Phase Scope Note

Phase 46 is primarily a caching infrastructure phase. The sole new UI surface is a shared `<CachedAvatar>` component that replaces 12+ inline `<img>` avatar patterns across the codebase. No new pages, layouts, or modals are introduced. All design values below apply specifically to that component and its loading/error states.

## Component Contract: `<CachedAvatar>`

This is the only new component introduced in Phase 46.

### Props

| Prop | Type | Required | Description |
|------|------|----------|-------------|
| `url` | `string \| null \| undefined` | Yes | Original avatar URL (Jira `avatarUrls['48x48']` or GitLab `avatar_url`) |
| `name` | `string` | Yes | Display name — used to generate initials fallback |
| `size` | `20 \| 24 \| 32 \| 40` | No | Pixel size (default: 32). Maps to Tailwind `size-5`, `size-6`, `size-8`, `size-10` |
| `className` | `string` | No | Additional Tailwind classes for layout overrides |

### States

| State | Visual | Trigger |
|-------|--------|---------|
| Loading (image pending) | Initials fallback visible immediately. No skeleton circle — initials are already meaningful content. | Cache miss, first render |
| Loaded | Circular image replaces initials with no layout shift | Blob URL ready in memory cache |
| Error / no URL | Initials fallback persists. No broken image icon. | `onError` fired, or `url` is null/undefined |
| Cached hit | Circular image renders on first paint — no visible loading state | Blob URL already in memory Map |

### Visual Spec

- Shape: `rounded-full` (circle crop)
- Border: none (matches existing pattern)
- Initials generation: 1-2 characters from display name — first letter of first word + first letter of last word (if present), uppercase
- Initials container: `bg-muted flex items-center justify-center rounded-full`
- Image tag: `object-cover` to prevent distortion on non-square source images
- Transition: none — swap is instant when blob URL resolves (avoids fade flicker on cache hits)

### Placement in codebase

`taskflow/src/components/ui/cached-avatar.tsx` — lives in `components/ui/` alongside other primitive components, per shadcn convention.

Source: D-05, D-06 from 46-CONTEXT.md; TaskCard.tsx lines 106-136 (reference pattern).

## Copywriting Contract

| Element | Copy |
|---------|------|
| Primary CTA | Not applicable — no user-triggered actions in this phase |
| Avatar initials empty state | First 1-2 uppercase letters of the user's display name (e.g. "JD" for "Jane Doe") |
| Avatar error state | Show initials fallback silently — no visible error message to the user. Image errors are non-blocking and invisible |
| Destructive confirmation | Not applicable — no destructive actions in this phase |

Note: Avatar fetch failures are silent UX — the user sees the initials fallback with no indication that a network error occurred. This matches the existing onError pattern and preserves visual continuity.

Source: D-06 from 46-CONTEXT.md ("No skeleton circle — initials are already meaningful"), TaskCard.tsx onError pattern.

## Interaction Contract

No new user interactions are introduced. The `<CachedAvatar>` component is display-only. There are no click handlers, hover states, or focus states on the avatar element itself.

If a parent component wraps `<CachedAvatar>` in a clickable context (e.g. assignee picker), focus and hover styling is the parent's responsibility — not part of this component's contract.

---

## Accessibility Contract

- `<img>` element: `alt={name}` — always set to the user's display name. Never empty string.
- Initials fallback `<div>`: `aria-label={name}` — screen readers get the same text as the image alt.
- Role: implicit `img` role on the `<img>` tag; fallback div uses `role="img"`.
- Color contrast: initials text on `bg-muted` background must meet WCAG AA (4.5:1) at 10px. Use `text-foreground` (high contrast) over `text-muted-foreground` for the initials text to satisfy this.
