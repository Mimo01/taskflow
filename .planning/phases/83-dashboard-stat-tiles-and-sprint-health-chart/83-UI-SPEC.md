## Spacing Scale

Declared values (must be multiples of 4):

| Token | Value | Usage |
|-------|-------|-------|
| xs | 4px | Icon gaps, tile icon-to-label gap |
| sm | 8px | Tile inner padding, label-to-value gap |
| md | 16px | Card padding, stat-tile internal vertical rhythm |
| lg | 24px | Section padding, gap between stat tiles row and sprint-health section |
| xl | 32px | Gap between hero and first content section |
| 2xl | 48px | Major section vertical break |
| 3xl | 64px | (reserved; not used this phase) |

Exceptions:
- Stat tile minimum height: 80px (compact information display, not a touch-primary target).
- Donut chart container: explicit 200px height (WebKit 0×0 collapse guard, per Phase 81 D-05).
- Progress bar height: 8px (matches existing `Progress` primitive default).

## Typography

| Role | Size | Weight | Line Height |
|------|------|--------|-------------|
| Body | 14px (text-sm) | 400 (regular) | 1.5 |
| Label | 12px (text-xs) | 400 (regular) | 1.4 |
| Tile value | 28px (text-3xl) | 600 (semibold) | 1.2 |
| Section heading / card title | 16px (text-base) | 600 (semibold) | 1.2 |

Notes:
- "Tile value" is the large number displayed in each StatTile (e.g. "4", "0").
- Section headings follow the ChartWrapper convention: `text-base font-semibold text-foreground`.
- Label row (tile name, section sub-labels) uses `text-xs text-muted-foreground uppercase tracking-wide` to match existing dashboard card header pattern.
- Hero h1 (`text-6xl font-semibold`) is retained unchanged (D-01 / source: `dashboard/index.tsx` line 97).

## Color

| Role | Value | Usage |
|------|-------|-------|
| Dominant (60%) | `var(--background)` — oklch(1 0 0) light / oklch(0.145 0 0) dark | Page background, behind all sections |
| Secondary (30%) | `var(--card)` — oklch(1 0 0) light / oklch(0.205 0 0) dark | Stat tile card surfaces, sprint-health card surface, ChartWrapper background |
| Accent (10%) | `var(--primary)` — oklch(0.205 0 0) light / oklch(0.922 0 0) dark | Tile value number, progress bar fill (via Progress primitive) |
| Destructive | `var(--destructive)` — oklch(0.577 0.245 27.325) light | Overdue tile value and label (signals urgency); no destructive actions exist this phase |

Accent reserved for:
- The numeric value inside each StatTile (`text-primary` weight 600).
- The progress bar fill (via `Progress` component which uses `--primary` internally).
- NOT used on tile icons, section icons, or label text.

Chart status colors (donut segments — criterion 3, D-07):
- To Do segment: `var(--chart-1)` — oklch(0.809 0.105 251.813) — light blue
- In Progress segment: `var(--chart-2)` — oklch(0.623 0.214 259.815) — medium blue
- Done segment: `var(--chart-3)` — oklch(0.546 0.245 262.881) — deep blue

No hardcoded hex in chart segments. All three map to semantic `--chart-N` CSS-var aliases (source: `src/index.css` lines 105–109, 140–144).

Tile icon accent colors (contextual semantic):
- Open tile icon: `text-sky-500` (neutral active work)
- In Progress tile icon: `text-amber-500` (motion/in-flight, matches existing Zap icon in SprintCard)
- Overdue tile icon: `text-destructive` (urgency)
- SP Done tile icon: `text-green-500` (completion, matches existing CheckCircle2 in InProgressCard)

Overdue tile: entire value + label use `text-destructive` when `overdueCount > 0`; fall back to default foreground at zero.

Source: existing dashboard card conventions in `DashboardSprintCard.tsx` and `DashboardInProgressCard.tsx`.

## Component Inventory

New components to create under `src/routes/dashboard/`:

### `StatTile`

```
Props: label, value, icon (LucideIcon), iconClass?, valueClass?
Layout: vertical stack — icon + label row (xs gap) → large value number
Card surface: rounded-lg border border-border bg-card p-4
Min-height: 80px
States: Skeleton (3 pulse lines, matching existing pattern) | Data
```

Grid: four tiles in a row — `grid grid-cols-2 sm:grid-cols-4 gap-4` — under the hero, replacing the 3-card grid.

### `SprintHealthSection`

```
Props: sprintIssues, activeSprint, storyPointsFieldKey
Layout: Card surface (bg-card rounded-lg border border-border p-6) containing:
  Row 1: Sprint name (text-sm font-medium) + days-remaining badge (text-xs muted)
  Row 2: Progress bar (Progress primitive, value=donePct) + caption (text-xs muted)
  Row 3: Points-by-status DonutChart (200px height container)
States: Skeleton | ErrorState | EmptyState ("No active sprint") — each independent (D-11)
```

Donut chart: `PieChart` with `Pie` from Recharts v3, `innerRadius` 60%, `outerRadius` 80%, `isAnimationActive={false}`, `responsive` prop (Phase 81 D-03). Wrapped in `ChartWrapper`. Donut center label: total sprint SP value (`text-2xl font-semibold`) + "pts" caption (`text-xs muted`).

### Layout assembly in `dashboard/index.tsx`

```
<hero section>                         ← retained unchanged
<stat-tiles row>                       ← 4-tile grid, full-width, px-6 pt-0 pb-6
<sprint-health section>                ← full-width card, px-6 pb-6
<release countdown>                    ← DashboardReleaseCard logic, full-width card, px-6 pb-6
```

Release countdown: extracted from `DashboardReleaseCard` into a narrow single-row card (`flex items-center justify-between`) showing next-version name + countdown days. Placed below sprint-health. Exact visual treatment at executor discretion within this layout slot.

## Interaction Contract

### Stat Tiles (D-06 — static display only)

- No hover state beyond cursor default.
- No click handler. No drill-down. Tiles are not interactive elements.
- Do NOT use `role="button"`, `cursor-pointer`, or `hover:bg-*` on tile cards.
- Tiles are `<div>` with `role="region"` and `aria-label="{label} count"` for screen readers.

### Sprint Health Section

- Progress bar: not interactive (`aria-valuemin`, `aria-valuemax`, `aria-valuenow` from `Progress` primitive; no click).
- Donut chart: no tooltip on hover this phase (keep it simple; tooltip is discretionary for Phase 84+).
- `ChartWrapper` `onRetry` prop: pass the sprint-board query `refetch` so the error state retry button works.

### Independent Section Degradation (D-11)

- Stat tiles row has its own `Skeleton` when `isLoading`.
- Sprint health section has its own `Skeleton` | `ErrorState` | `EmptyState` via `ChartWrapper`.
- A failure in one section must not blank or error the other.

## Accessibility

- Each stat tile: `<div role="region" aria-label="{label}">` wrapping the card.
- Tile value: `<p aria-label="{value} {label}">` so screen readers read "4 Open" not just "4".
- Progress bar: uses shadcn `Progress` which exposes `role="progressbar"` with `aria-valuenow`.
- Donut chart: `aria-label="Points by status: To Do {N}%, In Progress {N}%, Done {N}%"` on the chart container.
- Sprint health card: `role="region" aria-label="Sprint health"`.
- All lucide icons: `aria-hidden="true"` (decorative).
