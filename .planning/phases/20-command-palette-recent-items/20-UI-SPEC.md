# Phase 20 -- UI Design Contract

> Visual and interaction contract for the command palette, recent items popover, and navigation shortcuts. Generated by gsd-ui-researcher, verified by gsd-ui-checker.

---

## Design System

| Property | Value |
|----------|-------|
| Tool | shadcn |
| Preset | base-nova (neutral base color, CSS variables, 0.625rem radius) |
| Component library | shadcn/ui (Radix primitives under the hood) |

## Spacing Scale

Declared values (must be multiples of 4):

| Token | Value | Usage |
|-------|-------|-------|
| xs | 4px | Icon-to-text gaps inside palette rows, inline padding |
| sm | 8px | Palette row vertical padding, popover item padding |
| md | 16px | Palette container horizontal padding, section gaps |
| lg | 24px | Palette top margin from viewport top (mt-16 = 64px used by existing overlay) |
| xl | 32px | Not used in this phase |
| 2xl | 48px | Not used in this phase |
| 3xl | 64px | Palette vertical offset from viewport top (mt-16) |

Exceptions: The palette backdrop uses `mt-16` (64px from top) matching the existing SearchOverlay pattern. Touch target minimum is 32px height for each palette result row.

## Typography

| Role | Size | Weight | Line Height | Usage in this phase |
|------|------|--------|-------------|---------------------|
| Body | 14px (text-sm) | 400 (normal) | 1.43 (20px) | Palette result item text, recent items popover rows |
| Label | 12px (text-xs) | 600 (semibold) | 1.33 (16px) | Group headings ("Issues", "Merge Requests", "Navigation", "Actions", "Recent Items"), shortcut hint badges |
| Heading | 14px (text-sm) | 600 (semibold) | 1.43 (20px) | Popover header title ("Recent Items") |
| Mono | 14px (text-sm) | 400 (normal) | 1.43 (20px) | Issue keys (PROJ-123), MR identifiers (!42) -- font-mono class |

Note: The project uses Tailwind's default type scale. No custom font sizes are introduced. All text in this phase uses text-xs (12px) or text-sm (14px) only.

## Color

All colors use the existing shadcn CSS variable system. No new color tokens are introduced.

| Role | Token | Usage |
|------|-------|-------|
| Dominant (60%) | `--background` / `--popover` | Palette backdrop overlay (bg-background/80), palette container surface, popover surface |
| Secondary (30%) | `--muted` | Hover state on palette rows (hover:bg-muted), active/selected row highlight, loading skeleton pulse |
| Accent (10%) | `--primary` | Palette input caret color (inherits), keyboard shortcut badge text when focused |
| Muted text | `--muted-foreground` | Group heading labels, placeholder text, issue key prefix, shortcut hint text |
| Destructive | `--destructive` | Not used in this phase (no destructive actions) |

Accent reserved for: Keyboard focus ring on the active palette result row (cmdk [aria-selected] uses primary). No other accent usage in this phase.

## Interaction Contract

### Palette triggers
| Trigger | Action |
|---------|--------|
| `Cmd+K` (macOS) / `Ctrl+K` (Win/Linux) | Open palette. Uses react-hotkeys-hook (`useHotkeys('mod+k', ...)`) |
| Search icon click in TopBar | Open palette (same state as Cmd+K) |
| `Escape` | Close palette. Uses cmdk built-in + react-hotkeys-hook with `enableOnFormTags: true` |
| Backdrop click | Close palette |

### Palette keyboard navigation
| Key | Action |
|-----|--------|
| Arrow Up / Arrow Down | Move selection through results (cmdk built-in) |
| Enter | Execute selected item (open issue, navigate, run action) |
| Type any character | Filter results with fuzzy matching (cmdk built-in) |

### Palette item actions
| Item type | On select |
|-----------|-----------|
| Jira issue (cached) | Call `onIssueClick(issueKey)` to open IssueDetailSheet, close palette |
| GitLab MR (cached) | Open MR URL in default browser (`open(url)`), close palette |
| Navigation action | Call `navigate(route)` or open popover, close palette |
| App action (Toggle theme) | Toggle theme in settings store, close palette |
| App action (Mark all read) | Call `markAllRead()` in notifications store, close palette |
| "Search Jira for X" | Fire live search query, show results inline with loading skeleton |

### Navigation shortcuts
| Shortcut | Action | Scope |
|----------|--------|-------|
| `Cmd+Shift+S` / `Ctrl+Shift+S` | Navigate to Sprint Board route | Global (not in inputs) |
| `Cmd+Shift+B` / `Ctrl+Shift+B` | Navigate to Backlog route | Global (not in inputs) |
| `Cmd+Shift+N` / `Ctrl+Shift+N` | Open notification popover | Global (not in inputs) |

### Recent items popover
| Trigger | Action |
|---------|--------|
| Clock icon click | Toggle popover open/closed |
| Click recent Jira item | Call `onIssueClick(issueKey)`, close popover |
| Click recent GitLab MR | Open MR URL in browser, close popover |
| Click outside popover | Close popover (Radix Popover default) |

### Recent items tracking
| Event | Tracking action |
|-------|----------------|
| IssueDetailSheet opens (any entry point) | Push issue key to recent items store |
| GitLab MR opened in browser (any entry point) | Push MR ID + URL to recent items store |
| Store exceeds 10 items | Drop oldest entry |
