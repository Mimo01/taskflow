  <action>
Create `taskflow/src/components/app/CommandPalette.tsx` -- a full command palette overlay using shadcn Command (NOT CommandDialog -- CommandDialog uses Radix Dialog which conflicts with @base-ui/react).

**Props interface:**
```typescript
interface CommandPaletteProps {
  open: boolean;
  onClose: () => void;
  onIssueClick: (issueKey: string) => void;
  onNavigate: (path: string) => void;
  onOpenNotifications: () => void;
}
```

**Component structure:**
- If `!open`, return null (no rendering when closed)
- Fixed backdrop: `className="fixed inset-0 z-50 bg-background/80 backdrop-blur-sm"` with `onClick={onClose}`
- Inner container: `className="max-w-xl mt-16 mx-auto"` with `onClick={(e) => e.stopPropagation()}`
- Command component: `className="rounded-lg border shadow-lg bg-popover"`
- CommandInput: `placeholder="Search issues, MRs, and actions..."`
- CommandList: `className="max-h-[300px]"`
- CommandEmpty: "No matches -- try different keywords"

**State management:**
- `const [query, setQuery] = useState('')` -- track input via CommandInput's `onValueChange`
- Escape handling: `useHotkeys('escape', onClose, { enableOnFormTags: true })` -- imported from react-hotkeys-hook

**Cached data access (NO API calls for cached results):**
- Use `useQueryClient()` to get queryClient
- Read settings store: `const { storyPointsFieldKey } = useSettingsStore()`
- Read auth store: `const { jiraBaseUrl, gitlabBaseUrl, activeJiraProject } = useAuthStore()`
- Read cached my-tasks: `queryClient.getQueryData(['jira-issues', 'my-tasks', activeJiraProject, storyPointsFieldKey])`
- Read cached sprint-board: `queryClient.getQueryData(['jira-issues', 'sprint-board', activeJiraProject, storyPointsFieldKey])`
- Read cached gitlab MRs: iterate over queryClient's cache entries matching `['gitlab-mrs']` query key prefix (since userId may vary, use `queryClient.getQueriesData({ queryKey: ['gitlab-mrs'] })`)
- Deduplicate issues by key using a Map: merge my-tasks + sprint-board issues, keep first occurrence
- Flatten MRs: merge assigned + reviewRequested, deduplicate by iid

**Default state (<2 chars typed -- `query.length < 2`):**
Show two CommandGroups:
1. "Recent Items" -- from `useRecentItemsStore().items`. For each RecentItem, render:
   - Jira items: `<CommandItem value={item.id} onSelect={() => { onIssueClick(item.id); onClose(); }}>`  with text showing issue key. Use `keywords={[item.id]}` so cmdk can match.
   - GitLab items: `<CommandItem onSelect={() => { openUrl(item.url!); onClose(); }}>` with MR id
   - If no recent items, show "No recent items" as a disabled CommandItem
   - Look up title from react-query cache for display. For Jira issues, search the deduped issues Map by key. For GitLab MRs, search the MRs array by iid. Fallback to showing just the key/id if not in cache.
2. "Navigation" -- static items (always visible in default state):
   - "Sprint Board" with shortcut hint `<CommandShortcut>⌘⇧S</CommandShortcut>`, onSelect calls `onNavigate('/sprint-board'); onClose()`
   - "Backlog" with `<CommandShortcut>⌘⇧B</CommandShortcut>`, onSelect calls `onNavigate('/backlog'); onClose()`
   - "Notifications" with `<CommandShortcut>⌘⇧N</CommandShortcut>`, onSelect calls `onOpenNotifications(); onClose()`
   - "Settings" (no shortcut hint), onSelect calls `onNavigate('/settings'); onClose()`

**Search state (>=2 chars typed -- `query.length >= 2`):**
Show these CommandGroups:
1. "Issues" -- filtered cached Jira issues. Each item: `<CommandItem value={issue.key + ' ' + issue.fields.summary} onSelect={() => { onIssueClick(issue.key); onClose(); }}>` showing `<span className="text-muted-foreground font-mono">{issue.key}</span> <span className="truncate">{issue.fields.summary}</span>`
2. "Merge Requests" -- filtered cached GitLab MRs. Each item: onSelect calls `openUrl(mr.web_url); onClose()`. Show `!{mr.iid}` prefix and `{mr.title}`.
3. "Navigation" -- same as default state (cmdk will filter to matches)
4. "Actions" -- app actions (only shown in search state, cmdk filters to matches):
   - "Toggle theme" with `keywords={['theme', 'dark', 'light', 'appearance']}`, onSelect: cycle theme using THEME_CYCLE pattern from ThemeToggle.tsx: `const THEME_CYCLE: Theme[] = ['light', 'dark', 'system']; const { theme, setTheme } = useSettingsStore(); const nextTheme = THEME_CYCLE[(THEME_CYCLE.indexOf(theme) + 1) % THEME_CYCLE.length]; applyTheme(nextTheme); setTheme(nextTheme); saveTheme(nextTheme); onClose();`
   - "Mark all notifications read" with `keywords={['notification', 'unread', 'clear']}`, onSelect: `useNotificationsStore.getState().markAllRead(); onClose();`
5. After a `<CommandSeparator />`, render the "Search Jira for X" tail item:
   - `<CommandItem forceMount onSelect={handleLiveSearch} value="search-jira-live-query">Search Jira for "{query}"</CommandItem>`
   - Live search: use react-query `useQuery` with key `['search', 'live', query]`, `enabled: query.length >= 2 && liveSearchTriggered`, `staleTime: 30_000`. The query function calls `searchJira(jiraBaseUrl, jiraToken, activeJiraProject, query)` -- read jiraToken from Stronghold via `readSecret('jira-pat')`.
   - When tail item is selected, set `liveSearchTriggered = true` to enable the query. Show results inline as additional issue items with a loading skeleton (3 `<div className="h-9 rounded bg-muted animate-pulse" />`) while loading.
   - Use `keepPreviousData: true` (or `placeholderData: keepPreviousData` in TanStack Query v5 syntax) to avoid flash-to-empty on query change.

**Important anti-patterns to avoid:**
- Do NOT use `CommandDialog` -- it wraps Radix Dialog which conflicts with @base-ui/react
- Do NOT use `createContext`/`useContext` -- project rule: prop threading only
- Do NOT add `useQuery` to TopBar -- search logic stays in CommandPalette
- Use `openUrl` from `@tauri-apps/plugin-opener` for MR links (not window.open)
