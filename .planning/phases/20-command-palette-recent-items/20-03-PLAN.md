**PopoverContent:** `className="p-0 w-80"` (matching NotificationPopover width)

**Inner layout (matching NotificationPopover pattern):**
1. Header: `<div className="flex items-center justify-between p-3 border-b"><span className="font-semibold text-sm">Recent Items</span></div>`
2. List: `<div className="overflow-y-auto max-h-[400px]">`
3. Empty state: `<div className="p-6 text-center text-sm text-muted-foreground">No recent items yet</div>`
4. Item rows: `<button className="w-full text-left px-3 py-2 text-sm hover:bg-muted flex gap-2">` for each RecentItem

**Title lookup from react-query cache:**
- Use `useQueryClient()` to access cache
- For Jira items: search all query data matching `['jira-issues']` prefix for an issue with matching key. Display `{issue.key}: {issue.fields.summary}` if found, else just `{item.id}` as fallback.
- For GitLab items: search query data matching `['gitlab-mrs']` prefix for MR with matching iid. Display `!{mr.iid}: {mr.title}` if found, else `!{item.id}` as fallback.

**Item click behavior:**
- Jira item: call `onIssueClick?.(item.id)` to open IssueDetailSheet
- GitLab item: call `openUrl(item.url!)` to open in browser

**Row display:**
- Clock icon (small, `w-4 h-4 text-muted-foreground`) on the left of each row
- Issue key/MR id in `font-mono text-muted-foreground`
- Title text with `truncate` class

Export as default: `export default function RecentItemsPopover`
