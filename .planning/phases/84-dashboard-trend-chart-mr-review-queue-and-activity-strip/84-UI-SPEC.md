## Spacing Scale

Declared values (must be multiples of 4). Matches Phase 83 dashboard layout:

| Token | Value | Usage |
|-------|-------|-------|
| xs | 4px | Icon gaps, inline label padding |
| sm | 8px | Row item gaps, badge padding |
| md | 16px | Card internal padding, section gap between chart and label |
| lg | 24px | Card padding (`p-6` = 24px, matching `ChartWrapper`) |
| xl | 32px | Layout gaps between major dashboard sections |
| 2xl | 48px | Not used in this phase |
| 3xl | 64px | Not used in this phase |

Exceptions:
- Dashboard outer columns use `px-6 pb-6` (24px) — matches Phase 83 pattern exactly (`index.tsx` lines 148, 197, 208).
- Stat tile minimum height: 80px (`min-h-[80px]`) — inherited from `StatTile.tsx`.
- Card minimum height for MR queue and activity strip: 160px (`min-h-[160px]`) — matches `MrHealthPanel` existing pattern.
- Touch targets for the "+N more" overflow button: minimum 32px height.

Source: `index.tsx`, `StatTile.tsx`, `MrHealthPanel.tsx`, `ChartWrapper.tsx`

- "+N more" overflow indicator: `text-xs text-muted-foreground`.

Source: `ChartWrapper.tsx`, `StatTile.tsx`, `MrHealthPanel.tsx`, `index.tsx`

## Color

| Role | Value | Usage |
|------|-------|-------|
| Dominant (60%) | `var(--background)` — `oklch(1 0 0)` light / `oklch(0.145 0 0)` dark | Page background |
| Secondary (30%) | `var(--card)` — same as background light, `oklch(0.205 0 0)` dark | All dashboard cards (ChartWrapper, MR queue card, activity strip card) |
| Accent (10%) | `var(--chart-1..5)` OKLCH blue spectrum | Reserved for: chart bars, activity icon tints, health badge colors |
| Destructive | `var(--destructive)` — `oklch(0.577 0.245 27.325)` light | Token-load errors, auth errors (via `ErrorState`) |

Accent reserved for:
- `var(--chart-1)` — weekly trend bar fill (logged hours bars)
- `var(--chart-2)` — reference line / 8h target marker stroke (ReferenceLine)
- `var(--chart-3)` — "In Progress" status in any chart context
- `var(--chart-4)` / `var(--chart-5)` — reserved, not used this phase
- `text-sky-500` — activity strip Jira icon tint (matches existing `Activity` icon tint in `index.tsx`)
- `text-amber-500` — GitLab commit icon tint (matches `Zap` icon tint pattern)
- `text-green-500` — "approved" MR health badge indicator dot
- `text-amber-500` — "needs_review" MR health badge indicator dot
- `text-destructive` — "changes_requested" MR health badge indicator dot

Color rules:
- All chart colors MUST use `var(--chart-N)` CSS variables — never hardcoded hex (CONTEXT D-01, criterion from Phase 81).
- Card borders: `border-border` (existing pattern).
- Muted text: `text-muted-foreground`.
- Empty/disabled states: `text-muted-foreground` with `size-12` icon.

Source: `index.css` (chart-1..5 OKLCH tokens, both themes), `SprintHealthSection.tsx`, `index.tsx`

## Component Inventory

New components for this phase (under `src/routes/dashboard/`):

### WeeklyTrendChart

Wraps a Recharts `BarChart` in `ChartWrapper`. Renders Mon–Fri logged hours per day with a `ReferenceLine` at y=8.

| Property | Value |
|----------|-------|
| Container | `ChartWrapper` with `title="Hours logged this week"` `height={240}` |
| Chart type | `BarChart` with `Bar` (logged hours) + `ReferenceLine` (y=8, `stroke="var(--chart-2)"`) |
| X-axis | Day abbreviations: Mon / Tue / Wed / Thu / Fri |
| Y-axis | Hours (0–12, tick at 0, 4, 8, 12) |
| Bar fill | `var(--chart-1)` |
| Animation | `isAnimationActive={false}` — WebKit guard (Phase 81 D-06) |
| Responsive | `responsive` prop on `BarChart` (never `ResponsiveContainer`) |
| Outer div | Explicit height div wrapping `ChartContainer` (0×0 WebKit guard) |
| `'use no memo'` | Required at top of file (Phase 81 D-07, React Compiler conflict) |
| Tempo-off state | `isEmpty` with custom copy (not `error`) — see Copywriting |
| Loading state | `isLoading` prop → `ChartWrapper` renders `Skeleton` |
| Error state | `error` prop → `ChartWrapper` renders `ErrorState` |
| Section wrapper | `role="region"` `aria-label="Weekly hours logged"` |

## Layout — Dashboard Section Order

Top to bottom (matches CONTEXT "Claude's Discretion" delegation):

1. **Hero** — gradient greeting, full-width (existing, unchanged)
2. **Stat tiles row** — 2×2 / 1×4 grid (Phase 83, existing)
3. **Sprint health + Weekly trend charts** — side-by-side on wide screens: `grid grid-cols-1 lg:grid-cols-2 gap-4` wrapping `SprintHealthSection` (left) and `WeeklyTrendChart` (right). On narrow: stacked.
4. **MR review queue** — full-width card
5. **Activity & Releases** — two-column grid: `ActivityStrip` (left) + `DashboardReleaseCard` (right)

Section padding: each section block uses `relative px-6 pb-6` consistent with existing `index.tsx` pattern.

Independent degradation: each section renders its own loading / error / empty state. One section's failure does not affect others (DASH-07, CONTEXT D-17).

## Interaction Contract

| Component | Interaction | Behavior |
|-----------|-------------|----------|
| WeeklyTrendChart | Hover bar | Recharts default tooltip showing day + hours (no custom tooltip needed this phase) |
| WeeklyTrendChart | Tempo off | Renders EmptyState — no retry, no action button |
| MrReviewQueue | Click MR row | `open(mr.web_url)` in external browser (existing GitLab-open pattern) |
| MrReviewQueue | GitLab disconnected | EmptyState — no action button (not a settings deep-link — out of scope) |
| ActivityStrip | "+N more" | Button renders but does not expand (deferred); cursor-pointer, no click handler this phase |
| ActivityStrip | Click activity item | No click action this phase — items are display-only |
| All sections | Error state | Shows `ErrorState` with "Retry" button via `onRetry` prop |
| All sections | Loading | Shows `Skeleton` rows with `useDelayedLoading` (300ms delay, prevents flash) |

Prohibited:
- StatTile: no click handlers, no hover background, no `role="button"` (inherited from Phase 83, `StatTile.tsx` comment D-06).
- No new polling intervals on MR queue or activity strip — strictly cache-derived or shared-key.
- No `ResponsiveContainer` — use `responsive` prop on `BarChart` (Phase 81 rule).
- No `toISOString()` for date bucketing — use `dateStarted` / `slice(0, 10)` (CONTEXT D-04).

## Accessibility Contract

| Rule | Detail |
|------|--------|
| Section landmarks | Each new card/section uses `role="region"` with `aria-label` |
| Chart axes | `BarChart` with `XAxis`/`YAxis` — Recharts renders SVG text; add `aria-label` to chart container |
| MR row links | Each MR row must be a `<button>` (not `div`) or use the overlay-button pattern (project memory `project_overlay_button_nested_interactive`) |
| Color alone | Health badge dots always paired with text label — never color alone |
| Empty state icons | `aria-hidden` on decorative icons in `EmptyState` (inherits from existing `EmptyState` component) |
| Skeleton | `aria-busy="true"` on skeleton wrapper regions |
