**operation-profiler.store.ts — New file:**

Create `taskflow/src/stores/operation-profiler.store.ts` with:

```typescript
import { create } from 'zustand';

export interface FetchRecord {
  id: string;
  source: 'jira' | 'gitlab';
  method: string;
  url: string;
  status: number | null;
  durationMs: number;
  startTime: number;
  error?: string;
}

export interface Operation {
  id: string;
  label: string;
  startTime: number;
  endTime: number;
  wallClockMs: number;
  serverTimeMs: number;
  fetches: FetchRecord[];
  timestamp: string;
}

interface OperationProfilerState {
  operations: Operation[];
  ungrouped: FetchRecord[];
  activeOps: Map<string, { label: string; fetches: FetchRecord[]; timer: ReturnType<typeof setTimeout> }>;
  addFetch: (label: string | undefined, record: FetchRecord) => void;
  clear: () => void;
}

const OP_TIMEOUT_MS = 2000;
```

The store logic:
- `addFetch(label, record)`: If `label` is undefined, push to `ungrouped` array. If `label` is provided, check `activeOps` map for an existing entry with that label. If found, push the fetch record, reset the timer. If not found, create a new activeOps entry with a 2-second timer. When the timer fires, finalize the operation: compute `startTime = min(fetches[].startTime)`, `endTime = max(fetches[].startTime + fetches[].durationMs)`, `wallClockMs = endTime - startTime`, `serverTimeMs = sum(fetches[].durationMs)`, set `timestamp = new Date().toISOString()`, push to `operations` array (newest first), remove from `activeOps`, and enforce retention limit (read from settings store same as debug-log).
- `clear()`: Clear `operations`, `ungrouped`, and cancel all active timers in `activeOps`.
- Export `useOperationProfilerStore`.

Use `Map` for `activeOps` (not persisted — in-memory only, no persist middleware).
