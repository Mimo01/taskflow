## Typography

| Role | Size | Weight | Line Height |
|------|------|--------|-------------|
| Body | 14px | 400 (regular) | 1.5 |
| Label | 12px | 600 (semibold) | 1.33 |
| Heading | 24px | 700 (bold) | 1.2 |
| Mono | 12px | 400 (regular) | 1.5 |

Notes:
- All data values (URLs, durations, status codes, timestamps) use `font-mono` at 12px.
- Section labels (e.g. "URL", "Request Headers", tab labels) use Label role at 12px semibold uppercase with `tracking-wider` and `text-muted-foreground`.
- Page heading ("Developer Tools") uses Heading role at 24px bold, matching existing DebugLogs page pattern (`text-2xl font-bold`).
- This is a power-user, information-dense page. 14px body (not 16px) is appropriate.

## Layout Contract

### Page structure

```
+--------------------------------------------------+
| Developer Tools                      [Clear]      |
| (subtitle text)                                   |
+--------------------------------------------------+
| [> Settings]  (collapsible, collapsed by default) |
|   [ ] Enable Developer Tools (master)             |
|   [ ] Request logging                             |
|   [ ] Response body capture                       |
|   [ ] Operation profiling                         |
|   [ ] Performance waterfall                       |
|   Retention: [200 v]                              |
+--------------------------------------------------+
| [Logs] [Operations] [Waterfall]                   |
+--------------------------------------------------+
|                                                   |
|  (active tab content)                             |
|                                                   |
+--------------------------------------------------+
```

- Page container: `max-w-5xl mx-auto py-8 px-4` (wider than existing debug logs `max-w-4xl` to accommodate waterfall bars)
- Settings panel above tabs, full width
- Tabs use shadcn `Tabs` component with `variant="default"`
- Tab content scrolls independently (page scrolls, not tab panel)

### Waterfall bar layout

```
| Operation name (200px) | [====bar====]  120ms    |
|   GET /rest/api/...    |    [==bar==]   45ms     |
|   GET /rest/api/...    |      [===bar===] 75ms   |
```

- Left column: fixed 200px for labels, truncated with ellipsis
- Right column: flex-1, position-relative container
- Bars: position-absolute, left and width as percentages of total timeline
- Bar height: 20px for operations, 16px for nested fetches
- Vertical gap between rows: 4px
- Nested fetch rows indented 24px from parent

## Interaction Contract

| Interaction | Behavior |
|-------------|----------|
| Tab switch | Instant content swap, no animation. Selected tab shows active state |
| LogCard expand/collapse | Click summary row toggles detail panel. Chevron rotates (existing pattern) |
| OperationCard expand/collapse | Click summary toggles per-fetch breakdown rows |
| Ungrouped section expand/collapse | Click header toggles visibility of ungrouped request cards |
| Settings panel expand/collapse | Click header toggles settings visibility |
| Master toggle off | All granular toggles become visually disabled (`opacity-50 pointer-events-none`) |
| Clear button | Clears all logs, operations, and waterfall data. Disabled when empty (`disabled:opacity-40 disabled:cursor-not-allowed`) |
| Waterfall bars | Read-only. No hover tooltips, no click interaction. Duration label inline |
| Keyboard: Cmd+Shift+D | Navigate to /dev-tools from anywhere in the app |

## State Contracts

### Dev Tools not enabled (master toggle off)

All three tabs show a centered message: "Developer Tools are disabled. Toggle the master switch in Settings to start capturing data." in `text-sm text-muted-foreground`. Settings panel remains interactive.

### Individual toggle off

If a specific feature toggle is off (e.g., "Operation profiling" off), the corresponding tab shows its empty state with a hint pointing to the toggle. Other tabs function normally.

### Data present

Logs tab: newest-first list of `LogCard` components, same pattern as existing `DebugLogs.tsx`.
Operations tab: grouped operation cards, newest first. Ungrouped section at bottom.
Waterfall tab: timeline visualization with operation rows.
