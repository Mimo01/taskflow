**WaterfallTab.tsx:**

Read `devToolsEnabled`, `performanceWaterfall` from settings store. Read `operations` from operation profiler store.

State rendering:
- If `!devToolsEnabled`: disabled state message.
- If `!performanceWaterfall` or no operations: empty state heading "No waterfall data" + body "Enable performance waterfall in Settings above, then perform some actions to see timing data."
- Otherwise: render waterfall.

Waterfall layout:
1. Compute timeline bounds: `timelineStart = Math.min(...operations.map(o => o.startTime))`, `timelineEnd = Math.max(...operations.map(o => o.endTime))`, `totalDuration = timelineEnd - timelineStart`.

2. If `totalDuration === 0`, show a single operation with 100% width.

3. Time axis header row: show `0ms` on left, `{Math.round(totalDuration)}ms` on right, and a midpoint label.

4. For each operation, render a `<WaterfallBar>` row. Operations are expandable (useState per operation, or a Set of expanded IDs).

**WaterfallBar.tsx:**

Props: `{ operation: Operation; timelineStart: number; totalDuration: number; }`.

Expandable row with two columns:
- Left (200px fixed): label, truncated with ellipsis. `className="w-[200px] shrink-0 truncate text-sm"`.
- Right (flex-1, position-relative): bar container.

Operation bar:
```typescript
const leftPct = ((operation.startTime - timelineStart) / totalDuration) * 100;
const widthPct = (operation.wallClockMs / totalDuration) * 100;
```

Render:
```
<div className="relative h-5" style={{ left: `${leftPct}%`, width: `${Math.max(widthPct, 1)}%` }}>
  <div className="absolute inset-0 bg-muted rounded-sm" />
  <span className="relative text-xs font-mono ml-1 leading-5">{operation.wallClockMs}ms</span>
</div>
```

When expanded, show nested fetch bars indented 24px. Each fetch bar:
- Color by source: Jira = `bg-blue-200 dark:bg-blue-800`, GitLab = `bg-orange-200 dark:bg-orange-800`. Error fetches: `bg-red-200 dark:bg-red-800`.
- Height: 16px (4px shorter than operation bars).
- Left and width computed relative to the same timeline.
- Fetch `startTime` is an absolute `performance.now()` value. `leftPct = ((fetch.startTime - timelineStart) / totalDuration) * 100`. `widthPct = (fetch.durationMs / totalDuration) * 100`.

Row gap: `gap-1` (4px) between rows per UI-SPEC.
