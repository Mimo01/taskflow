**Create `taskflow/src/components/app/PinnedTabStrip.tsx`:**

Props interface:
```typescript
interface PinnedTabStripProps {
  pinnedKeys: string[];
  activeKey: string | null;
  onTabClick: (issueKey: string) => void;
  onTabClose: (issueKey: string) => void;
}
```

Component implementation:

1. Import: `X` from lucide-react, `Popover`/`PopoverTrigger`/`PopoverContent` from `../ui/popover`, `useQueryClient` from @tanstack/react-query, `Bug`/`BookOpen`/`CheckSquare`/`CornerDownRight`/`FileText` from lucide-react (for issue type icons)

2. Create a helper function `resolveIssueFromCache(queryClient, issueKey)` that:
   - Searches `queryClient.getQueriesData({ queryKey: ['jira-issues'] })` for matching issue key — both flat array and `{ issues: [] }` shapes
   - Searches `queryClient.getQueriesData({ queryKey: ['jira-backlog-view'] })` for sprints[].issues and backlog arrays
   - Searches `queryClient.getQueriesData({ queryKey: ['jira-issue-detail', issueKey] })` for direct detail cache
   - Returns `{ summary: string; issueTypeName: string } | undefined`
   - This follows the same cache search pattern as `handleIssueClick` in main.tsx

3. Create a helper function `issueTypeIcon(typeName: string)` that maps issue type name to a lucide icon component:
   - `'Bug'` -> `<Bug className="size-3.5 text-red-500" />`
   - `'Story'` -> `<BookOpen className="size-3.5 text-green-600" />`
   - `'Subtask'` or `'Sub-task'` -> `<CornerDownRight className="size-3.5 text-blue-500" />`
   - `'Epic'` -> `<BookOpen className="size-3.5 text-purple-500" />`
   - default (Task, etc.) -> `<CheckSquare className="size-3.5 text-blue-500" />`

4. Component body:
   - `const queryClient = useQueryClient()`
   - Slice pinnedKeys: `const visibleKeys = pinnedKeys.slice(0, 7)` and `const overflowKeys = pinnedKeys.slice(7)`
   - Render outer container: `<div className="h-9 border-b border-border flex items-center gap-1 px-4 flex-shrink-0 bg-background" role="tablist" aria-label="Pinned issues">`
   - For each key in visibleKeys, render a tab button:
     ```tsx
     <button
       key={key}
       role="tab"
       aria-selected={key === activeKey}
       onClick={() => onTabClick(key)}
       className={cn(
         "flex items-center gap-1 px-2 h-7 min-w-[120px] max-w-[200px] rounded-t-md text-xs font-medium border-b-2 transition-colors group",
         key === activeKey
           ? "border-primary text-foreground bg-muted/50"
           : "border-transparent text-muted-foreground hover:bg-muted hover:text-foreground"
       )}
     >
       {issueTypeIcon(resolved?.issueTypeName ?? '')}
       <span className="font-mono">{key}</span>
       <span className="truncate">{resolved?.summary ?? ''}</span>
       <button
         type="button"
         onClick={(e) => { e.stopPropagation(); onTabClose(key); }}
         className="ml-auto opacity-0 group-hover:opacity-100 transition-opacity"
         aria-label={`Close ${key} tab`}
       >
         <X className="size-3.5 text-muted-foreground hover:text-foreground" />
       </button>
     </button>
     ```
   - Resolve issue data per key using `resolveIssueFromCache(queryClient, key)` — call this for each visible and overflow key
   - If `overflowKeys.length > 0`, render a Popover:
     ```tsx
     <Popover>
       <PopoverTrigger
         className="text-xs font-semibold px-2 py-1 rounded bg-muted text-muted-foreground hover:bg-accent"
         aria-label={`Show ${overflowKeys.length} more pinned tabs`}
       >
         +{overflowKeys.length}
       </PopoverTrigger>
       <PopoverContent className="p-1 w-64 max-h-60 overflow-y-auto">
         {overflowKeys.map((key) => {
           const resolved = resolveIssueFromCache(queryClient, key);
           return (
             <button key={key} onClick={() => onTabClick(key)}
               className="flex items-center gap-2 w-full px-2 py-1.5 text-xs hover:bg-muted rounded transition-colors">
               {issueTypeIcon(resolved?.issueTypeName ?? '')}
               <span className="font-mono">{key}</span>
               <span className="truncate text-muted-foreground">{resolved?.summary ?? ''}</span>
             </button>
           );
         })}
       </PopoverContent>
     </Popover>
     ```

5. Import `cn` from `@/lib/utils` for conditional class merging.
