**shortcuts.ts:**
- Added optional `displayKeys: string[]` field to `ShortcutEntry` interface

**KeyboardShortcutsPanel.tsx (full redesign):**
- Backdrop: `bg-black/40 backdrop-blur-sm` for modern glass effect
- Open animation: `animate-in fade-in-0 zoom-in-95 duration-200`

- Category sections: Lucide icons (Keyboard, Compass, List, Zap), uppercase tracking-wider headers, border-t separators
- Shortcut rows: hover:bg-muted/50 transition-colors, description left + keycaps right
- Keycap badges: gradient bg, border, shadow, mono font, min-w-[24px] -- each key in combo gets its own badge
- Footer: fixed "Press Esc to close" with inline keycap badge
- Scrollable body: max-h-[50vh] between fixed header and footer
- Empty search state: centered "No shortcuts found" with py-8
- Search state resets on close
