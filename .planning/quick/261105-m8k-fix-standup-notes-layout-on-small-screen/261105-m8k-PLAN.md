<objective>
Fix the Standup Notes page on small screens.

1. The Yesterday|Today separator currently stores the LEFT pane width in px
   (`standupYesterdayWidth`), so when the app sidebar opens only the right pane shrinks.
   Persist a ratio (fraction of the split container) instead.
2. On narrow Today columns the task title vanishes. Root cause (confirmed by reading
   `TodayInProgressSection.tsx` / `TodayUpNextSection.tsx` rows): the trailing cluster is
   `shrink-0` and holds a status pill (`STATUS_PILL_LAYOUT_CLASS` = `shrink-0 min-w-[5.5rem]
   whitespace-nowrap`, wider for long status names), an SP slot (`min-w-7`), the time bar
   (`w-24`, hidden only `@max-[30rem]`) and a 20px avatar. Together with the type icon + key
   (both shrink-0) and `px-6` column padding, that consumes the whole row in a ~320–480px
   pane, so the `flex-1 min-w-0 truncate` title gets 0px. Fix with progressive
   container-query tiers so the cluster compacts/drops and the title keeps a floor.
3. Verify at many widths via screenshots and iterate.

Purpose: standup is used on a laptop with the sidebar open; both columns must stay readable.
Output: percentage split + migration + tests, responsive Today/Yesterday rows, screenshot-verified.
</objective>
