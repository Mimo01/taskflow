In FieldsSection.tsx, modify the fix version popover rendering logic (lines 498-522) to filter the versions before displaying them.

After `versionsQuery.data && versionsQuery.data.length > 0 &&`, instead of spreading and sorting inline, compute a filtered list:

1. Split `versionsQuery.data` into two arrays: `unreleased` (where `!v.released`) and `released` (where `v.released`).
2. Sort `released` by `releaseDate` descending (most recent first). Versions without a releaseDate sort to the end of released.
3. Take only the first 10 from the sorted released array (`released.slice(0, 10)`).
4. Also include any currently-selected fix versions (`f.fixVersions`) that are released but fell outside the top 10, so the user can see and deselect them.
5. Combine: `[...unreleased, ...recentReleased, ...selectedButTruncated]`.
6. Sort the combined list for display: unreleased first (sorted by name), then released (sorted by releaseDate descending).

Extract this filtering into a `useMemo` or inline computed const above the JSX return, e.g.:

```typescript
const filteredVersions = useMemo(() => {
  const all = versionsQuery.data;
  if (!all || all.length === 0) return [];

  const unreleased = all.filter((v) => !v.released);
  const released = all
    .filter((v) => v.released)
    .sort((a, b) => {
      // Most recent release first
      if (!a.releaseDate && !b.releaseDate) return a.name.localeCompare(b.name);
      if (!a.releaseDate) return 1;
      if (!b.releaseDate) return -1;
      return b.releaseDate.localeCompare(a.releaseDate);
    });

  const recentReleased = released.slice(0, 10);
  const recentIds = new Set(recentReleased.map((v) => v.id));

  // Ensure currently-selected released versions remain visible
  const selectedOlder = released.filter(
    (v) => !recentIds.has(v.id) && f.fixVersions.some((fv) => fv.id === v.id),
  );

  // Display order: unreleased (by name), then released (most recent first)
  const sortedUnreleased = [...unreleased].sort((a, b) => a.name.localeCompare(b.name));
  const sortedReleased = [...recentReleased, ...selectedOlder].sort((a, b) => {
    if (!a.releaseDate && !b.releaseDate) return a.name.localeCompare(b.name);
    if (!a.releaseDate) return 1;
    if (!b.releaseDate) return -1;
    return b.releaseDate.localeCompare(a.releaseDate);
  });

  return [...sortedUnreleased, ...sortedReleased];
}, [versionsQuery.data, f.fixVersions]);
```
