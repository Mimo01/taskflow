# Quick 260331-039: Assignee Avatar on Sprint Board Story Headers Summary

One-liner: Assignee 20px CachedAvatar added to sprint board story swimlane headers, using blob-cached avatar infrastructure ported from main branch.

## What Was Built

Story swimlane headers on the sprint board now display a small (20px) circular avatar for the story's assignee. The avatar appears between the key+summary button and the status badge, allowing users to identify ownership at a glance without expanding the swimlane.

For unassigned stories, no avatar element is rendered — clean and no dead space.

## Implementation Details

**StoryHeaderRow.tsx:**
- Added `assigneeAvatarUrl?: string | null` and `assigneeDisplayName?: string` optional props
- Renders `<CachedAvatar url={assigneeAvatarUrl} name={assigneeDisplayName} size={20} />` wrapped in `shrink-0` div after the key+summary button
- Conditional render: only when `assigneeDisplayName` is truthy

**SprintBoardTab.tsx:**
- All three `StoryHeaderRow` call sites updated:
  1. Virtualizer path (line ~288): `story.fields.assignee?.avatarUrls['48x48']` / `story.fields.assignee?.displayName`
  2. Non-virtualizer path (line ~371): same source
  3. Sticky header (line ~970): uses `stickyHeader.story.fields.assignee?....`

**Avatar infrastructure (ported from main):**
- `avatarCache.ts`: Fetches avatar images with Jira/GitLab auth, caches as blob URLs in memory and disk with 30-day TTL
- `useAvatarCache.ts`: React hook that provides blob URL from cache
- `cached-avatar.tsx`: Component with initials fallback, graceful null handling, and onError eviction
