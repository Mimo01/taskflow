<objective>
Upgrade the existing Priority selector on the issue detail page so each priority's
icon is shown next to its label — both in the open option list and in the dropdown
trigger (the currently-selected value).

Purpose: The priority scheme is 9-level and conveyed primarily by icon elsewhere in the
app (TaskCard, StoryHeaderRow, BacklogRow all render `PriorityIcon`). The issue-detail
edit dropdown currently shows icons only in the read-only (non-editing) state; once the
`Select` is opened, options and the trigger are text-only. This makes the dropdown
inconsistent with the rest of the app and harder to scan.

Output: A reworked Priority `MetaRow` in `FieldsSection.tsx` that reuses the existing
`PriorityIcon` component and the existing `@/components/ui/select` primitive — no new
dependencies, matching existing icon sizing (`w-3.5 h-3.5 shrink-0`).
</objective>
