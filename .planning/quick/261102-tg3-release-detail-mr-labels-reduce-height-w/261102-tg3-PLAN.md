In MrLabels.tsx, add a module constant `MAX_LABEL_ROWS = 5` with a comment explaining the math: 5 rows of h-5 pills plus gap-1 is 116px, which fits beside the 120px donut. Compute `itemCount = labelSummary.length + (missing > 0 ? 1 : 0)` and `rows = Math.min(itemCount, MAX_LABEL_ROWS)`.

Change the container to a CSS grid with column-major auto-flow. The classes are `grid min-w-0 grid-flow-col gap-1 gap-x-1.5 border-l pl-3 text-xs content-start justify-start` (keep `cn(..., className)`). Add an inline `style` with `gridTemplateRows: repeat(${rows}, auto)` and `gridAutoColumns: 'minmax(0, 9.5rem)'`, so the old 9.5rem cap applies to each column, not the whole block.

Do NOT use flex-col + flex-wrap + max-h. WebKit (the Tauri macOS webview) does not widen a column-wrap flex container for the extra columns, so pills overlap or overflow.

Remove `max-w-[9.5rem]` from the container. Pills keep `max-w-full min-w-0 truncate` plus `title`, so long names truncate inside their column track. Keep `self-start` on the pills, and add `justify-self-start` if needed so pills stay content-width rather than stretching to the column width.

Render the "No label" pill as the last grid item: drop the wrapping `<div className="flex flex-col ... mt-1.5 border-t pt-2">` and render the Pill element directly. Its dashed orange border and warning icon already set it apart. Keep its data-testid, aria-pressed, onClick, and classes otherwise unchanged.

Update the JSDoc above MrLabels to say: a column-major grid, at most 5 rows tall, extra pills flow into more columns, never collapsed.

Hide nothing: no "+N more" (user memory: show all MR labels). Pill text stays one line (one row = one line).
