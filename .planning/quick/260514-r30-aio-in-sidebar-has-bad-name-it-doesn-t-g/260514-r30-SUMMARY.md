# Phase 260514-r30 Plan 01: Rename Sidebar Label to AIO Cycles Summary

Renamed the Testing section sidebar label from "AIO Projects" to "AIO Cycles" using TDD — tests updated first (RED), then production code changed to green.

## What Changed

**Label change (old → new):** `'AIO Projects'` → `'AIO Cycles'` in `SIDEBAR_NAV_ITEMS` entry with `id: 'aio-projects'` in `sidebar-items.ts`.

**Rationale:** Phase 55 D-10 changed the sidebar item from linking to an AIO Projects list page to deep-linking directly to a configured project's cycles overview at `/aio-project/{selectedAioProjectKey}`. That destination page (`AioProjectOverviewPage`) renders the header "Cycles — {projectKey}". The old label "AIO Projects" (plural) implied a list of projects that no longer exists; "AIO Cycles" accurately describes what the user sees after clicking.

**What was deliberately NOT changed:**
- `id: 'aio-projects'` — preserved to keep the deep-link branch in `Sidebar.tsx` (`nav.id === 'aio-projects'`) and the visibility preset sets in `sidebar-items.ts` / `settings.store.ts` working correctly
- `path: '#aio-dynamic'` sentinel — Sidebar.tsx continues to compute the real `to` from `selectedAioProjectKey`
- `iconName: 'FlaskConical'`, `section: 'testing'` — unchanged
- Route assertion in tests: `expect(link?.getAttribute('href')).toBe('/aio-project/PROJ')` — unchanged (only the human-visible label was renamed)
