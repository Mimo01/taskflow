## Design notes

- Card body is a fixed `h-[184px]` for all 3 chart cards in data, skeleton and empty states. Plan-checker warning handled: By owner = 6 rows x 24px + "+N others" line (about 164px); Execution mix = 12px bar + 5 rows x 24px (about 144px); Schedule = 148px columns area (16 count + up to 84 bar + 28 two-line label) + 24px footer = 172px. All fit without clipping, no density-dependent heights, so no card/row height adjustment was needed.
- Schedule labels: columns are narrow (about 21px at the 3-col breakpoint), so labels are the day-of-month number with a month abbreviation line only when the month changes; overdue = "Late", later = "8w+". The tooltip carries the full week range. This deviates from the plan's "formatDateKey of each weekStart" label to avoid overlapping text.
- Pass rate = passed / total runs (A2 decision). Executed/total is the tile sub-text.
- Scroll reset on folder change uses `paneRef.current.scrollTop = 0`.
