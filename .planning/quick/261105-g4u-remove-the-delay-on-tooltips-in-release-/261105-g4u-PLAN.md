<objective>
Make every tooltip on the release detail page open with no delay.

Purpose: the user wants release detail tooltips to show straight away. The audit (done while planning) found these sources of delay:
- `ROW_TOOLTIP_DELAY = 600` in `graphs/rowToggle.tsx`. The 261102-vuw graph-row tooltips use it at three sites: ReleaseStatusRows.tsx:72, ReleaseTypeWaffle.tsx:111 and ReleaseAssigneeRows.tsx:82. It is imported nowhere outside release-detail/graphs, so it is safe to remove.
- The shared default `delay = 150` in `components/ui/tooltip.tsx`. This plan does NOT change it, because many other pages use it. All the other release-detail TooltipTriggers already pass `delay={0}`: ReleaseFacts.tsx:516, ReleaseStatusRows.tsx:137, ReleaseAssigneeRows.tsx:145 and components/release/ReleaseIssueGraph.tsx:82.
- The burnup recharts `ChartTooltip` in ReleaseBurnup.tsx:332. It has no open delay, but recharts animates the tooltip box into place over 400ms by default, which makes it feel delayed. Turning that off at this one call site is my choice; chart.tsx is unchanged.

Out of scope: native `title=` attributes (UnifiedTaskTable, ReleaseFacts, DeploymentPackageSection, MrLabels, etc.). The browser/OS sets their delay and app code cannot change it. Converting them to Base UI tooltips would be a different task, so do not do it here.

Output: the three graph rows use delay 0, the constant is removed, and the burnup tooltip animation is off.
</objective>
