<objective>
Let users filter stories by **Unassigned** in both the Backlog and Sprint Board views, merged into the existing assignee filter dropdown (`UnifiedFilterBar`). A dedicated reserved sentinel value represents "no assignee"; it is matched strictly against `issue.fields.assignee === null`, rendered as the label "Unassigned", pinned to the top of the option list, and shown only when the current view contains at least one unassigned issue.

Purpose: Filtering by unassigned work is a core triage need; today the assignee filter only lists named people.
Output: A shared assignee-filter module (sentinel + option builder + predicate), both view predicates/option builders rewired to use it, and the dropdown/chip rendering the sentinel's human label.
</objective>
