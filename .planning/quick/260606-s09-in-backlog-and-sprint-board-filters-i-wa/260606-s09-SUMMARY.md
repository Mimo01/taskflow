# Quick 260606-s09: Unassigned Assignee Filter Summary

Added an "Unassigned" option to the assignee filter in both the Backlog and Sprint Board views, backed by a shared sentinel/predicate module (`@/lib/assignee-filter`) matched strictly against `assignee === null`, rendered as the label "Unassigned", pinned to the top, and shown only when at least one visible issue is unassigned.

## What Was Built

- **`taskflow/src/lib/assignee-filter.ts`** — new shared module exporting:
  - `UNASSIGNED_FILTER` (`'__unassigned__'`) reserved sentinel, `UNASSIGNED_LABEL` (`'Unassigned'`).
  - `buildAssigneeOptions(issues)` — distinct named displayNames (first-seen order, matching the prior unsorted Set builders); prepends the sentinel only when ≥1 issue has `assignee == null`, omits it otherwise.
  - `matchesAssigneeFilter(issue, activeAssignees)` — empty Set → true; sentinel matches iff `assignee == null`; named values matched as case-insensitive substring of displayName; sentinel excluded from the substring pass; OR semantics across all selected values.
- **`taskflow/src/lib/assignee-filter.test.ts`** — 11 vitest cases covering the no-filter path, sentinel match/non-match, named substring, the "unassigned never matches a named query" guard, OR semantics, and all four option-builder visibility states.
- **BacklogPage / SprintBoardTab** — both option builders now call `buildAssigneeOptions(...)` and both predicates now call `matchesAssigneeFilter(...)`, replacing the duplicated inline logic. SprintBoardTab's shared label/assignee loop was split so the labels collection is preserved (minimal diff). Epic/label/status matches left untouched so the two views stay identical for those.
- **UnifiedFilterBar** — Assignee `<FilterDropdown>` gets `displayMap={new Map([[UNASSIGNED_FILTER, UNASSIGNED_LABEL]])}` so the sentinel renders (and search-filters) as "Unassigned"; the active-filter chip label is overridden to "Unassigned" for the sentinel. `filterOptions.assignees: string[]` typing unchanged.

## Locked Decisions Honored

- Dedicated reserved sentinel constant (not a substring marker).
- Strict `assignee == null` match for the sentinel; excluded from the named substring pass.
- Label "Unassigned" in dropdown, search, and chip.
- Option present only when ≥1 visible issue is unassigned; pinned to index 0 (top).
- Both predicates behaviorally identical (single shared function).
- `filter.store.ts` untouched — sentinel round-trips as a plain string through `activeAssignees` / `QuickFilter.assignees`.
