<objective>
In the command palette search, a bare number entered while an active Jira project is set must
resolve to that project's issue. Example: with active project `PROJ`, typing `12345` must surface
a Direct Match for `PROJ-12345`. Typing the full key `PROJ-12345` must continue to work unchanged.

Purpose: Users frequently know only the numeric portion of an issue (from URLs, commit messages,
Slack) and should not have to retype the project prefix when the active project already implies it.

Output: Updated direct-key-lookup logic in `CommandPalette.tsx` plus regression tests.
</objective>
