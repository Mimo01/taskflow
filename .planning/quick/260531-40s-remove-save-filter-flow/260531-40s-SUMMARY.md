# Quick Task 260531-40s: Remove the Jira "Save Filter" Flow Summary

Deleted the entire Jira-backed saved-filter subsystem (dialogs, store, service, sync hook, and all downstream consumers) while preserving the local "Save" QuickFilters flow and leaving the Tempo (WorklogsPage) saved-filters subsystem untouched.

## What Was Done

Removed 7 source files and 3 test files forming the self-contained Jira saved-filter delete-set: `SaveFilterDialog.tsx`, `EditFilterDialog.tsx`, `SavedFilterList.tsx` (+test), `saved-filter.store.ts` (+test), `useSavedFilterSync.ts`, `services/jira/filters.ts` (+test). - **main.tsx**: removed the `useSavedFilterSync` import and its call.

### Task 3 — Clean stale test mock (commit 58f83bd6)
Removed the now-dead `@/services/jira/client` mock for `fetchAllSearchPages` (and its "saved filter integration" comment) from `SprintBoardTab.test.tsx` — its only source consumer was removed in Task 2.
