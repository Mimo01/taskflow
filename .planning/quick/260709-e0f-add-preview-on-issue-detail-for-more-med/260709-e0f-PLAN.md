<objective>
Extend the issue-detail attachment preview beyond images. Today only `image/*`
attachments get a preview (thumbnail grid + `AttachmentLightbox`); everything else
is a download-only `AttachmentFileRow`. Add inline previews for text, code, PDF,
video, and audio, with a download fallback for unsupported types — reusing the
existing auth-blob fetch pattern and the existing single type-switching modal
pattern (no second architecture).

Purpose: Users can view more attachment types without leaving the app or downloading.
Output: A shared `useAuthBlob` hook, a `resolvePreviewKind` detector (with tests),
a `highlightCode` wrapper around highlight.js, a generalized `AttachmentPreviewModal`,
and wiring so previewable non-image rows open it.

One new dependency: `highlight.js` (core build + only the languages we need) to
satisfy CONTEXT.md's locked decision that code files render as a **syntax-highlighted**
preview (not plain text). Plain text types (.txt/.md/.log/.csv) stay plain `<pre>`.
PDF/video/audio use native HTML5 elements with zero new deps (CSP is disabled).
</objective>
