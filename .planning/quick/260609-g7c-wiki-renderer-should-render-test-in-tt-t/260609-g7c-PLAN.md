<objective>
Fix the Jira wiki renderer so `{{{TEXT}}}` (triple-brace teletype macro) renders as `<tt>TEXT</tt>` instead of garbled output.

Purpose: jira2md's `{{...}}` monospace regex partially matches `{{{TEXT}}}`, leaving a dangling `}` and stray `{`. The fix is a single regex replacement in `preprocessJiraMarkup` that runs before jira2md, converting the full triple-brace span to raw `<tt>` HTML which passes through jira2md untouched and is already allowed by `wikiSanitizeSchema`.

Output: One line added to `preprocessJiraMarkup` in WikiRenderer.tsx; two new tests in WikiRenderer.test.tsx.
</objective>
