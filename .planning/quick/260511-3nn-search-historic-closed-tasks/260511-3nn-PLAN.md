<objective>
Add a second live search path in the command palette that searches Jira for historically
closed (Done) tasks. The open-issue search and closed-task search remain separate queries,
each capped at maxResults=20, so neither causes large data loads.

Purpose: Users need to navigate to closed tickets without the current open-issue search
missing them (Jira's `text ~` index may deprioritise or exclude Done items in certain
Jira configurations; explicit `statusCategory = Done` ensures they are found).

Output:
- `searchJiraClosed` function exported from jira service
- Separate "Search closed tasks" trigger + result group in CommandPalette
</objective>
