   Note: also change the character class from `[A-Z]` to `[A-Za-z]` and `[A-Z0-9]` to `[A-Za-z0-9]` since the `i` flag alone does not change character classes in all engines -- be explicit.

   `const TICKET_KEY_SPACE_RE = /(?<![A-Za-z0-9-])\b([A-Za-z][A-Za-z0-9]+)\s+(\d+)\b/gi`
