# Quick Task 260602-x58 — Summary

## Task

On the Standup Notes page (Yesterday column), a story's status activity was rendered
as one sub-item per Jira status transition. Collapse this to a single line showing the
journey endpoints: initial status → final status.

## What changed

In `taskflow/src/routes/standup-notes/YesterdayColumn.tsx`, the `buildGroups` transition
loop was replaced with a collapse that:

1. Copies `activity.transitions` (no in-place mutation).
2. Sorts by the `at` ISO timestamp (lexicographic comparison is correct for ISO-8601) —
   does not trust the API array order.
3. Takes `sorted[0].fromStatus` as the initial status and `sorted[last].toStatus` as the
   final status.
4. Pushes exactly ONE `{ kind: 'transition', label: 'initial → final' }` sub-item per issue.

A story moving To Do → In Progress → In Review → Done now shows a single "To Do → Done"
line. Single-transition and zero-transition stories are unaffected. The Copy-markdown
output collapses identically because it reads the same `subItems`.
