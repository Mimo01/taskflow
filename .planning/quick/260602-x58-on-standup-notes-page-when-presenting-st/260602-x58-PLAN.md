<objective>
On the Standup Notes page (Yesterday column), a story's status activity is currently
rendered as one sub-item per Jira status transition. When a story moved through several
statuses in a day (e.g. To Do → In Progress, In Progress → In Review, In Review → Done),
the recap shows three lines. The user wants this collapsed to a single line showing the
journey endpoints: the initial status → the final status (e.g. To Do → Done).

Purpose: Cleaner standup recap — one status line per story instead of a noisy chain.
Output: A localized change in `buildGroups` that collapses the per-issue `transitions`
array to a single transition sub-item (earliest `fromStatus` → latest `toStatus`), plus
unit-test coverage through `generateMarkdown`.
</objective>
