    - duplicateTemplate(id) on unknown id returns null and leaves templates unchanged (same array contents)
    - duplicateTemplate('b') with templates [a, b, c] yields [a, b, copy, c] (inserted right after source, not appended)
    - copy.name === `${source.name} (copy)`; copy.subtaskIssueTypeId/Name equal source's
    - returned value equals copy.id, and copy.id !== source.id
    - copy.rows has same length and same field values as source rows (title, assignee, priority, labels, duedate, timeEstimate, storyPoints, components, customFieldValues), but every copy row id differs from every source row id and copy row ids are unique among themselves
    - deep independence: copy.rows[0].labels, .components, .customFieldValues are not the same references as the source's (toEqual but not toBe); mutating via updateTemplate on the copy leaves source rows untouched
    - source template object is unchanged after duplication
  </behavior>
