<objective>
Add a Resolution field control to the issue detail sidebar (FieldsSection), mirroring the
existing Priority inline-Select pattern. The row is always visible; it is editable only when
the issue's status category is `done`, otherwise it renders the current resolution (or
"Unresolved") as read-only text. An "Unresolved" option clears the field via `value: null`.

Purpose: Today the `resolution` field cannot be changed anywhere in the UI. This closes that
gap using proven existing infrastructure (`useFieldMutation`, `updateIssueField`, on-open React
Query fetch).

Output: A new `fetchResolutions` service fetcher, a `resolution` field on the canonical
`JiraIssueDetail` type + `fetchIssueDetail` fields array, the Resolution `MetaRow` in
FieldsSection, and tests asserting the set/clear payload and the read-only gate.
</objective>
