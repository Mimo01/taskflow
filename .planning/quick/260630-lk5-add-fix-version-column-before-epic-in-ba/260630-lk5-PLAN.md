**Step 1 — Build a version lookup map (new useMemo, after `entityMaps`):**

Add a `versionMap` useMemo that flattens `backlog.versionData.versionsPerProject` into a `Map<number, { id: string; name: string }>`. Iterate over all values (each is an array of `{ id: number; name: string; released: boolean }`), and for each entry insert `versionMap.set(v.id, { id: String(v.id), name: v.name })`. Returns an empty Map when `backlog` is null/undefined.

```
const versionMap = useMemo(() => {
  const m = new Map<number, { id: string; name: string }>();
  if (!backlog) return m;
  for (const versions of Object.values(backlog.versionData.versionsPerProject)) {
    for (const v of versions) m.set(v.id, { id: String(v.id), name: v.name });
  }
  return m;
}, [backlog]);
```
