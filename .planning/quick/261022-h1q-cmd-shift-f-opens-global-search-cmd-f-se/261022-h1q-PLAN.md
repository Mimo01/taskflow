  <action>
Create the pure and DOM engine in `taskflow/src/lib/find-in-page.ts`, following RESEARCH Patterns 1, 2, 3, 5 and 7. Do not change `src/lib/search-text.ts`; the palette ranking depends on it.

**foldText(text)**
- Returns `{ folded, starts, ends }`.
- Iterate code points. For each char compute `ch.toLowerCase().normalize('NFD').replace(/\p{M}/gu, '')`.
- For each unit of that output, push the original start index and end index (start + ch.length).
- This is the per-character index map required by the locked accent-insensitivity decision.

**findInRuns**
- Signature: `findInRuns(runs: string[], query: string, cap = 1000)`. Returns `{ matches: { run: number; start: number; end: number }[]; capped: boolean }`.
- Offsets are in ORIGINAL run-text space: map folded `[a, b)` to `[starts[a], ends[b-1])`.
- Fold and trim the query first.
- Search with indexOf and advance by the query length after each hit, so matches don't overlap.

**collectRuns(scope, isVisible = defaultIsVisible)**
- Returns `TextRun[]`, where each run is `{ text: string; segments: { node: Text; start: number }[]; parent: Element }`.
- Walk with `document.createTreeWalker(scope, SHOW_ELEMENT | SHOW_TEXT)`.
- `acceptNode` returns FILTER_REJECT for the excluded tags and attributes listed in the behavior.
- Group consecutive sibling text nodes into a run. Any element sibling breaks the run.

**buildMatchRanges(runs, query, isVisible)**
- Runs findInRuns.
- Applies isVisible ONLY to the parents of runs that matched, caching the result per Element in a Map for the pass.
- Converts each match to a live Range with `setStart` / `setEnd` via the segment table. The start and end can be in different text nodes.
- Returns `{ ranges: Range[]; capped: boolean }`.

**defaultIsVisible(el)**
- Uses `el.checkVisibility?.({ visibilityProperty: true, opacityProperty: false })`, falling back to `el.getClientRects().length > 0`.

**resolveFindScope(doc = document)**
- Uses `MODAL_SEL = '[data-slot="dialog-content"],[data-slot="sheet-content"],[role="dialog"][aria-modal="true"],[role="alertdialog"]'`.
- Filter out elements that are not connected or that are inside `[data-closed]` or `[inert]`.
- Take the last remaining element. Otherwise fall back to `[data-find-scope="peek"]`, then `[data-find-scope="main"]`, then null.
- Also return `kind: 'modal' | 'peek' | 'main'`, so the caller knows whether to portal into the scope.
- This implements the CONTEXT decision that the topmost layer wins.

**scrollRangeIntoView(range)**
- Call `range.startContainer.parentElement?.scrollIntoView?.({ block: 'nearest', inline: 'nearest' })`.
- Then refine: find the nearest scrollable ancestor (overflow-y auto or scroll, and scrollHeight > clientHeight). If `range.getBoundingClientRect()` lies outside that ancestor's rect, adjust `scrollTop` by the delta to centre the match.

Write the tests first in `find-in-page.test.ts`, covering every behavior bullet. Use jsdom DOM built with `document.body.innerHTML` and pass `() => true` as the visibility predicate. Then implement until they pass.

Commit RED and GREEN together in one commit, because the pre-commit hook blocks failing tests.
