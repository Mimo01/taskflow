# Phase 260518-m70 Plan 01: DefectRow Full-Row Clickability Summary

**One-liner:** DefectRow `<tr>` made fully clickable via loading-gated conditional spread, with breadcrumb push + navigate to `/issue/{resolvedKey}` — matching the existing run-row UX pattern.

## What Was Built

### AioCycleDetailPage.tsx

Extended `DefectRow` to accept an `onOpen: (resolvedKey: string) => void` prop and conditionally renders the `<tr>` as an interactive button-role element once the Jira issue resolves:

- `resolvedKey = issueQuery.data?.key ?? null`
- `isClickable = !issueQuery.isLoading && !!resolvedKey`
- When `isClickable`: spreads `role="button"`, `tabIndex={0}`, `aria-label`, `onClick`, `onKeyDown` (Enter/Space) onto `<tr>`
- `data-testid={`defect-row-${defectIdOrKey}`}` always present (for test targeting in loading state too)
- Inner `NavLink` gets `onClick={(e) => e.stopPropagation()}` to prevent double-navigation
- Added `openDefect` function next to `openRun`: pushes breadcrumb with `{ label: cycleName, path: location.pathname }` then navigates to `/issue/${resolvedKey}`
- `onOpen={openDefect}` wired into `DefectRow` JSX

### AioCycleDetailPage.test.tsx

Added 5 new tests inside the existing `Defects tab` describe block:

- **AIOC-03-A** (loading gate): Row has no `role="button"` and no `cursor-pointer` while issue is still loading
- **AIOC-03-B** (click resolved): Clicking the title cell navigates to `/issue/PROJ-1234` via MemoryRouter route matching
- **AIOC-03-C** Enter (keyboard): `fireEvent.keyDown(row, { key: 'Enter' })` navigates to the issue route
- **AIOC-03-C** Space (keyboard): `fireEvent.keyDown(row, { key: ' ' })` navigates to the issue route
- **AIOC-03-D** (breadcrumb): `mockBreadcrumbPush` called with `{ label: 'Sprint 2', path: '/aio-cycle/PROJ/PROJ-CY-2' }` before navigation
