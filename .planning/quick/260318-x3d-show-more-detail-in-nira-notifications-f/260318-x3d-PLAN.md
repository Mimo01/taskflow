8. **issuetype** — `changeLines.push(\`Type: ${item.fromString ?? '(none)'} -> ${item.toString ?? '(none)'}\`)`

For each new field, also set `changeAuthor` and `changeAuthorAvatar` if not already set (same pattern as the existing status/assignee cases).

else if (item.field === 'description') {
