1. In `operation-profiler.store.ts`, add `responseSize?: number` to the `FetchRecord` interface (optional since errors won't have it). This is bytes.

2. In `apiFetch.ts`, capture response size in both the success path (line ~171) and error path (line ~132):
   - Success path: After the response is available, read `response.headers.get('content-length')`. If present, parse to int. If not present and `responseBodyCapture` is already enabled (body text is already read), use `text.length` as approximate byte size. Store as `responseSize` on the FetchRecord.
   - Error path: Set `responseSize: 0` on the FetchRecord.
   - IMPORTANT: Do NOT clone or read the response body just for size. Only use content-length header OR the already-read body text length (when responseBodyCapture is on). This avoids performance impact.

3. In `utils.ts`, add a `formatBytes(bytes: number | undefined): string` helper:
   - undefined/0 returns '-'
   - < 1024 returns `${bytes} B`
   - < 1048576 returns `${(bytes/1024).toFixed(1)} KB`
   - else returns `${(bytes/1048576).toFixed(1)} MB`
