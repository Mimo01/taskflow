<objective>
Sort the AIO project options alphabetically (by display `name`, case-insensitive) in the Settings → Integrations → AIO Project selector.

Purpose: Currently the dropdown renders projects in whatever order `fetchAioProjects` returns them (API order). For instances with many AIO projects this makes it hard to find the right one. Sorting by name matches the user's mental model.

Output: A single sorted render in `IntegrationsSection.tsx` plus a test that pins the alphabetical order.
</objective>
