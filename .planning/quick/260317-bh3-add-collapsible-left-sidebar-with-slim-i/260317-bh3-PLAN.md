**Sidebar.tsx changes:**

1. Import `useSettingsStore` (already imported) and read `sidebarCollapsed` and `toggleSidebarCollapsed` from it.
2. Import `PanelLeftClose` and `PanelLeftOpen` from lucide-react (for the toggle button icon).
3. Replace the static width classes. Currently uses `w-16 md:w-56`. Change to:
   - When `sidebarCollapsed` is true: `w-16` (always slim, icons only)
   - When `sidebarCollapsed` is false: `w-16 md:w-56` (current responsive behavior)
   Add `transition-all duration-200` for smooth width animation.
4. For text labels: currently use `hidden md:block`. When collapsed, these should be hidden even on desktop. Change each `<span className="hidden md:block">` to use a conditional class:
   - `sidebarCollapsed ? 'hidden' : 'hidden md:block'`
   Do the same for the branding text "Taskflow" and the section labels ("Work", "Developer", "PM").
5. For the branding row gap: when collapsed, hide the gap-3 text gap (just center the icon).
   - When collapsed: `flex items-center justify-center px-3 py-4 border-b border-border`
   - When expanded: `flex items-center gap-3 px-3 py-4 border-b border-border` (current)
6. Add a toggle button at the bottom of the sidebar, ABOVE the border-t settings section. Place it as a small icon button:
   ```tsx
   <button
     type="button"
     onClick={toggleSidebarCollapsed}
     className="mx-2 mb-1 flex items-center justify-center p-2 rounded-lg text-muted-foreground hover:bg-accent hover:text-accent-foreground transition-colors"
     aria-label={sidebarCollapsed ? 'Expand sidebar' : 'Collapse sidebar'}
   >
     {sidebarCollapsed ? <PanelLeftOpen className="h-4 w-4" /> : <PanelLeftClose className="h-4 w-4" />}
   </button>
   ```
   Place this button between the nav section and the bottom border-t div. Use a flex spacer or insert it right before the bottom div.
7. Add tooltips for collapsed icons: wrap each NavLink and button in the nav with a `title` attribute showing the label when collapsed (e.g., `title={sidebarCollapsed ? 'Dashboard' : undefined}`). This gives native browser tooltips on hover.

**main.tsx changes:**

Register keyboard shortcut for sidebar toggle. Add after the existing `useHotkeys('mod+comma', ...)` line:
```tsx
const toggleSidebarCollapsed = useSettingsStore((s) => s.toggleSidebarCollapsed);
useHotkeys('mod+b', (e) => { e.preventDefault(); toggleSidebarCollapsed(); });
```
Note: Use `mod+b` (Cmd+B on macOS) which is the standard sidebar toggle shortcut in VS Code, Slack, etc. preventDefault is needed to avoid browser bold text action.
