# Quick Task 260330-x87: Right-click story header transitions on sprint board

**One-liner:** Right-click context menu on StoryHeaderRow using ContextMenu/ContextMenuTrigger with asChild, wired to all three render sites with optimistic update and rollback via shared handleTransition.

## What Was Built

StoryHeaderRow now accepts optional `transitions`, `onTransition`, and `transitionError` props. When `onTransition` is provided, the component wraps its row in a ContextMenu (using `asChild` on ContextMenuTrigger to preserve the existing div). Right-clicking shows a "Move to..." popup with colored status badges for each available transition.

SprintBoardTab was updated to:
1. Add a `handleTransition` function with optimistic update + rollback pattern identical to drag-and-drop transitions
2. Pass transition props to all three StoryHeaderRow render sites: `renderSwimlane` (virtualized), the fallback non-virtualized render, and the sticky header overlay
3. Fix the transitions pre-fetch to include ALL issues (stories + subtasks) rather than only subtasks and orphan stories

The `getTransitions` helper inside `VirtualizedSwimlanes` reads from the react-query cache by issueKey, making transitions available without additional API calls when the pre-fetch has already run.
