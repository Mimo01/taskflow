## Interaction Contracts

### Activity Timeline (DETAIL-01)

| Interaction | Behavior |
|-------------|----------|
| Page load | Fetch issue with `?expand=changelog`. Merge changelog.histories and comments by timestamp. Show Skeleton placeholders (3 rows) during load. |
| Sort order | Newest-first by default (inherits `commentSortOrder` from useSettingsStore). Existing sort toggle applies to entire timeline. |
| Changelog entry render | Single line: `[icon] [author avatar placeholder] [author name] changed [field] from [old] to [new] [relative time]` in muted-foreground. No card wrapper. |
| Comment entry render | Full CommentCard (existing design). Card background on `var(--card)`. |
| Vertical connector | 2px wide line in `var(--border)` connecting entries on the left side, 24px from left edge. |
| Scroll | Timeline area scrolls independently if content exceeds viewport. CommentComposer stays sticky at bottom. |

### Timeline Filters (DETAIL-02)

| Interaction | Behavior |
|-------------|----------|
| Default state | "All" chip is active. All entry types visible. |
| Click a chip | Toggle that filter as active. Only one chip active at a time. Chips: `All (N)`, `Changes (N)`, `Comments (N)`. |
| Active chip style | Badge with `default` variant (filled primary). Inactive chips use `outline` variant. |
| Count update | Counts are computed from merged timeline data, not refetched. |
| Transition | No animation. Instant filter via array `.filter()`. |

### Comment Edit/Delete (DETAIL-03, DETAIL-04)

Already implemented (D-12). No new UI contract needed.

### Watcher Toggle (DETAIL-05)

| Interaction | Behavior |
|-------------|----------|
| Placement | Sidebar field row, below existing fields. Label: "Watchers". |
| Default state | Eye icon + count (e.g., "3"). If current user is watching: EyeOff icon, filled state. |
| Click | Optimistic toggle. POST/DELETE to `/rest/api/2/issue/{key}/watchers`. On error, revert with toast. |
| Loading | Icon shows subtle opacity pulse during API call. |
| Layout | `Eye` or `EyeOff` icon (16px) + count text (text-sm) + clickable area fills the row. |

### Overdue Badge (DETAIL-10)

| Interaction | Behavior |
|-------------|----------|
| Condition | `issue.fields.duedate` is non-null AND `new Date(duedate) < new Date()` AND status category is not "Done". |
| Render locations | Issue detail sidebar (next to due date value), TaskRow on sprint board, backlog rows, search result rows. |
| Style | Badge destructive variant: `bg-destructive/10 text-destructive`. Text: "Overdue". Size: text-xs (12px). |
| No due date | No badge rendered. No "on track" badge either. |

### Clone Issue (DETAIL-11)

| Interaction | Behavior |
|-------------|----------|
| Button placement | Action bar in IssueDetailContent, after Pin and Edit buttons, before Open in Jira. |
| Button style | `Button` variant="secondary" size="sm". Icon: `Copy` (lucide). Label: "Clone". |
| Click | Opens CreateEditIssueModal in create mode. Pre-filled fields: summary = "Clone - {original summary}", description, labels, priority, assignee. |
| Success | Modal's existing success flow (close + invalidate queries). No additional clone-specific toast. |
| Keyboard | No dedicated shortcut in this phase. |

## Loading & Error States

| State | Component | Behavior |
|-------|-----------|----------|
| Timeline loading | Skeleton | 3 skeleton rows: 1 full-width (simulating comment card) + 2 half-width (simulating changelog entries). Animate with shadcn Skeleton pulse. |
| Timeline error | ErrorState | "Couldn't load activity" with Retry button. Uses existing ErrorState component. |
| Watcher loading | Inline | Eye icon at 50% opacity during API call. No skeleton. |
| Watcher error | Toast | "Couldn't update watchers. Please try again." Revert optimistic update. |
| Clone modal loading | Existing | CreateEditIssueModal handles its own loading states. |

## Responsive Behavior

| Breakpoint | Behavior |
|------------|----------|
| Desktop (>= 1024px) | Two-column layout (existing): content + sidebar. Timeline in content area. |
| Tablet/Small (< 1024px) | Single column (existing behavior). Sidebar collapses below content. Timeline full-width. |
| Filter chips overflow | Chips wrap to next line if container width is insufficient. No horizontal scroll. |

## Accessibility

| Concern | Contract |
|---------|----------|
| Timeline semantics | Use `<ol>` for the timeline list. Each entry is an `<li>`. |
| Filter chips | Use `role="radiogroup"` on chip container. Each chip is `role="radio"` with `aria-checked`. |
| Watcher toggle | `aria-pressed` on the button. `aria-label="Watch this issue"` / `"Stop watching this issue"`. |
| Overdue badge | `aria-label="Overdue"` on the badge for screen readers. |
| Clone button | Standard button semantics. `aria-label="Clone issue"`. |
| Keyboard nav | Filter chips navigable with arrow keys within radiogroup. Tab moves between timeline, filters, sidebar. |
