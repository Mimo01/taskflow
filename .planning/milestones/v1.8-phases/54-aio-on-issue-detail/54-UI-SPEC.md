## Layout Contract

### AioTestRunsSection placement

Position: below `ActivityTimeline` in `IssueDetailPage.tsx` / `IssueDetailContent.tsx`.

Layout structure:
```
<section aria-label="AIO Test Runs">
  ├── Section header (collapsible toggle + FlaskConical icon + "AIO Test Runs" label + run count)
  └── [if expanded]
      ├── [if aioEnabled=false]  → return null (section hidden entirely)
      ├── [if loading]           → AioTestRunsSkeleton
      ├── [if error]             → ErrorState with retry
      ├── [if no linked cases]   → return null (section hidden entirely — D-04)
      ├── [if linked but no runs]→ EmptyState "No test runs in active cycle"
      └── [if data]
          ├── [single test case] → flat step table (no collapsible wrapper)
          └── [multiple cases]   → one CollapsibleRunBlock per test case
              └── CollapsibleRunBlock header: FlaskConical + test case name + overall run status Badge
                  └── [if expanded] → step table for that run
```

### Step table structure

4-column table. Matches `AioCycleDetailPage` `<table>` pattern.

```
<table class="w-full text-sm">
  <thead class="border-b bg-muted/10">
    <tr>
      <th>Step</th>          <!-- flex-grow, px-4 py-2, text-xs font-semibold text-muted-foreground -->
      <th>Expected</th>      <!-- w-48, px-3 py-2 -->
      <th>Actual</th>        <!-- w-48, px-3 py-2 -->
      <th>Status</th>        <!-- w-24, px-3 py-2 -->
    </tr>
  </thead>
  <tbody>
    <tr class="border-b border-border hover:bg-muted/30 transition-colors">
      <td>step action text</td>
      <td>expected result text</td>
      <td>
        actual result text (or "—" for NOT_EXECUTED)
        [thumbnails row below text if attachments present]
      </td>
      <td><Badge status chip /></td>
    </tr>
  </tbody>
</table>
```

### Step attachment thumbnails

- Position: below the actual result text inside the "Actual" cell (stacked layout)
- Thumbnail size: `h-12` (48px height), `w-auto` (aspect-ratio preserved), `rounded-md overflow-hidden`
- Multiple thumbnails: `flex flex-row gap-1 mt-1 flex-wrap`
- Click: opens `ImageLightbox` with `src={attachmentUrl}` — one lightbox per thumbnail (independent)
- Uses `AuthImage` for authenticated fetch (AIO attachment URLs are on the same Jira host)
- Role/a11y: `role="button"` + `tabIndex={0}` + `aria-label="{filename} - click to view full size"` — matches `AttachmentThumbnail.tsx` pattern

### CollapsibleRunBlock (multi-test-case grouping)

- Default state: **collapsed** for PASS runs; **expanded** for FAIL or BLOCKED runs
- Header: `flex items-center gap-2 cursor-pointer min-h-[44px] px-4 py-2 hover:bg-muted/30`
- Header content: `ChevronDown/Right size-4` + `FlaskConical size-3.5 text-muted-foreground` + `{testCaseName} text-sm font-normal` + `Badge {overall status}`
- Body: step table for that run (rendered when expanded)

### AioTestRunsSkeleton

Pattern from `AioCycleDetailSkeleton.tsx`:
```
<div class="flex flex-col gap-3 p-4">
  <Skeleton h-6 w-48 />          <!-- section heading placeholder -->
  <Skeleton h-8 w-full />        <!-- table header row -->
  {[0,1,2,3].map → Skeleton h-10 w-full}   <!-- step rows -->
</div>
```

## Interaction Contract

### Loading state (AIOI-01)

- `useDelayedLoading` with 200ms threshold — skeleton only shown after 200ms, preventing flicker on fast network
- AIO query fires in parallel with the main Jira issue query — does NOT block issue detail render
- Query enabled: `!!jiraBaseUrl && !!token && !!issueKey && aioEnabled`

### aioEnabled gate (AIOI-01)

- `if (!aioEnabled) return null` — section not rendered at all when AIO is disabled
- Evaluated from `useSettingsStore((s) => s.aioEnabled)`

### Collapse/expand (multi-case)

- Keyboard: `Enter` or `Space` on collapsible header toggles expanded state
- FAIL/BLOCKED runs start expanded; PASS runs start collapsed
- Single test case: no collapse wrapper — flat table always visible

### Lightbox (AIOI-03)

- Opens on thumbnail click (or Enter/Space keyboard)
- Closes on `Escape` key or clicking overlay (existing `ImageLightbox` behavior)
- No multi-image navigation between step thumbnails (single `ImageLightbox` per thumbnail — D-14)

### Filter chips

- Phase 54 does NOT include filter chips on the step table — chips are a Phase 53 (cycle detail) pattern
- The step table shows all steps for each test run without status filtering
