## Milestone Summary

**Key Decisions:**

- Charting stack: Recharts v3.8+ via shadcn `chart` primitive — `responsive` prop replaces `ResponsiveContainer` (React Compiler #4590/#5173 conflict avoidance); chart wrapper uses `'use no memo'` + explicit-height outer div (WebKit 0×0 prevention).
- My Tasks "all assigned" scope uses `fetchAllSearchPages` (server-side pagination) — avoids the fetch-once page-cap pitfall; two named functions prevent client-side-filter temptation.
- SP aggregation filters `!issuetype.subtask` before summing to avoid double-counting.
- Tempo date bucketing via `tempo.started.slice(0, 10)` only — never `new Date(...).toISOString()` (UTC shift bug).
- Phase 85 insights gated on a mandatory live probe; no chart code before probe results documented.
- Phase 86 D-01 clean slate: the redesign deletes the entire Phase 83–85 widget surface (including the Phase 85 velocity/burndown insights) in favour of the 3-region screenshot layout.

**Issues Resolved:**

- MYTASK-01 audit blocker — sidebar entry invisible for existing installs — fixed by a v27 settings-store migration (`appendMyTasksItemIfMissing`).
- v1.13 tech debt cleared (quick-260616-mmw): orphaned `ChartWrapper`/burndown types/`deriveCounts` deleted, stale cache-sharing comments corrected, REQUIREMENTS traceability reconciled.

**Requirements Outcomes:**
