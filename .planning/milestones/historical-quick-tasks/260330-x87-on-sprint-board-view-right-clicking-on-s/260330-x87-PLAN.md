Two changes in SprintBoardTab.tsx:

**A. Fix pre-fetch to include ALL stories (not just subtasks and orphan stories):**

In the useEffect that pre-fetches transitions (around line 575-596), the current filter on line 583-585 builds a `subtaskParentKeys` set and only fetches transitions for subtasks or stories NOT in that set. This means stories WITH subtasks never get their transitions pre-fetched.

Change the `draggable` filter to include ALL issues. Replace:
```
const subtaskParentKeys = new Set(
  issues.filter((i) => i.fields.issuetype.subtask && i.fields.parent?.key).map((i) => i.fields.parent?.key),
);
const draggable = issues.filter(
  (i) => i.fields.issuetype.subtask || !subtaskParentKeys.has(i.key),
);
```
With simply using all issues (since we now need transitions for stories too):
```
const allIssueKeys = new Set<string>();
const uniqueIssues = issues.filter((i) => {
  if (allIssueKeys.has(i.key)) return false;
  allIssueKeys.add(i.key);
  return true;
});
```
Then use `uniqueIssues` in the Promise.allSettled map instead of `draggable`.

**B. Pass transition props to all 3 StoryHeaderRow render sites:**

Add these props to each StoryHeaderRow instance:

1. In `renderSwimlane` (around line 291-300):
   ```
   transitions={getTransitions(story.key)}
   onTransition={(tid, name, toId, catKey) => onTransition(story.key, tid, name, toId, catKey)}
   transitionError={cardErrors.get(story.key)}
   ```

2. In the fallback non-virtualized render (around line 371-381): same props as above.

3. In the sticky header (around line 929-938): same props but using `stickyHeader.story.key`:
   ```
   transitions={getTransitions(stickyHeader.story.key)}
   onTransition={(tid, name, toId, catKey) => handleTransition(stickyHeader.story.key, tid, name, toId, catKey)}
   transitionError={cardErrors.get(stickyHeader.story.key)}
   ```
   Note: sticky header uses `handleTransition` directly (not `onTransition` prop) since it's in the main component scope.
