1. Add imports at top:

2. Inside FieldsSection component, add:
   - Get `activeJiraProject` from `useAuthStore()`
   - Add state: `const [fixVersionOpen, setFixVersionOpen] = useState(false)`
   - Add a useQuery to fetch available versions when the popover opens:
     ```
     const versionsQuery = useQuery({
       queryKey: ['jira-fix-versions', activeJiraProject, jiraBaseUrl],
       queryFn: async () => {
         const token = await readSecret('jira-pat').catch(() => null);
         if (!token || !activeJiraProject) return [];
         return fetchFixVersions(jiraBaseUrl, token, activeJiraProject);
       },
       enabled: fixVersionOpen && !!activeJiraProject,
     });
     ```

3. Replace the fix versions MetaRow (lines 454-456). The new version should:
   - ALWAYS show the MetaRow (remove the `f.fixVersions.length > 0` condition) so users can add versions even when none are set
   - Show current versions as comma-separated badge-like text (clickable to open popover)
   - Show "None" when no versions are set (also clickable)
   - Use Popover/PopoverTrigger/PopoverContent (already imported) for the picker
   - Inside popover: show a scrollable list of all project versions from versionsQuery
   - Each version row: version name + a check indicator (checkmark or filled circle) if currently selected
   - Clicking a version toggles it: if selected, remove from array; if not, add to array
   - On toggle, call `mutation.mutate({ fieldName: 'fixVersions', value: newVersionArray })` where newVersionArray is `[{ id: "versionId" }, ...]` format
   - Show loading spinner/text while versions load
   - Show error state if versions fail to load
   - Sort versions: unreleased first, then released, within each group sort by name

   - Selected versions get a checkmark icon (use unicode checkmark or a simple span)

5. Show mutation error inline like other fields:
