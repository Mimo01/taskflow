<objective>
Add an "Assign to me" quick action to the Assignee popover on the Jira issue detail page so the user can self-assign in one click instead of typing their name into the typeahead search.

Purpose: Self-assignment is the most common assignee change. Today it requires opening the popover, typing a few characters, waiting for the debounced search (300ms) and clicking the matching row — 3+ interactions plus a network round-trip. A one-click shortcut removes all of that.

Output: Updated `FieldsSection.tsx` with a shortcut row inside the assignee Popover.
</objective>
