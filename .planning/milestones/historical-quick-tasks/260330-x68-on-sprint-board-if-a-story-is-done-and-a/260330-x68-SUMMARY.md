# Quick 260330-x68: Auto-collapse Done Swimlanes Summary

**Auto-collapse fully-done story swimlanes on sprint board with user-toggle persistence and visually distinct collapsed headers**

## Performance

- **Duration:** ~12 min
- **Tasks:** 2 (1 auto + 1 user-feedback refinement)
- **Files modified:** 2

## Accomplishments
- Stories where story + all subtasks are done auto-collapse on board load and data refresh
- User-toggled stories are never overridden by polling — tracked via useRef Set
- Collapsed headers have distinct visual styling (lighter bg, stronger border, spacing gap) so adjacent collapsed rows are clearly separated
- No infinite re-render loops thanks to fingerprint-based useMemo dependency

## Task Commits

Each task was committed atomically:

1. **Task 1: Add auto-collapse logic for all-done story swimlanes** - `5ad4b09` (feat)
2. **Task 2: Add visual separation between collapsed headers** - `b444c59` (feat)

## Files Created/Modified
- `taskflow/src/routes/dashboard/SprintBoardTab.tsx` - Added userToggledRef, allDoneFingerprint useMemo, auto-collapse useEffect
- `taskflow/src/routes/dashboard/StoryHeaderRow.tsx` - Differentiated collapsed vs expanded header styles (bg, border, margin)

## Decisions Made
- Used a fingerprint string (comma-separated `key:done` pairs) as a stable useEffect dependency instead of the swimlanes array — prevents infinite re-renders since swimlanes creates a new array reference every render
- Used useRef<Set<string>> for user toggle tracking instead of state — avoids unnecessary re-renders and survives across data polls
- Included stories with zero subtasks in auto-collapse logic (a done story with no subtasks is fully complete)
- Per user feedback, added visual distinction for collapsed headers: lighter background (bg-muted/25 vs bg-muted/40), stronger bottom border (border-border/50 vs border-border/30), and mb-0.5 spacing gap
