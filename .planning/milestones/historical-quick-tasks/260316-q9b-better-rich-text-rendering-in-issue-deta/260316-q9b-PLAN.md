  <action>
1. Create `preprocessJiraMarkup(wiki: string): string` function inside WikiRenderer.tsx that runs BEFORE jira2md:
   - Replace `[~accountId:XXX]` with `<mention>XXX</mention>` (custom HTML tag that react-markdown will pass through)
   - Replace `[~username]` with `<mention>username</mention>`
   - Replace `{info}...{info}` with `<div data-callout="info">...</div>` (use regex with dotall: `\{info\}([\s\S]*?)\{info\}`)
   - Replace `{warning}...{warning}` with `<div data-callout="warning">...</div>`
   - Replace `{note}...{note}` with `<div data-callout="note">...</div>`
   - Replace `{panel:title=TITLE}...{panel}` with `<div data-callout="panel" data-title="TITLE">...</div>`
   - Replace `{panel}...{panel}` (no title) with `<div data-callout="panel">...</div>`

2. Update WikiRenderer to use `rehype-raw` plugin (install if not present: `npm install rehype-raw`) so custom HTML tags pass through react-markdown. Add `remarkPlugins={[remarkGfm]}` and `rehypePlugins={[rehypeRaw]}`.

3. Add `components` prop to `<Markdown>` with custom renderers:
   - `img`: Render as `<img>` with `max-w-full rounded-md cursor-pointer` classes. On click, open ImageLightbox. Store lightbox state with useState in WikiRenderer.
   - `mention`: Render as `<span className="inline-flex items-center rounded-full bg-primary/15 text-primary px-2 py-0.5 text-xs font-medium">@{children}</span>` (pill badge style)
   - `div`: Check for `data-callout` attribute. If present, render styled callout:
     - `info`: Blue-tinted left-border box with info icon styling (`border-l-4 border-blue-500 bg-blue-500/10 p-3 rounded-r-md`)
     - `warning`: Amber-tinted (`border-l-4 border-amber-500 bg-amber-500/10 p-3 rounded-r-md`)
     - `note`: Yellow-tinted (`border-l-4 border-yellow-500 bg-yellow-500/10 p-3 rounded-r-md`)
     - `panel`: Gray-tinted with optional title (`border-l-4 border-border bg-muted/50 p-3 rounded-r-md`), if `data-title` present render as bold text above content
   - For non-callout divs, render default `<div>`.

4. Create `ImageLightbox.tsx`:
   - Props: `{ src: string; alt?: string; open: boolean; onClose: () => void }`
   - Render a fixed fullscreen overlay (`fixed inset-0 z-50 bg-black/80 flex items-center justify-center`)
   - Image inside with `max-w-[90vw] max-h-[90vh] object-contain rounded-lg`
   - Click overlay or press Escape to close
   - Close button (X) in top-right corner

5. Pipeline order in WikiRenderer: `preprocessJiraMarkup(wiki)` -> `j2m.to_markdown(result)` -> `<Markdown>` with rehype-raw + custom components.

IMPORTANT: The WikiRenderer props interface does NOT change. All consumers (IssueDetailContent, DescriptionEditor) continue working with zero modifications.
