| Token | Value | Usage |

- Wizard step headings use `text-xl font-semibold` (20px) — the 4-step wizard that remains after RoleStep deletion continues this pattern.
- Font family: `'Geist Variable', sans-serif` (declared in `--font-sans`).

## Surface Changes (Deletion Contract)

This section specifies what the UI looks like **after** the deletions. Executor must verify each surface matches this contract post-implementation.

### OnboardingWizard (ROLES-01)

**Before:** 5 steps — Welcome, Jira, GitLab, Role, Done.
**After:** 4 steps — Welcome, Jira, GitLab, Done.

- `StepIndicator` renders exactly 4 dots/labels: `['Welcome', 'Jira', 'GitLab', 'Done']`
- Step indexes shift: Done moves from index 4 → index 3.
- `completedSteps` tracking: only `jiraValidated` (pushes step index 1) and `gitlabValidated` (pushes step index 2). No step 3 completion tracking.
- The wizard `min-h-screen flex flex-col` shell structure is preserved unchanged.
- `py-6 px-4 border-b border-border` header region (StepIndicator container) is preserved unchanged.
- `flex-1 px-4 overflow-auto` step content region is preserved unchanged.

### SidebarSection (ROLES-02, ROLES-03)

**Before:** heading + description + `<SidebarItemsList />` + `<PresetButtons />`.
**After:** heading + description + `<SidebarItemsList />`.

- Section heading `text-lg font-semibold` "Sidebar" is preserved.
- Helper text `text-sm text-muted-foreground mt-1` "Choose which navigation items appear in the sidebar." is preserved.
- `<SidebarItemsList />` is preserved — only visibility toggles rendered (no drag handles; drag handles are Phase 67 scope, not Phase 66).
- The "Quick Presets" row (`text-xs font-medium text-muted-foreground` label + Developer/PM outline buttons) is removed entirely. No replacement UI.
- `gap-6` between section children is preserved; with `<PresetButtons />` gone the section ends after `<SidebarItemsList />`.

### AppearanceSection (ROLES-03)

- Remove `<PresetButtons />` import and its usage (line ~65). No other changes to AppearanceSection layout.

### Settings Store Migration (ROLES-04)

- No visual change to the store form. After upgrade to v22, all 9 sidebar items are visible. Users see all nav items in sidebar on next load — no confirmation prompt, no notification. Silent migration.
