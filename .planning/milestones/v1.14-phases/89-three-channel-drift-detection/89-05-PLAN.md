| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-89-17 | Tampering | MR title rendered through the `extractTicketKeys` linkification IIFE | mitigate | The IIFE emits React text nodes and `<button>` elements only — never `dangerouslySetInnerHTML` and never an `href` built from MR content.
