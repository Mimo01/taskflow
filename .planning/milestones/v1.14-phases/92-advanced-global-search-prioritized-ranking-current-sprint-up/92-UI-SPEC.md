## Spacing Scale

Declared values (multiples of 4), expressed as Tailwind v4 utilities already used by the palette:

| Token | Value | Usage in this phase |
|-------|-------|---------------------|
| xs | 4px | Result row vertical padding (`py-1`), gap between inline badges, tag horizontal padding (`px-1`) |
| sm | 8px | Row horizontal padding (`px-2`), gap between row columns (`gap-2`) |
| md | 16px | Dialog side safe margin (`mx-4`) |
| lg | 24px | Empty-state vertical padding (`py-6`) |
| xl | 32px | Empty-state icon (`size-8`) |
| 2xl | 48px | not used |
| 3xl | 64px | Dialog top offset (`mt-16`, unchanged) |

Exceptions (all existing codebase conventions, intentional):
- Off-grid 2px/6px values come only from reused geometry: shared status pill and epic badge (`px-1.5 py-0.5`), group heading (`py-1.5`, cmdk default), and the 2px loading bar (`h-0.5`). Do not introduce other off-grid values.
- Status pill uses the shared `STATUS_PILL_LAYOUT_CLASS` (`px-1.5 py-0.5`, `min-w-[5.5rem]`) — do NOT add geometry. Compact look comes from using it as-is inside a flex parent; do not shrink min-width per-row.
- Avatar size 20px (multiple of 4) via `CachedAvatar size={20}` — smaller than BacklogRow's 24px per user "compact" note [CTX D-10].
- Subtask indent: `pl-6` (24px) on the row plus a `↳` glyph in the leading slot [CTX D-13].
- Row density: `py-1` (4px) instead of cmdk default `py-1.5`; override via `className` on `CommandItem`.

Dialog geometry [CTX D-09]:
- Panel: `max-w-3xl` (768px) `mx-auto`, `w-full` with `mx-4` safe margin below 800px viewport. Replaces `max-w-xl`.
- List: `max-h-[70vh]` replaces `max-h-[300px]`. Panel stays a centred overlay under the existing backdrop (`fixed inset-0 z-50 bg-background/80 backdrop-blur-sm`).

## Typography

Compact dense list; two sizes cover the entire palette (existing palette already uses only `text-sm` and `text-xs`).

| Role | Size | Weight | Line Height |
|------|------|--------|-------------|
| Body (title, input, nav/action items) | 14px (`text-sm`) | 400 regular | 1.5 |
| Label (key, snippet, tag, epic badge, status pill, group heading, helper text) | 12px (`text-xs`) | 500 medium for heading/pill/badge/tag; 400 for key + snippet | 1.33 (Tailwind `text-xs` default) |
| Heading (tier headers) | 12px (`text-xs`) | 500 medium, uppercase NOT used (title case as in copy table), `text-muted-foreground` | 1.33 (Tailwind `text-xs` default) |
| Display | not used in this phase | — | — |

Weights: exactly two — 400 and 500 (project convention is `font-medium`, not semibold).

Specifics:
- Issue key: `font-mono text-xs text-muted-foreground`, `shrink-0`.
- Title: `text-sm`, `truncate`, first to shrink [CTX D-11] (use `min-w-0 flex-1`-style shrink priority; follow BacklogRow flex-shrink-priority memory: title shrinks first, badges have min-widths, no max-w caps on badges).
- Snippet: `text-xs text-muted-foreground`, **not italic** (avoids truncate glyph clipping). If a designer later italicises, add `pr-0.5`.
- Match highlight: `<mark>` styled `bg-transparent text-inherit underline decoration-primary/60 underline-offset-2`. Underline only: no background fill (colour = status only; avoids introducing a new hue) and no weight change (would shift width).

## Color

Neutral base-nova tokens only [CODE]. No new colours; colour on a row continues to mean status (pill) or Jira epic colour (badge).

| Role | Value | Usage |
|------|-------|-------|
| Dominant (60%) | `--popover` / `--background` (oklch(1 0 0) light, oklch(0.145 0 0) dark) | Palette panel surface, backdrop tint |
| Secondary (30%) | `--muted` (oklch(0.97 0 0) / oklch(0.269 0 0)) | Selected row (`data-selected:bg-muted`), `desc`/`comment` tag background, dimmed parent context row hover |
| Accent (10%) | `--primary` (oklch(0.205 0 0) / oklch(0.922 0 0)) at /60 | **Reserved for:** match-highlight underline only; focus ring on the input (existing) |
| Destructive | `--destructive` | Not used — no destructive actions in this phase |

Accent reserved for: match highlight underline in titles and snippets; existing input focus ring. Nothing else.

Semantic colours carried by reused helpers (not new):
- Status pill: `statusPillClass(statusCategoryKey)` — status category colour.
- Epic badge: `epicColorToTailwind(epicColor, epicKey)` — Jira epic colour with hash fallback; hex colours apply via returned `style`.
- Dimmed parent context row [CTX D-13]: `opacity-60` on title/key/badges (no highlight); the row stays fully clickable and keyboard-selectable. Selected state restores `data-selected:opacity-100`.
- Tier headers: `text-muted-foreground` (no per-tier colours, no legend).

## Layout & Component Contract

### Result row (one line, never wraps) [CTX D-10, D-11]

Left to right, `flex items-center gap-2 min-w-0 py-1 px-2`:

1. Type icon — `IssueTypeIcon className="size-3.5 shrink-0"` (14px, existing).
2. Key — `font-mono text-xs text-muted-foreground shrink-0`; it is a nested interactive element (navigates full-page; see Interaction). Keep the existing palette pattern: key `<button>` inside the cmdk `CommandItem` with `stopPropagation` (established PEEK-05 behaviour). Do not restructure into an overlay button.
3. Title — `truncate text-sm`, with `<mark>` highlights. Shrinks first.
4. Snippet (only on description/comment hits) — trailing muted `text-xs` "…phrase…" with highlighted term, `truncate`, followed by a small tag. Snippet region is `flex-[0_1_auto] min-w-0` with a floor of ~`min-w-24` so it never collapses to zero when title is long (fixed-length floor, not `min(...)` — WebKit).
5. Tag — `desc` or `comment`: `shrink-0 rounded border border-border bg-muted px-1 py-0 text-xs font-medium text-muted-foreground`, lowercase literal text.
6. Epic badge (stories only; hidden for subtasks and epics themselves) — replicate the BacklogRow chip: `inline-flex min-w-14 shrink items-center overflow-hidden rounded border px-1.5 py-0.5 text-xs font-medium` + `epicColorToTailwind` classes/style; label = epic name, `title="{epicKey}: {epicName}"`. Not a button in the palette (pure label; clicking the row is the only action). Show `Skeleton h-4 w-14 rounded-full` only if epic names are still loading.
7. Status pill — `statusPillClass(...)` wrapped in a flex parent (`<div className="flex shrink-0">`) [memory: statusPillClass needs flex parent].
8. Assignee — `CachedAvatar size={20}`, name for unassigned = `'Unassigned'` (initials fallback handled by component). Wrapped in `flex-none w-5` so it cannot collapse to 0 width.

Narrow-width degradation (drop columns, never wrap, per one-row-one-line preference): below ~`560px` panel width hide in this order: snippet+tag → epic badge → status pill label stays. Implement with a container-query on an inner wrapper (not on the container itself — Tailwind `@container` variants never style the container). Title and key always remain.

### Tier headers [CTX D-06]
- Rendered with `CommandGroup heading="…"` so cmdk semantics/a11y are preserved. Existing heading style (`text-xs font-medium text-muted-foreground`, `py-1.5 px-2`).
- Order: Direct match (pinned) → Current sprint → each upcoming sprint by sprint order (heading = sprint name; first upcoming gets suffix ` (next)`) → Backlog → Closed → Merge Requests → Navigation → Actions.
- Empty tiers are not rendered. No counts, no legend.
- Cap rows per tier: 8 visible per tier [DEFAULT, Claude's discretion]; if more, final row `+N more in <tier>` (muted, `text-xs`, selectable, expands that tier in place without layout jump of tiers above). Total soft cap 40 rows.

### Subtask grouping [CTX D-07, D-13]
- Story row followed by matching subtask rows directly beneath, `pl-6`, leading `↳` (`text-muted-foreground text-xs`, replaces nothing — sits before the type icon).
- Parent matched itself: normal (undimmed, highlighted) row.
- Parent not matched, only children matched: parent shown dimmed (`opacity-60`) as non-highlighted context header, still selectable; non-matching siblings hidden.
- Subtasks inherit the parent's sprint tier heading.
- A subtask with a parent already in another result tier is NOT duplicated: it is grouped under its parent's tier.
- Standalone subtasks whose parent is unknown (not in cache) render as a normal row, no indent.

### Direct match row [CTX D-17]
- First group "Direct match" with a single row using the same row anatomy (resolved locally from index; Jira fetch only if absent — show one `Skeleton h-8` row while fetching). Pinned: not re-sorted by tier.

### Default state (<2 chars) [CTX D-18]
Unchanged: Recent Items + Navigation. No tier headers.

### Closed tier [CTX D-01, D-15]
- Last item of the issue results region (always present when query ≥2 chars): `Include closed issues` — `CommandItem forceMount` with `value="include-closed"`, muted text, leading `Archive` lucide icon (`size-3.5`), no trailing hint. On select: sets include-closed flag for the current query, item is replaced by the Closed tier (with 3 skeleton rows while loading), tier appears last among issue tiers.
- "Search Jira for …" tail item is removed [CTX D-15].

### Merge Requests, Navigation, Actions [CTX D-16]
Render only when matching the query (cmdk filter or explicit filter on `!iid`/title). Rows keep existing single-line anatomy (`GitMerge size-3.5`, `!iid` muted, title truncate). Remove the always-visible cached-MR listing.

## Interaction Contract

| Concern | Contract |
|---------|----------|
| Open/close | Same shortcut and entry point; Escape closes (existing hotkey), backdrop click closes. |
| Typing | Title-tier results render synchronously from the cached index on every keystroke (no debounce). Body tiers (description/comment) arrive via one debounced Jira request (debounce 300ms [DEFAULT]) and merge into the already-rendered list. |
| Loading (body) | Never blocks the list. Show a 2px-high indeterminate bar (`h-0.5 bg-primary/30 animate-pulse`) under the input while the body request is in flight. No skeleton rows for local results. Skeleton rows only for Direct-match fetch and the Closed tier. |
| Cold index | If `['gh-backlog', boardId]` is empty on open: input is usable immediately; list shows 4 `Skeleton h-6 rounded` rows under a muted `Loading issues…` line until the cache fills, then results render reactively (subscribe via `useQuery`, not imperative `getQueryData`). |
| Re-ranking stability | When body results merge in, rows already displayed must not jump under the cursor: keep the currently selected cmdk item by `value` (key), and only insert new rows into their tier positions. New body hits appear below same-tier title hits (ordering rules D-05 guarantee this). |
| Keyboard | Up/Down moves selection across rows and tiers (cmdk default, `loop`); Enter selects → opens peek panel via the existing `onOpenIssue`/`handleIssueSelect` path; key button click → full-page `onIssueClick`. Selected row scrolls into view (`scroll-py-1`). Typing never moves focus out of the input. |
| Pointer | Hover = same `data-selected:bg-muted` as cmdk selection. Hover affordances must not shift layout (no opacity-0 elements that take width). |
| Row action | Row body (Enter or click) = existing select handler; key text click = full-page navigation with `stopPropagation` (PEEK-05, unchanged). Epic badge in palette is non-interactive. |
| Highlighting | Case-insensitive; highlight each matched query term on titles and snippets; for fuzzy matches highlight the matched character runs (contiguous runs merged into one `<mark>`). Max 6 marks per string. |
| Snippet extraction | ~48 characters of context each side of first match, collapsed whitespace, `…` ellipsis at truncated edges; fall back to start of description if no local match (comment-hit case, in which case tag = `comment` and no highlighted text in snippet; snippet omitted entirely for comment hits where text is not fetched). |
| Scroll | List scrolls inside panel (`overflow-y-auto`, `no-scrollbar` retained); panel height grows with content up to `70vh`; reset scrollTop to 0 when the query changes. |
| Reduced motion | No animation beyond existing `animate-pulse` (disable under `motion-reduce:`). |

Accessibility:
- Preserve cmdk `role=listbox/option` semantics; tier headers via `CommandGroup heading`.
- `<mark>` elements stay as `mark` (screen readers announce). No `aria-label` on row items; the accessible name comes from content. Avatar gets `aria-hidden` and the assignee name in a `title` attribute.
- Contrast: muted text (`text-muted-foreground`) used only for secondary info; dimmed parent rows (`opacity-60`) are a context-only affordance and remain selectable. Medium-contrast risk accepted by user for dimmed rows [CTX D-13].
- Input keeps focus ring; `autoFocus` retained.
