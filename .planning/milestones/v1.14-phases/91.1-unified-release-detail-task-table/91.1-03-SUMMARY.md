## Accomplishments

- `UnifiedTaskTable` exported: presentational-only (no `useQuery`/`useStore`/`fetch*` — P87 D-08 confirmed by grep), renders the merged header (`Issues` heading + done badge + flagged-count badge with `data-testid="flagged-count-badge"`), the `Progress` bar, and a single degraded banner (`data-testid="drift-degraded-banner"`) merging the two prior banner copies
- `TaskRow`: overlay-button click pattern (sibling `<button>` with `absolute inset-0`, never `role="button"` wrapping the key button — copied structurally from `IssueActivityGroup.tsx`'s `ActivityGroupHeader`), key/summary/assignee/status columns on the shared `COL_*` grid, two empty 28px gutter spans (no TASK rollup glyph, D-06)
- `MrSlot`: four mutually-exclusive states gated on `isLoadingDrift` FIRST — `mr-slot-pending` / `mr-slot-none` (healthy, orange) / `mr-slot-unavailable` (degraded, neutral) / rendered `MrSubLine[]` — so pending always wins and states 2/3 are structurally unreachable while drift is loading
- `MrSubLine`: `group/row` scoped to the individual sub-line only (verified: exactly one occurrence in the file, on the MR sub-line container), re-hosted `DriftActionCell`/`DriftMarkCell` verbatim (including `lastMarkRef`'s render-phase sticky-error reset and the `liveRegion`), linkified MR title via the verbatim `matchTicketKeyInTitle` IIFE, `mrStateBadgeClass` extracted once (was triplicated across the two source files)
- Secondary table (`data-testid="secondary-section"`): wrapped in `{secondaryRows.length > 0 && (...)}` so heading + content are both absent when empty (D-13); reuses `MrSubLine` via its `keyCell` prop rather than a second renderer; key column branches on `row.taskKeys.length` (never `taskReason === 'not-in-fix-version'`, which would mislabel non-evaluated uncovered MRs per the plan's explicit warning) showing either the orange out-of-scope-key warning with the exact `"{KEY} is not in fix version {versionName}"` tooltip template or a plain muted dash
- All three tasks' acceptance-criteria greps verified directly against the finished file (applyHeldOrder/orderRef/heldForVersion/versionId: 0, drift-task: 0, group/row: 1, absolute inset-0: 1, role="button"/dangerouslySetInnerHTML: 0, .sort()/primaryRows.slice: 0, drift-br/drift-ms: 2 each, secondary-key-flagged/none: 2, etc.)
