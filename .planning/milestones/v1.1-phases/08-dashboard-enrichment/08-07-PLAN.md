**Fix 1 — sprintIssueKeySet useMemo (line 114):**
Replace:
```ts
return new Set((data ?? []).map((i) => i.key))
```
With:
```ts
return new Set((Array.isArray(data) ? data : []).map((i) => i.key))
```
Rationale: `data ?? []` only guards null/undefined. If the Jira API or query cache returns a non-array object `{}`, `new Set({})` throws "is not iterable". `Array.isArray` rejects any non-array value including `{}`.

**Fix 2 — projectMrs spread (line 103):**
Replace:
```ts
return [...assigned, ...reviewer, ...projectMrs].filter(
```

With:
```ts
return [...assigned, ...reviewer, ...(Array.isArray(projectMrs) ? projectMrs : [])].filter(
```
Rationale: `fetchProjectMRs` may return `{}` on network/parse failure (e.g. empty response body parsed as object). Spreading a non-iterable object throws. The `Array.isArray` guard ensures the spread always receives an array.

Do NOT change any other lines in this file. These are surgical two-line fixes only.
