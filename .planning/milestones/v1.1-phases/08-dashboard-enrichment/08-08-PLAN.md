  <action>
Create `taskflow/src/routes/notifications/index.tsx` as a full-page list of all notifications.

**Page structure:**
- Header row: "Notifications" heading (h1, text-xl font-semibold) on the left; "Mark all read" button on the right (only enabled when there are unread items)
- Below header: scrollable list of all `items` from `useNotificationsStore`
- Each item rendered with `NotificationRow` (pass `isUnread` based on whether item.id is NOT in `readIds`)
- Clicking a `NotificationRow` calls `markAsRead(item.id)` AND toggles an inline `NotificationDetail` below that row (same accordion pattern as NotificationsPanel — clicking the active row collapses it, clicking a new row opens it and collapses the previous)
- `NotificationDetail` receives `onClose` that collapses the detail (sets `expandedId` to null)
- Empty state: when `items` is empty, show "No notifications yet" centered in muted text
- No TanStack Query needed — data comes from the Zustand store directly

**State:** `const [expandedId, setExpandedId] = useState<string | null>(null)`

**Toggle logic:**
```ts
const handleRowClick = (id: string) => {
  setExpandedId((prev) => (prev === id ? null : id))
  markAsRead(id)
}
```

**Mark all read button:**
```tsx
<button
  type="button"
  onClick={markAllRead}
  disabled={unreadCount === 0}
  className="text-sm text-muted-foreground hover:text-foreground disabled:opacity-40 disabled:cursor-not-allowed transition-colors"
>
  Mark all read
</button>
```
where `unreadCount` is derived inline: `const readSet = new Set(readIds); const unreadCount = items.filter(i => !readSet.has(i.id)).length`

**Outer layout:**
```tsx
<div className="flex flex-col gap-0 p-4 max-w-2xl mx-auto">
  {/* header */}
  {/* list or empty state */}
</div>
```
