## Interaction Contracts

### StaleDataBanner

The banner surfaces when a background revalidation fails after serving cached data. It already exists and its behavior is unchanged by this phase.

- Displayed inline at the top of the affected view
- `onRetry` triggers a manual `queryClient.invalidateQueries()` for the view's query key
- `onDismiss` removes the banner from view without retrying
- No modal, no toast — inline only
- Icon: `RefreshCw` from lucide-react at `size-4`
- Dismiss icon: `X` from lucide-react at `size-4`

### Polling State (invisible to user)

The polling pause behavior (`enabled: isOnThisRoute`) introduced in this phase is entirely invisible in the UI. No spinner, badge, or indicator is shown when polling is paused. The user only sees the result of polling (fresh data or StaleDataBanner on failure).
