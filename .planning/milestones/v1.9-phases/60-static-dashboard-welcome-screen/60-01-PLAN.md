| Boundary | Description |
|----------|-------------|
| Stronghold → React state | `jira-pat` PAT crosses from secure storage into `useState` in `index.tsx` (not this plan); this card receives the token via props |
| React state → Jira REST API | `jiraToken` is sent in `Authorization: Bearer <token>` headers by `fetchSprintIssues`/`fetchActiveSprint` |
| Jira API response → React render | Sprint name, issue summary, status strings traverse from external API into JSX |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-60-01 | Information Disclosure | `jiraToken` prop on DashboardSprintCard | mitigate | Token held in props (React-internal); never rendered into DOM; not logged; passes only to `fetchSprintIssues`/`fetchActiveSprint` for Authorization header |
| T-60-02 | Tampering (XSS) | sprint name + issue summary rendered as text | mitigate | React JSX auto-escapes string interpolation; no `dangerouslySetInnerHTML`; no string concatenation into HTML |
| T-60-03 | Denial of Service | division by zero on `totalPoints` | mitigate | Explicit `totalPoints > 0 ? ... : 0` guard before percentage compute (RESEARCH Pitfall in `getDaysRemaining`/`donePct`) |
| T-60-SC | Tampering | shadcn `add progress` install | mitigate | Package source verified in RESEARCH §"Package Legitimacy Audit" — shadcn official registry (`ui.shadcn.com`), `components.json` `"registries": {}`, no third-party blocks; install command runs from `taskflow/` to honor configured paths |
