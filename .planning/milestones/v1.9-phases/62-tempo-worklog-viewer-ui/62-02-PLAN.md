| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-62-04 | Tampering | username query param | mitigate | `fetchWorklogs` already uses `URLSearchParams.append('username', u)` — safe encoding, no string concatenation. WorklogsPage passes `selectedUsername` straight to the array argument without sanitization (encoding is the service layer's job). Confirmed in Phase 61 service. |
| T-62-05 | Tampering | custom date range | mitigate | Client-side guard `customFrom && customTo && customTo >= customFrom` in `enabled` flag prevents fetch on invalid/empty input; server enforces its own limits (Tempo API rejects invalid ranges with 400). Tested explicitly in Task 2 test (b)/(d). |
