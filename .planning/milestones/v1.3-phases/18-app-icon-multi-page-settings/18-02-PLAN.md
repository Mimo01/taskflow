  <action>
    From the `taskflow/` directory, run `npx tauri icon` pointing at the SVG source file.

    Step 1 — Try SVG directly (preferred — avoids needing sharp):
    ```bash
    cd /Users/mimo/Desktop/Tasker/taskflow && npx tauri icon ./app-icon-source.svg
    ```

    Inspect the output `src-tauri/icons/32x32.png` — if the background is dark (not transparent/black-filled), the SVG path worked. Verify with:
    ```bash
    ls -lh src-tauri/icons/32x32.png src-tauri/icons/icon.icns
    ```

    Step 2 — If SVG output has wrong background (transparent or black fill artifact):
    - Install sharp as dev dependency: `npm install --save-dev sharp`
    - Create a temporary Node.js script `gen-icon-png.mjs`:
      ```javascript
      import sharp from 'sharp';
      import { readFileSync } from 'fs';
      const svg = readFileSync('./app-icon-source.svg');
      await sharp(svg).resize(1024, 1024).png().toFile('./app-icon.png');
      console.log('app-icon.png written');
      ```
    - Run: `node gen-icon-png.mjs`
    - Then run: `npx tauri icon ./app-icon.png`
    - Remove the temp script after use: `rm gen-icon-png.mjs`
    - Do NOT commit app-icon.png (it is generated from the SVG)

    Critical: ALWAYS run from `taskflow/` directory — the CLI needs to find `src-tauri/tauri.conf.json`. If run from elsewhere, the error "could not find tauri.conf.json" will appear.

    No changes to `tauri.conf.json` are needed — the icon array is already correctly configured.
  </action>
