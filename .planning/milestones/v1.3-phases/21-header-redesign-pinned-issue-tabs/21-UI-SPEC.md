## Spacing Scale

Declared values (must be multiples of 4):

| Token | Value | Usage |
|-------|-------|-------|
| xs | 4px | Icon-to-text gaps inside tabs, inline padding |
| sm | 8px | Tab internal padding, gap between tab strip items |
| md | 16px | TopBar horizontal padding (px-4), section padding |
| lg | 24px | Content area padding (p-6 in IssueDetailSheet) |
| xl | 32px | Not used this phase |
| 2xl | 48px | Not used this phase |
| 3xl | 64px | Not used this phase |

Exceptions: Tab strip height is 36px (not a spacing token -- it is a component dimension). TopBar remains h-12 (48px) as established.

---

## Typography

| Role | Size | Weight | Line Height |
|------|------|--------|-------------|
| Body | 14px (text-sm) | 500 (medium) | 1.5 |
| Label / Tab text | 12px (text-xs) | 500 (medium) | 1.4 |
| Heading | 20px (text-xl) | 600 (semibold) | 1.2 |
| Branding | 16px (text-base) | 600 (semibold) | 1.2 |

Notes:
- 2 weights only: 500 (medium) for body, labels, and tab text; 600 (semibold) for headings, branding, and overflow badge
- Overflow badge (+N): 12px (text-xs), weight 600 (semibold)
- Tab text uses the same 12px size as labels for a compact, consistent scale

---

## Visuals

**Primary focal point:** The active tab bottom border (2px accent) draws first attention in the tab strip; the filled pin icon is the primary new affordance signaling pinned state.

---

## Color

| Role | Value | Usage |
|------|-------|-------|
| Dominant (60%) | `var(--background)` | Page background, TopBar background, tab strip background |
| Secondary (30%) | `var(--muted)` | Inactive tab hover background, J/K focus row highlight, sidebar |
| Accent (10%) | `var(--primary)` | Active tab bottom border indicator, pin icon filled state |
| Destructive | `var(--destructive)` | Not used this phase |

Accent reserved for:
- Active pinned tab bottom border (2px solid, `border-b-2 border-primary`)
- Filled pin icon on pinned issues (pin icon uses `fill-current text-primary` when pinned)
- J/K focused row left border indicator (2px solid `border-l-2 border-primary`)

Additional semantic colors:
- `var(--muted)` for J/K focus row background highlight (`bg-muted`)
- `var(--muted-foreground)` for inactive tab text color
- `var(--foreground)` for active tab text color

## Interaction Contracts

### Pin/Unpin Toggle

| Property | Specification |
|----------|--------------|
| Trigger | Click pin icon button in IssueDetailContent header row |
| Unpinned state | Lucide `Pin` icon, outline style, `text-muted-foreground` |
| Pinned state | Lucide `Pin` icon, with `fill-current text-primary` (filled appearance) |
| Tooltip | "Pin to tabs" (unpinned) / "Unpin from tabs" (pinned) |
| aria-label | "Pin issue {KEY}" / "Unpin issue {KEY}" |
| Button size | w-8 h-8, matching existing action button dimensions in the header |

### Tab Strip

| Property | Specification |
|----------|--------------|
| Visibility | Hidden when 0 tabs pinned; visible when >= 1 tab pinned |
| Height | 36px (h-9) |
| Background | `bg-background` with `border-b border-border` bottom separator |
| Layout | `flex items-center gap-1 px-4 overflow-hidden` |
| Max visible tabs | 7 |
| Tab min-width | 120px |
| Tab max-width | 200px |
| Tab content | Issue type icon (16px) + key (font-mono text-xs) + summary (truncated, text-xs) |
| Summary truncation | CSS `truncate` (text-overflow: ellipsis), approximately 20 characters visible |
| Close button | Lucide `X` icon, 14px, visible on hover, `text-muted-foreground hover:text-foreground` |
| Active tab | `border-b-2 border-primary text-foreground bg-muted/50` |
| Inactive tab | `text-muted-foreground hover:bg-muted hover:text-foreground` |
| Tab click | Calls `handleIssueClick(issueKey)` to open IssueDetailSheet |
| Tab border-radius | `rounded-t-md` (top corners only) |

### Overflow Badge (+N)

| Property | Specification |
|----------|--------------|
| Trigger | Appears when pinned tabs > 7 |
| Label | "+{count}" where count = total pinned - 7 |
| Style | `text-xs font-semibold px-2 py-1 rounded bg-muted text-muted-foreground hover:bg-accent` |
| Click | Opens Popover (reuse existing shadcn Popover) |
| Popover content | List of overflow tabs, each row: issue type icon + key + summary (truncated), clickable |
| Popover row click | Calls `handleIssueClick(issueKey)` |
| Popover max-height | 240px with `overflow-y-auto` |

### J/K List Navigation

| Property | Specification |
|----------|--------------|
| Keys | J = next row, K = previous row, Enter = open detail |
| Hook | `useHotkeys('j', ...)` and `useHotkeys('k', ...)` from react-hotkeys-hook |
| Scope | Active only when the respective list route is mounted |
| Focus state | Integer index tracked in `useState`, -1 = no focus |
| Focus indicator | Row receives `bg-muted border-l-2 border-primary` |
| Edge behavior | J at last item = no-op; K at first item = no-op (no wrap-around) |
| Scroll behavior | `scrollIntoView({ block: 'nearest', behavior: 'smooth' })` when focused row is off-screen |
| Reset | Focus index resets to -1 on route navigation (useEffect cleanup) |
| Enter action | Calls `onIssueClick(issueKey)` for the focused row |
| Input guard | Default react-hotkeys-hook behavior: `enableOnFormTags: false` (KEYS-07) |

### TopBar Branding

| Property | Specification |
|----------|--------------|
| Logo | App icon SVG inline or img, 20px x 20px |
| App name | "Taskflow", text-base (16px), font-semibold (600), `text-foreground` |
| Layout | `flex items-center gap-2` on the left side of the header |
| Separator | No explicit separator; existing border-b on header suffices |

## Accessibility Contract

| Element | Requirement |
|---------|-------------|
| Pin button | `aria-label="Pin issue PROJ-123"` / `"Unpin issue PROJ-123"` |
| Tab strip | `role="tablist"` with `aria-label="Pinned issues"` |
| Each tab | `role="tab"`, `aria-selected="true"` for active tab |
| Tab close button | `aria-label="Close PROJ-123 tab"` |
| Overflow trigger | `aria-label="Show N more pinned tabs"` |
| J/K focused row | `aria-current="true"` on the focused row |
| Logo image | `alt="Taskflow"` if img; `aria-hidden="true"` if decorative alongside text |
