**Common pattern for all three views:**

Each view needs:
1. Import `useListNavigation` from `@/hooks/useListNavigation`
2. Import `useRef`, `useEffect` from react (if not already imported)
3. Build a flat array of navigable items from the data
4. Call `useListNavigation({ itemCount, onSelect, enabled })`
5. Add `ref` to each row container to enable `scrollIntoView`
6. Apply focus highlight class when `index === focusIndex`
7. Use `useEffect` to call `scrollIntoView({ block: 'nearest', behavior: 'smooth' })` when focusIndex changes

**MyTasksTab.tsx (KEYS-04):**

1. Add import: `import { useListNavigation } from '@/hooks/useListNavigation'` and add `useRef` to existing react import

2. Build a flat ordered array of all visible issue keys (parents + subtasks in render order):
   ```typescript
   const flatIssueKeys = useMemo(() => {
     const keys: string[] = [];
     for (const { parent, subtasks: children } of groupedData.groups) {
       keys.push(parent.key);
       for (const child of children) {
         keys.push(child.key);
       }
     }
     // Include orphan subtasks if any
     for (const orphan of groupedData.orphans) {
       keys.push(orphan.key);
     }
     return keys;
   }, [groupedData]);
   ```

3. Call the hook:
   ```typescript
   const { focusIndex } = useListNavigation({
     itemCount: flatIssueKeys.length,
     onSelect: (index) => setSelectedIssueKey(flatIssueKeys[index]),
     enabled: !isLoading && flatIssueKeys.length > 0,
   });
   ```

4. Create a ref map for scroll-into-view:
   ```typescript
   const rowRefs = useRef<Map<string, HTMLDivElement>>(new Map());
   ```

5. Add scrollIntoView effect:
   ```typescript
   useEffect(() => {
     if (focusIndex >= 0 && focusIndex < flatIssueKeys.length) {
       const key = flatIssueKeys[focusIndex];
       const el = rowRefs.current.get(key);
       el?.scrollIntoView({ block: 'nearest', behavior: 'smooth' });
     }
   }, [focusIndex, flatIssueKeys]);
   ```
