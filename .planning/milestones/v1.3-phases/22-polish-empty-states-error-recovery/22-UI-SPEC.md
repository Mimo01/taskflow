## Spacing Scale

Declared values (must be multiples of 4):

| Token | Value | Usage |
|-------|-------|-------|
| xs | 4px | Icon-to-text gap in Alert component |
| sm | 8px | Internal padding of error banner, gap between icon and heading in EmptyState |
| md | 16px | Vertical padding around EmptyState subtitle, horizontal padding of error alerts |
| lg | 24px | Vertical space between icon and heading in EmptyState |
| xl | 32px | Top/bottom padding of EmptyState container (py-8 = 32px) |
| 2xl | 48px | Icon size for empty state illustrations |
| 3xl | 64px | Icon size upper bound (used for prominent empty states: My Tasks, Sprint Board) |

Exceptions: EmptyState icon sizing uses 48px (standard) and 64px (prominent views) which are multiples of 4 but not standard Tailwind spacing tokens -- use explicit `size-12` (48px) and `size-16` (64px) on the Lucide icon.

| Role | Token | Usage |
|------|-------|-------|
| Dominant (60%) | `bg-background` | Page background behind empty/error states |
| Secondary (30%) | `bg-card` | Alert component background (shadcn Alert default variant) |

Stale-data warning banner: `bg-muted border border-border` with `text-muted-foreground` message and inline Retry button. NOT destructive -- this is a soft warning, not an error.

### EmptyState (new: `src/components/ui/empty-state.tsx`)

```
Props:
  icon: LucideIcon        — Lucide icon component (not element)
  title: string           — Heading text
  subtitle?: string       — Explanatory text below heading
  action?: ReactNode      — Optional CTA button
```

Layout: `flex flex-col items-center justify-center py-8 text-center`
- Icon: `size-12 text-muted-foreground mb-4` (48px, muted)
- Title: `text-base font-medium text-foreground`
- Subtitle: `mt-1 text-sm text-muted-foreground max-w-xs`
- Action: `mt-4` (rendered as-is, caller provides Button)

### ErrorState (new: `src/components/ui/error-state.tsx`)

```
Props:
  error: Error | unknown  — The caught error
  onRetry: () => void     — Callback wired to refetch()
  viewName: string        — Human label: "tasks", "merge requests", etc.
```

Behavior:
- Auto-detects auth errors: checks `error.status === 401 || error.status === 403` or message contains "401" / "403"
- Non-auth: renders shadcn `<Alert variant="destructive">` with `AlertCircle` icon, title "Couldn't load {viewName}", description from error message (sanitized), and `<Button variant="secondary" size="sm">Retry</Button>`
- Auth: renders shadcn `<Alert variant="destructive">` with `ShieldAlert` icon, title "Session expired", description "Your {Jira|GitLab} token may have been revoked or expired", and `<Button variant="default" size="sm">Reconnect</Button>` that navigates to `/settings`

### StaleDataBanner (new: `src/components/ui/stale-data-banner.tsx`)

```
Props:
  onRetry: () => void     — Callback wired to refetch()
  onDismiss: () => void   — Hides the banner
```

Layout: Full-width bar above stale content.
- Container: `flex items-center gap-2 rounded-lg border bg-muted px-3 py-2 text-sm`
- Icon: `RefreshCw size-4 text-muted-foreground`
- Text: `text-muted-foreground flex-1` — "Couldn't refresh — showing cached data"
- Actions: `<Button variant="secondary" size="sm">Retry</Button>` + `<Button variant="ghost" size="icon-sm"><X /></Button>`

## Interaction Contract

### Retry Flow
1. User sees ErrorState with "Retry" button
2. User clicks Retry
3. Button shows loading state (disabled + spinner) while refetch is in-flight
4. On success: ErrorState unmounts, data renders normally
5. On repeated failure: ErrorState re-renders with updated error

### Reconnect Flow
1. User sees ErrorState with auth error detected
2. User clicks "Reconnect"
3. App navigates to `/settings` (Connections section is the default/first section)
4. User updates their token and tests connection
5. User navigates back; TanStack Query automatically retries on window focus

### Stale Data + Error Flow
1. Background refetch fails while cached data exists
2. StaleDataBanner renders above the existing (stale) content
3. User can click Retry to attempt refetch, or dismiss the banner
4. On successful refetch: banner unmounts, data updates silently

### Detection Logic
- `isError && !data` → full ErrorState (no cached data)
- `isError && data` → StaleDataBanner above stale content
- `!isLoading && !isError && data.length === 0` → EmptyState
- Auth detection: `error?.status === 401 || error?.status === 403`
