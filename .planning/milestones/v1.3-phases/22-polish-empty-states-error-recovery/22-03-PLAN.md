    **1. Extend notifications.store.ts:**
    - Add to NotificationsState interface:
      ```
      fetchError: Error | null;
      setFetchError: (err: Error | null) => void;
      retryFetch: (() => void) | null;
      setRetryFetch: (fn: (() => void) | null) => void;
      ```
    - Add to store initial state: fetchError: null, retryFetch: null
    - Add actions: setFetchError: (err) => set({ fetchError: err }), setRetryFetch: (fn) => set({ retryFetch: fn })
    - Do NOT add fetchError/retryFetch to the `partialize` function — these are transient (like permissionDenied)

    **2. Update useNotificationPolling.ts:**
    - After the useQuery call, access the query result: const queryResult = useQuery({...}); (change from void call to capturing the return)
    - Add useEffect to propagate error state to store:
      ```
      useEffect(() => {
        store.setFetchError(queryResult.isError ? (queryResult.error as Error) : null);
      }, [queryResult.isError, queryResult.error]);
      ```
    - Add useEffect to expose refetch via store:
      ```
      useEffect(() => {
        store.setRetryFetch(() => queryResult.refetch());
        return () => store.setRetryFetch(null);
      }, [queryResult.refetch]);
      ```

    **3. Update NotificationPopover.tsx:**
    - Add imports: EmptyState, ErrorState from shared components, Bell from 'lucide-react'
    - Read fetchError and retryFetch from store: const { items, readIds, ..., fetchError, retryFetch } = useNotificationsStore();
    - Replace the existing "No notifications yet" plain div with:
      ```
      {fetchError && items.length === 0 && retryFetch && (
        <ErrorState error={fetchError} onRetry={retryFetch} viewName="notifications" />
      )}
      {!fetchError && items.length === 0 && (
        <EmptyState icon={Bell} title="No notifications yet" subtitle="Mentions and updates will appear here as they happen" />
      )}
      ```
    - If there ARE items and fetchError exists, do NOT show error (the items are still useful stale data). Optionally add a small StaleDataBanner above the list, or skip it since the popover is compact.

    **4. Update CommandPalette.tsx:**
    - Add import: SearchX from 'lucide-react'
    - Find the existing <CommandEmpty> element (currently renders "No matches -- try different keywords")
    - Replace its content with a minimal inline empty state using the SearchX icon:

      <CommandEmpty className="flex flex-col items-center justify-center py-6 text-center">
        <SearchX className="size-8 text-muted-foreground mb-2" />

      </CommandEmpty>
