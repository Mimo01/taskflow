**main.tsx -- resolve title for pushRecentItem:**

In the `handleIssueClick` function (around line 123), resolve the issue title from the react-query cache before calling `pushRecentItem`. Use `queryClient.getQueriesData` with a prefix key `['jira-issues']` to search all cached issue queries, then find the issue by key:

```typescript
const handleIssueClick = (issueKey: string) => {
  setSelectedIssueKey(issueKey);

  // Resolve title from react-query cache for recent-items store
  let resolvedTitle: string | undefined;
  const entries = queryClient.getQueriesData<{ issues: Array<{ key: string; fields: { summary: string } }> }>({
    queryKey: ['jira-issues'],
  });
  for (const [, data] of entries) {
    const match = data?.issues?.find((i) => i.key === issueKey);
    if (match) {
      resolvedTitle = match.fields.summary;
      break;
    }
  }

  pushRecentItem({ type: 'jira', id: issueKey, title: resolvedTitle });
};
```

This ensures every issue opened from sprint board, my tasks, backlog, or notifications includes its title in the recent items store.
