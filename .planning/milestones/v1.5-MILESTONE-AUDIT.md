### Broken Flow (1/13)

**Execute saved filter on sprint board (FILT-02, FILT-04)**
- **Break point:** SprintBoardTab.tsx does not import `useSavedFilterStore` or read `activeFilterId`
- **Root cause:** Phase 33 Plan 05 wired this (commit `3fdbfb9`). Commit `81d976d` removed saved filters entirely. Phase 35 restored all filter components and stores but did NOT re-add the `useSavedFilterStore` import and `activeFilterId` evaluation in SprintBoardTab.
- **Effect:** Clicking a saved filter in sidebar/palette sets `activeFilterId` and highlights the item, but board issues are not filtered
- **Fix:** Re-add `useSavedFilterStore` import and `activeFilterId`/`activeSavedFilter` evaluation in SprintBoardTab's `applyFilters` useMemo (code existed in commit `3fdbfb9`)
