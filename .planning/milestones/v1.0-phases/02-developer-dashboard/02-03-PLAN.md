<objective>
Wire the linking engine into the dashboard UI: compute task-MR and MR-task associations from live data, fetch MR approvals and discussions to derive review health badges, and render the linked data in TaskRow chips, MrRow task badges, and TaskCard health dots.

Purpose: Without linking, the dashboard is a read-only view of two disconnected systems. Linking is what makes the app useful — developers instantly see which MRs belong to which tasks.
Output: TaskRow MR chips and MrRow task badges are live and accurate. Review health dots correctly reflect approved/changes-requested/waiting state.
</objective>
