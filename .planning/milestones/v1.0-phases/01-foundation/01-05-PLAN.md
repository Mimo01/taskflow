    Apply the identical change — add the same import line and update the same comment. Nothing else changes.

    **capabilities/default.json:**
    Add a `"scope"` key as a top-level sibling to the existing `"permissions"` array. The scope must allow HTTPS requests to any host (needed for on-premise Jira and GitLab instances at arbitrary URLs):

    ```json
    {
      "$schema": "../gen/schemas/desktop-schema.json",
      "identifier": "default",
      "description": "Capability for the main window",
      "windows": ["main"],
      "permissions": [
        "core:default",
        "opener:default",
        "stronghold:default",
        "store:default",
        "http:default"
      ],
      "scope": {
        "http": {
          "allow": ["https://**", "http://**"]
        }
      }
    }
    ```

    The `http://**` pattern is needed because some on-premise Jira/GitLab instances run on HTTP (not HTTPS). Both patterns are required.
