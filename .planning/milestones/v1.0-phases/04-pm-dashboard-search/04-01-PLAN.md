Implement `matchGitLabToFixVersion` pure function:
```typescript
export function matchGitLabToFixVersion(
  fixVersionDate: string | undefined,
  candidate: { date: string | null; name: string; url: string }
): ReleaseMatch
```

Date normalization rules (critical for correctness):
- `fixVersionDate` is "YYYY-MM-DD" → parse as `new Date(fixVersionDate + 'T00:00:00Z')` to force UTC midnight
- `candidate.date` for milestones is "YYYY-MM-DD" → same UTC parsing
- `candidate.date` for tag `commit.created_at` is ISO 8601 with timezone → floor to UTC midnight: `Math.floor(new Date(isoStr).getTime() / 86400000) * 86400000`
- diff = `Math.abs(fixMs - candMs) / 86400000` (days)
- `diff === 0` → 'exact'; `diff <= 1` → 'fuzzy'; else → 'none'
- Either date null/undefined → return `{ type: 'none', candidateName: candidate.name, candidateUrl: candidate.url }`
