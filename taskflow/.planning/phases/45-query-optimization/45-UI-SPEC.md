### New component

**Concurrency limit row** — inline sub-row inside DebugModeSection, following the established `Retention limit` row pattern:

```
<div className="flex items-center justify-between gap-4">
  <p className="text-sm font-medium">Jira concurrency limit</p>
  <Select value={...} onValueChange={...}>
    <SelectTrigger><SelectValue /></SelectTrigger>
    <SelectContent>
      {[1, 2, 3, 4, 6, 8].map(n => <SelectItem key={n} value={String(n)}>{n}</SelectItem>)}
```

The row is rendered inside the `devToolsEnabled` opacity gate (same `ml-4` indented block as other granular toggles) so it dims to `opacity-50 pointer-events-none` when dev tools are disabled.

## Interaction Contract

### Sidebar prefetch (invisible — no visual change)

- `onMouseEnter` with 100ms debounce fires `queryClient.prefetchQuery()` on heavy-route nav links.
- `onFocus` fires prefetch immediately (no debounce) for keyboard accessibility.
- No visual state change on the sidebar link — hover highlight already handled by existing `hover:bg-accent` class.
- Heavy routes to prefetch: sprint board, backlog, epics, my tasks, dashboard.
- Routes to skip: settings, notifications (already polled globally), lightweight pages.

Source: CONTEXT.md D-06, D-07

### Concurrency limit toggle

- Renders as a `Select` row inside DebugModeSection granular toggles block.
- Options: [1, 2, 3, 4, 6, 8] — default selected: 6.
- Disabled (opacity-50 pointer-events-none) when `devToolsEnabled` is false.
- No confirmation required — change takes effect immediately, applies to next API calls.
- Persists to settings store (same pattern as `retentionLimit`).

Source: CONTEXT.md D-09; `taskflow/src/routes/settings/DebugModeSection.tsx` pattern

### Sprint board progressive rendering

- Stories render immediately with existing `Skeleton` placeholders for subtask rows.
- Subtask skeletons resolve to real content progressively as subtask chunk queries complete.
- No new loading indicator needed — Phase 44 skeleton infrastructure handles this (LOAD-03 activation).
- `useDelayedLoading` 200ms guard prevents skeleton flash for fast responses.

Source: CONTEXT.md D-01; Phase 44 skeleton infrastructure
